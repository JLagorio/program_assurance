## Principles
- A verb either changes something a reader can see on every screen that shows it, or says plainly that the prototype does not save it. No success toast for nothing.
- A link lands on the thing it names: the record, or the list filtered to exactly what was counted, with the record's preview open when it counts one.
- One source per number: a count is computed from the rows it opens, or cut.
- Keep the v2 look: budgets in COMMON.md; the visual layer runs after you.
- Every dialog you wire has real inputs (type, choose), checks its required fields before it closes, names the missing field, and its primary carries `data-v2-wired` so C1's guard leaves it alone.
