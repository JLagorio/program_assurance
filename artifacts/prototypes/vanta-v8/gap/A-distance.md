# Section A: distance from Vanta (folder `distance`)

Question: screen family by screen family, how far is v9.1 from Vanta in structure and look?

Families (judge each; use the nearest Vanta equivalent):
Home · My work · Review queue · Programs (index) · WS-X90 Overview · registers (Controls, Evidence,
Findings, Risks, POA&M, Checks/Tests, Policies, Suppliers, People, Integrations; sample at least six) ·
a record page (a control, a risk, a finding) · the side-panel preview · the SSP editor · Create program ·
assessment mode (`campaign`) · Settings · the shell itself (rail, program menu, top bar, ⌘K).

For each family give:
- a score 0–5 (5 = a Vanta user would find it familiar at a glance: same page shape, same density, same
  order of parts; 0 = nothing alike) and one line saying why;
- the three biggest differences, each tagged "on purpose" (the DoD/RMF work needs it: SSP, ATO, STIGs,
  ITCSC, inheritance) or "drift" (no reason; we just drew it differently);
- what Vanta's page shape is (README "One page shape everywhere") and where ours departs.

Then, across families: the five changes that would close the most distance for the least work, and
anything Vanta does that we have no equivalent for. Check whether stat cards still sit on every
register and whether "the same pattern everywhere" is still true. Use the v5 comparison files rather
than redoing them; your job is how far v9.1 is now.

report.md structure: a table (family · score · one line · top differences) first, then a short section
per family, then the five cheapest wins.
