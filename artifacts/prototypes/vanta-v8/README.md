# Review all and in-prototype feedback (2026-11-27)

- **About › Before & after › Review all** (route `before-after-review`, first in the strip): every screen of the study in four versions, **v2** (V3 off), **V3** (V3 on), the **Drata** after-screen and the **Canvas Kit** mockup. On a phone the versions are a swipe (with a v2 / V3 / Drata / Canvas Kit strip to jump); on a wide screen they sit side by side. Each version takes a 👍 or 👎, each screen a **Keep** choice (v2, V3, Drata, Canvas Kit or Mix), and notes: 💬 Note for the whole version, or 📍 Pin and then the spot, which draws a numbered pin on the screenshot or mockup. A screenshot opens full size (and can be pinned there). Filters: All, Not reviewed, With notes; Go to jumps to a screen.
- **Feedback button on every other screen** (bottom right): a note, a like or dislike, or a pin on the live page, recorded against the screen and the version it is drawn in (v2, V3, a `dr-` route, or the Canvas Kit tab).
- **Where it is saved**: the artifact's database (it already declares `db` and `user`), collection `feedback`, one document per note (`n-…`), per vote (`vote~<screen>~<ver>`) and per Keep (`keep~<screen>`). Claude reads it with `db_list` on the artifact. Opened from the file, or when the database cannot be reached, it is kept in this browser's localStorage (`pa-rv-feedback`) and Copy all feedback gives it as JSON.
- **Screens**: one per Canvas Kit mockup (`PA.ckba.meta`, matched to the prototype by its `route`), with the Drata pairs whose `current.route` matches attached, plus every other Drata pair as its own screen. V3 images are `ck/cur-<id>.jpg` (or `dr/cur-<pair>.jpg`); v2 images are `rv/v2-<key>.jpg`, shot by `node rv/shoot.mjs src/out/prototype.html rv` (needs a fresh build; it rewrites `src/mod-zzzz-v6-review-data.js`, so build again after it). A V3-only page is shot as v2's own page through `PA.v3.wasOf` (now exported); `evidence-sources` has none, so its v2 shot says so.
- Source: `src/mod-zzzz-v6-review.js` and `.css`, `src/mod-zzzz-v6-review-data.js`. `mod-zz-compare.js` only puts the tab first and counts its screens. Nothing of v2, V3, Drata or Canvas Kit changes.
