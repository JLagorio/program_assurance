# Foundations

The type, colour and surfaces under every proposed part: how the seven proposed tokens sit on Ledger's own. Proposed in the November 2026 UX proposal; not in the package.

Read it with the brand book: every value here is a Ledger token or one the sheet names as proposed.

**What it holds**
- **Surfaces**: page, sunken, raised, overlay, and where each is used.
- **Status tones** (`nx-state`, `nx-late`, `nx-risk`): colour for status, neutral for everything else.
- **Bars** (`nx-selbar`, `nx-footbar`): the selection bar and the workspace foot.

**Do**
- Start from the brand book's rules; this sheet shows them applied.
- The seven proposed tokens are an open decision.

**Don't**
- No new colour outside a status.
- No token used for a role the sheet does not give it.

The full-width card is the sheet as reviewed on the proposal's mocks canvas.
