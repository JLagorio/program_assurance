# Interface settings

Source: https://help.vanta.com/en/articles/15506748-interface-settings
Fetched: 2026-11-17

**Purpose**: each user sets their own color scheme and sidebar behavior; nothing here applies to other users in the workspace. All roles can change it.

## The steps

1. Account header → **Settings** → page menu, scroll to **My Account** → **Interface**.
2. **Color scheme**: System (default, follows browser/device), Light, Dark. Stored per browser and device. Also changeable from the profile menu.
3. **Sidebar behavior**: "Auto-collapse sidebar sections" on = one section open at a time; off = several stay open until collapsed.

## Flow edges

- any page → Settings (gear) → My Account → Interface
- any page → avatar → profile menu → Color scheme / My notification settings / SOC 2 guide / Event log / Sign out

## Actions

change Color scheme · toggle Auto-collapse sidebar sections · My notification settings · Enter sandbox mode · Sign out

## For Program Assurance

- The left nav groups top destinations (Home, My work, Agent, Tests, Reports), then collapsible domain groups (Compliance, Customer trust, Risk, Vendors, Privacy, Assets, Personnel), then Integrations, then the reader's own items (My security tasks, My access requests); an RMF nav can keep the same three bands.
- Personal display choices (theme, sidebar) sit under My Account and in the avatar menu, never in company settings.
