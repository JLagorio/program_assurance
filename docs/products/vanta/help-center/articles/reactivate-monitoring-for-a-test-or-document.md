# Reactivate Monitoring for a Test or Document

Source: https://help.vanta.com/en/articles/11345959-reactivate-monitoring-for-a-test-or-document
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

## Prerequisites
- 
Monitoring must have been deactivated, or the document marked as not relevant.
 

## Procedure
- 
From the Tests page, navigate to the "..." button on the top right of the page and select "View deactivated tests":
[image 01]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/1755763100/41d63e24b3ddf13ab2f66dcd7b68/Screenshot+2025-10-01+at+3_07_27%E2%80%AFPM.png?expires=1794967200&signature=25f1fa987366fa40413e2b321cb5bb96ffad8014343304ab12a176c36fc52a9e&req=dSciE854noBfWfMW1HO4zZQ%2BpBMpqIQ1QujM6c67ZZO31bR0iHwi1XE5DH%2BF%0A1Jyr2RVAW99N%2BWao0P4%3D%0A>
 
- 
Next, once you have selected the desired test or document, you can click Reactivate monitoring for a test and Re-enable for a document
 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763038/4775462d58321f29c6e31d9e35af/27569672664980?expires=1794967200&signature=6aeaf40b8df7f35249faefccab7f67ddfd83e0582066340a2ab85ab909a2c9b2&req=dSUmEM54noFcUfMW1HO4zaRQx%2FGKC8dAtEY5HhPKdeMxcScZYVjEfJQLXqhG%0AnA0lUZwo%2FRrrk6aFSRc%3D%0A>
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763042/866c09057589aeb0d28e713072c8/27569664198804?expires=1794967200&signature=a587a5ea04e2cd587cb3a4c0bb4957d3310cf63b704290e729d7874e59e869ee&req=dSUmEM54noFbW%2FMW1HO4zTCh6fPksFuQv7f32LEmPQxyk3JeXdN%2BEKZyWBzW%0AIi%2BOkeIvB2W5AIbMrJs%3D%0A>
 
- 
Next, you may see a pop-up calling out the checklist task if one is associated, allowing you to view the checklist settings before selecting Reactivate
