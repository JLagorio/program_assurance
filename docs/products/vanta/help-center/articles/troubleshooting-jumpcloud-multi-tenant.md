## Article text

## Prerequisites
- 
To connect Jumpcloud multi-tenant and Vanta, you must use the main administrative account.
 

## Procedure
- 
Click Settings in the bottom left
- 
Select Administrators
- 
Select + to add an account
- 
The permissions must be an administrator with billing to get API access
- 
Make sure to use a complex password and enable MFA on the account
- 
Log in as that new admin account to generate an API key
