# Find the Vanta key

Source: https://help.vanta.com/en/articles/11346023-find-the-vanta-key
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

In some cases, employees may need to use the company's Vanta key to help install or register the Vanta Device Monitor on their device.
This may involve distinguishing between a Personal Vanta Key, which individual users can find within their accounts, and the Company Vanta Key located in the admin panel.
 

## Types of Vanta Keys
There are two types of Vanta keys available:
- 
Personal Vanta Key: This key can be retrieved through your Vanta account. Use the provided link or access the relevant section within the platform.
- 
Company Vanta Key: This key is accessible to users with admin privileges in the Vanta admin panel. Make sure you have the proper permissions to access these keys.

## Prerequisites
- 
Only Admins and Editors <https://help.vanta.com/en/articles/11345385> have access to this information within Vanta.
Users without admin rights should seek assistance from a designated Vanta admin in their organization to access the required information.
 

## Procedure
- 
Go to Computers <https://app.vanta.com/computers> in the left-hand column under Personnel
- 
Select the Unmonitored <https://app.vanta.com/computers?tab=unmonitored> tab in the upper left
- 
Select the View setup instructions button. The view setup instructions button will only be visible once you have monitored devices.
