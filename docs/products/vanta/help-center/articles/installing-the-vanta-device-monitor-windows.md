# Installing the Vanta Device Monitor: Windows

Source: https://help.vanta.com/en/articles/11345396-installing-the-vanta-device-monitor-windows
Collection: Continuous Monitoring ; Continuous Monitoring › Vanta Device Monitor
Fetched: 2026-11-17

## Article text

The Vanta Device Monitor is read-only, meaning it will not modify any settings on your machines. It has limited functionality to read data (Vanta deploys a modified version of osquery that excludes tables that we find dangerous). The Vanta Device Monitor does not access sensitive information, such as passwords, emails, or browsing history. 
 

## Downloading the Vanta Device Monitor
- 
Employees will be sent an email to complete their security tasks. Once they log into their personal security tasks page, they will be instructed to download the Vanta Device Monitor:
​

​
- 
Click the purple Download button to begin downloading the Vanta Device Monitor file.
- 
Double click on the installer to open the setup wizard, and then follow the prompts in the setup wizard until a prompt appears requesting a registration code.
- 
This code can be found on your Vanta onboarding page (where you downloaded the agent) under step 3 of the 'Windows installation instructions'. Note this key is unique to your login, please do not share this code with others:
- 
Copy and paste the key into the setup wizard prompt and click Next to complete the installation.
- 
Once installed, the module can be closed. The Vanta Device Monitor will continue to run silently in the background.
​
