# Remediation Task Tracking for Access Reviews

Source: https://help.vanta.com/en/articles/11345754-remediation-task-tracking-for-access-reviews
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Workflow and Ticketing Tools
Fetched: 2026-11-17

## Article text

Leverage your task-tracking platform with Vanta to stay on top of Access reviews that require additional action items and attention. Vanta currently integrates with Jira, Linear, Shortcut, Asana, and ServiceNow. To create tickets from an access review, your task tracker must be connected with write access enabled.
​

## Managing Multiple Task Tracking Tickets
- 
Select the accounts to create a ticket form using the check box column on the left-hand side.
- 
Select the Create dropdown
- 
Choose Create and select the task tracker you would like to leverage
[image 06]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763340/5cd8883bd8a8ba3cdf69acf46d8a/27429334140564?expires=1794967200&signature=b659bbf3f9ce9d8b1be503c74395a0b561ac0400168c82da786c75dc90d6ba7f&req=dSUmEM54noJbWfMW1HO4zQovPXKcr5fzRWHMKBVVx79oEXLuv9YpFSoVofKv%0AokwVVOgtyxLT8PNBFoI%3D%0A>
- 
Complete the information from the pop-up modal and select Create
[image 07]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763342/d7ccc6138e908a86416655fc8765/13745017978260?expires=1794967200&signature=e3d0e38a4bb33901eab861c6e1b01aa4f1bc2dfef6991e5ec1276636523fcc30&req=dSUmEM54noJbW%2FMW1HO4zdWtnf8zrxgQeKzA49xYD7R0xVNhT9f3fScYyMiZ%0AjAkN65RF%2BEGtMKnpOjk%3D%0A>
- 
One ticket is created for each account.
- 
Please note that this is a bulk ticket creation, not a bulk ticket with multiple accounts.
- 
The application admin should process each ticket from the task tracker platform outside of Vanta.
