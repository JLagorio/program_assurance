# How to add a start date for background check requirements

Source: https://help.vanta.com/en/articles/11345949-how-to-add-a-start-date-for-background-check-requirements
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

A cutoff date can be set in Vanta to exclude personnel from the Background Check <https://help.vanta.com/en/articles/11345825> onboarding requirement if they started at your company before that date.
 

## At Groups level:
- 
Go to the People page <https://app.vanta.com/people/groups> and select the Groups tab
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516762445/cec39e13630f49e6f1a4b2236b0c/33851969158292?expires=1794967200&signature=bf2201376776dd105a00f06bdb9fcc1052757bab4244839a9ce32432a917b02c&req=dSUmEM54n4VbXPMW1HO4zWY3aQZNunt3ekxcWtNiMrE%2FaVBVbPsBu0wCkWvT%0Al%2FeOL3s89rq95lHbQt8%3D%0A>
- 
Select the desired group
- 
Under Onboarding and recurring tasks, select Background checks
 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516762444/68c9d52a7b0b1bc23eb3b9d46ff9/33851969163412?expires=1794967200&signature=44c2b29e6655814db5c6f92d468c55bdd7e099a477bbd06913de2de974e78814&req=dSUmEM54n4VbXfMW1HO4zfZXnVE5Dg1%2B8Y0I%2F1GWXeOePQXdPCEDcjfyV1%2B%2F%0A5f74%2FZXtc%2F5hNAnmtyY%3D%0A>
 
- 
Choose a Start Date and click Add
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516762441/ccae9a33cbb5b3d56d2767f4aa61/33851960867092?expires=1794967200&signature=d9b8315be93b0827fc340e789443cebf288614b0a1eaa0c860b9911dc7bbb347&req=dSUmEM54n4VbWPMW1HO4zdoayx3MXyxyRfUa8nu1FeGIY1KIE2zR1OdqR4sQ%0AawDCBrd8izznvzqj20c%3D%0A>

## At Task Sets level:
If you are making use of Task Sets, this can also be set at that level.
- 
Go to the People page <https://app.vanta.com/people/groups> and select the Groups tab
- 
Click the three-dots menu in the upper right and select Manage task sets <https://app.vanta.com/people/groups/task-sets>
