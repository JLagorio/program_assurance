# Reconnecting Linear Permissions in Vanta (June 2022)

## Article text

In April, Linear launched support for OAuth authentication. OAuth provides increased security and an easier-to-manage connection experience with Linear. Vanta has switched to using the new OAuth linking flow, and we’ll be pausing old API key-based integrations on July 26th. No data will be harmed, but you must re-connect your Linear integration to re-enable fetching data.
If you connected Linear before March 18, 2022, you should reconnect your Linear account on the connections page <https://app.vanta.com/integrations>.
