# Configure JumpCloud - Password Manager

Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

When using JumpCloud, Vanta will look at the list of programs and browser extensions for a password manager solution. Shown below is how to properly configure this for Vanta.
 

## Procedure
- 
Vanta will recognize if one of our supported password manager applications <https://help.vanta.com/en/articles/11346116> is installed on the machine and available in the Details, followed by the Programs list
