## Article text

Supabase allows customers to connect tools like Vanta using OAuth. By connecting your Supabase account with Vanta, Vanta can make API calls as the connecting user, allowing you to display information in Supabase within Vanta under the Access page & Inventory Page
Improvements have been made to the Vanta and Supabase integrations, if you have already connected to Supabase, follow these instructions to utilize the new functionality.

## Integrating with Supabase
- 
In Vanta, go to the Integrations page, click Add integration, and search for Supabase. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
A pop-up modal will appear; select Connect Supabase.
- 
If you are not logged in, you will be asked to log into Supabase before continuing.
- 
If you are logged in, you will be greeted with the authorization screen below.
- 
Click on Authorize to continue and be redirected back to Vanta.

## Reconnecting Supabase for more automation
Vanta has recently improved the Supabase integration by introducing more security tests to improve your security and compliance posture. To do that, the Supabase integration requires additional permissions, which require specific customers to reconnect the integration.
- 
To reconnect your Supabase integration, navigate to the Integrations Page <https://app.vanta.com/integrations> and click the Reconnect button on the banner
- 
You can avoid deleting the connection, as that will lead to loss of scoping and other metadata from the integration once it's reconnected.
