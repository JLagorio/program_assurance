## Article text

Feature availability: Federal and NIST frameworks <https://www.vanta.com/products/additional-frameworks> include the Issue Management feature. Other frameworks may require an upgrade, depending on your plan. Refer to Vanta Plans and Pricing <https://www.vanta.com/pricing?utm_source=help_center&utm_campaign=hc_pricing_cta> for details.
 
At Vanta, issue management plays a significant role in maintaining a strong and on-track compliance program. It's all about identifying gaps, whether they arise from audits, security reviews, or team feedback, and ensuring they’re properly tracked and resolved. By having a straightforward process to manage and resolve these issues, we help teams stay ahead of risks and demonstrate their ongoing commitment to maintaining compliance. 
 
 

## Issue Management 
Please Note: Only users with the admin, editor, and collaborator role can be assigned as the Owner of an issue.

- 
Issue management can be accessed from the left-hand navigation menu, under the Compliance tab.
- 
Select Issues.
- 
From the Issues home page, you can view your current list of issues and their status. 
- 
To find specific issues, you can run a search in the search bar or filter by: 
- 
Status: Closed, Started, In progress
- 
Priority: Critical, High, Medium, Low 
- 
Owner: Owner of the task
- 
Type:  Exception, Major nonconformity, Minor nonconformity, Opportunity for improvement, Process for improvement
- 
Additionally, tabs allow you to view issues by: 
- 
All: All issues
- 
Open: Open issues
- 
Closed: Resolved/Closed issues  
- 
To reset the view and remove filters, select Reset view. 
 

## Creating an Issue
- 
From the top right-hand corner, select Create Issue.
- 
Provide the following information:
- 
Title: Issue name
- 
Description: Describe the issue
- 
Priority: Issue priority  
- 
Due date: When should this issue be closed by?
- 
Issue Owner: Must be an Admin. The Admin assigned will receive notifications and reminders concerning the issue.
- 
Source: Which Framework does this issue fall under? 
- 
Type: Issue type
- 
Select the checkbox next to Create another issue if you would like to create a new issue.
- 
Select Create Issue

## Viewing Issue Tasks in the Issues Page
You can now see task progress at a glance from the main Issues page. A new Tasks column displays how many subtasks exist for each issue and how many have been closed. This helps you quickly spot issues that may need attention without opening each one individually.
 
The Tasks column shows:
- 
A progress bar indicating completion
- 
The number of closed tasks out of the total tasks within the issue
- 
A percentage showing overall progress
The column appears on the far right of the Issues table and updates automatically as tasks are completed.

## Viewing Issue Tasks in My Work
Issue tasks now appear directly in the My Work page, making it easier to stay on track with everything assigned to you. When an issue contains subtasks, each task is surfaced alongside your other work so you can see what is overdue or coming soon without navigating back to the Issues page. This creates a unified experience, since My Work now shows both issues assigned to you and the individual tasks tied to those issues.
 
 

## Mapped Elements 
- 
To provide additional context to the issue, you can map controls to it from the Mapped elements tab. 
- 
Selecting the plus icon button at the top right-hand corner of the screen allows you to search for specific controls you would like mapped to this issue.

## Closing an Issue
Please note: Once an issue is closed, it cannot be modified or reopened.
- 
When an issue has been resolved, select Close issue.
- 
Provide a reason for closing the issue and any additional comments.
- 
Select Close.
