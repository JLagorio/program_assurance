# Marking Custom Documents as Sensitive

Source: https://help.vanta.com/en/articles/11345473-marking-custom-documents-as-sensitive
Collection: Evidence Collection ; Evidence Collection › Documents
Fetched: 2026-11-17

## Article text

In Vanta, you can mark custom documents as sensitive to restrict access to owners, Admins, and Auditors. Follow the steps below to apply or remove this designation for new or existing documents.

## Marking a Custom Document as Sensitive
- 
When creating a custom document from the documents page, select + Add Document 
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516769962/3c7f7e0c602a12cff48a9fa986e1/35310321993620?expires=1794967200&signature=f10077c623137b67ce3c7576f5f52574d2df211c22bca26e1c31a0c8edd239bd&req=dSUmEM54lIhZW%2FMW1HO4zdW%2B7CxskqsoefJFA5cPlyVWcH8kdxInJaGkEL9U%0A5McrSDzQv1KjMuovLxY%3D%0A>
- 
Complete the necessary information, and check the box next to This is a sensitive document 
Sensitive documents can only be viewed by their owners, by Admin-level users, and Auditors'

## Marking a Previously Created Custom Document as Sensitive
- 
If you would like to mark a document that has already been added to Vanta as sensitive, from the Documents page, click on the document name
- 
From the top right-hand panel, select More
- 
Select Edit Custom Document 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516769961/5b06915244e1715af6d7c6cc9672/16466599906196?expires=1794967200&signature=0b9341ab66db475a6c27ef016a33898d0e5f805873e4265e9905a5d4c08dafa6&req=dSUmEM54lIhZWPMW1HO4zcEaNVYl7OkzV9Giok9qZHc%2FcArP%2F9p03sjTEJJF%0AMN5qo5oeh%2BKwA1tXFxk%3D%0A>
- 
Check This is a sensitive document 
- 
Alternatively, if you would like to unmark a document as sensitive, click the check box to remove the checkmark
