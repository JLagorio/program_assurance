## Converting a Contractor to an Employee
- 
To convert a contractor to an employee, you first want to offboard the contractor <https://help.vanta.com/en/articles/11345609>
- 
This will ensure the user is properly offboarded as a contractor, and that information will be maintained in Vanta for your records.
- 
Once the contractor has been offboarded, you will want to start the onboarding process from scratch with the user marked as an employee.
- 
Review their access from the access page once the user has been onboarded as an employee. You may need to reassign their access to the current contractor user
 
You can reassign access by:
- 
Open the access page and use the search bar to look for the user
- 
If the access needs to be reassigned to the new contractor user, select the pen icon and choose the appropriate person from the dropdown
