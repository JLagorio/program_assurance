## Connecting Vanta & Zendesk
- 
In Vanta, go to the Integrations page, click Add integration, and search for Zendesk. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect
- 
Vanta requires read-only access to users and ticket information through OAuth
- 
Select the services to enable, and select Next
