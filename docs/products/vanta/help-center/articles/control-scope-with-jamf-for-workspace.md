# Control Scope with Jamf for Workspace

Source: https://help.vanta.com/en/articles/11345706-control-scope-with-jamf-for-workspace
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Endpoint and Device Management (MDM)
Fetched: 2026-11-17

## Article text

- 
Navigate to Integrations
- 
Under your connected integrations, find  Jamf Pro
- 
Click Configure scope
- 
Enable the MDM scoping toggle next to the Control scope with Jamf
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516758914/496f28d4738528b485ae861aac0b/24972230997268?expires=1794967200&signature=6c7efcafc81d3712ba49b798466dc62603c09132f1ba44da89a67fe8a3fc2fce&req=dSUmEM57lYheXfMW1HO4zZMP0%2FNN5OOevK0iOY2qcSMviMvrGrGvpPiK1qoP%0A49xEItsiCulpTvEki60%3D%0A>
- 
Select the group(s) with which you want to scope computers and accounts. Then, click Publish changes.
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516758911/88ebddcbb8f241736af7dcec6a7d/24972231003540?expires=1794967200&signature=30837b9f85e3c8564921d43b2ea65d7cdb07fbf7aa3f1fd6489013e63e7c95b2&req=dSUmEM57lYheWPMW1HO4zbnhc6QnfrTiC9V%2FJAoDuepEiBxDAuKWjlcEhBE6%0AfdegJeiDnDPixVlSdnY%3D%0A>
- 
Once Jamf scoping is enabled, all account and computer scopes will be managed through Jamf, and the scope toggles for each account and computer will be disabled. Vanta will update the scope status for MDM accounts and computers of the following data fetch, which happens hourly.
