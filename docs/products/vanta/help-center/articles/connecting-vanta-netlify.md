## Article text

Netlify allows customers to connect tools like Vanta using OAuth. By connecting your Netlify account with Vanta, Vanta can make API calls as the connecting user, allowing you to display users in Netlify within Vanta under the Access page.
If you have connected to Netlify before March 7, 2024 additional automation has been added to the integration. Reconnect to leverage the updates.
 

## Integrating with Netlify
- 
In Vanta, go to the Integrations page, click Add integration, and search for Netlify. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect
- 
a pop-up modal will appear; select Connect Netlify
- 
Vanta will request access to your Netlify account; select Authorize 
- 
Note: You will need to login first if you are not already logged in on the browser.

## Reconnecting Netlify for more automation
Vanta has recently improved the Netlify integration by introducing more security tests to improve your security and compliance posture. To do that, the Netlify integration requires additional permissions, which require certain customers to reconnect the integration.
- 
To reconnect your Netlify integration, navigate to the Integrations Page <https://app.vanta.com/integrations> and click the Reconnect button on the banner.
- 
Avoid deleting the connection, as doing so will cause the integration to lose scoping and other metadata once it's reconnected.
