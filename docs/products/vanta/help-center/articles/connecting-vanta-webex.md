# Connecting Vanta & Webex

## Article text

Webex allows customers to connect tools like Vanta using OAuth. By connecting your Webex account with Vanta, Vanta is able to make API calls as the connecting user, allowing you to display Webex users within Vanta under the Access page <https://help.vanta.com/en/articles/11345381>.

## Integrating with Webex
- 
In Vanta, go to the Integrations page, click Add integration, and search for Webex. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
A pop-up modal will appear; select Connect Webex
