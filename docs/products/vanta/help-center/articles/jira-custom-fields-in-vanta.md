## Article text

With Vanta's improved Jira integration, you can now dynamically handle required custom fields when creating Jira tasks. This update ensures that Vanta automatically detects and includes required fields, preventing errors that previously blocked task creation.

## Why This Feature Matters
- 
No more blocked tasks. You no longer have to worry about Jira rejecting task creation due to missing required fields.
- 
Increased efficiency. Vanta automatically retrieves required fields, reducing the time spent manually filling them in.
- 
Improved compatibility. This update supports various Jira custom field configurations, making integration smoother.

## Using the Jira Custom Fields Feature

## 1. Ensure Your Jira Integration is Connected
Before using this feature, make sure your Jira integration is properly set up in Vanta.
- 
Navigate to Integrations in Vanta
- 
Locate Jira and confirm it is connected

## 2. Create a Jira Task in Vanta
Once your integration is active, follow these steps to create a Jira task:
- 
Open Vanta and go to Tasks
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516756721/ff3364da32fe1c742dc8ece255e2/35518021094420?expires=1794967200&signature=85bf91ec7456c03c830af703f87c99cb838f8d8b39fb2b5864e4802dc2487df9&req=dSUmEM57m4ZdWPMW1HO4zaE%2FA2E3imFaR4Ktou4oFCmzFqGrUbA97PEVIV59%0AM4zcg9JJWYV3nE9Sm1Y%3D%0A>
- 
Select a task that needs to be linked to Jira
- 
Click Create Jira Task

## 3. Automatically Populate Required Fields
Vanta now detects and dynamically generates required Jira fields:
- 
When you select a Jira Project and Issue Type, Vanta automatically retrieves required fields
- 
These fields appear in the Jira Task Creation Modal
- 
Fill in any required values as needed

## 4. Submit the Task to Jira
After filling in the required fields:
- 
Click Create Task
- 
Vanta submits the task to Jira, ensuring all required fields are included
- 
You will receive a confirmation once the task is successfully created

## Troubleshooting
If you encounter issues when creating a Jira task:
- 
Ensure the Jira integration is properly connected
- 
Check if required fields have valid inputs.
- 
If an error persists, verify Jira permissions for your project
- 
Contact Vanta support for further assistance
This feature ensures a seamless experience when managing compliance tasks in Vanta while leveraging Jira’s customization capabilities.
