# Creating Groups and Tasklists

Collection: Team Compliance ; Team Compliance › Managing Users
Fetched: 2026-11-17

## Article text

With Vanta, the default security requirements can be changed for all users or a subset of employees. For example, if you want contractors to have different needs than full-time employees, you can create a group for them.

## Default Group
- 
Personnel added to Vanta manually or through your Identity provider will be added to the default group.
- 
We recommend using this group for security tasks that all personnel must complete and then creating new groups for subsets of employees requiring additional security tasks. People can belong to more than one group.
- 
The group cannot be removed, but the name can be changed, and personnel can be removed or added to this group at any time.

## Create Groups
- 
Select People from the left-hand navigation panel
- 
Select Groups  <https://app.vanta.com/people/groups>
- 
Click the Create New Group button

## Assigning Tasks
- 
Open the group you would like to assign security tasks to
- 
Move through the list of options, adding requirements for your personnel
Onboarding Tasks 
- 
- 
Policies
- 
Requires personnel to agree to company policies
- 
Trainings
- 
Require personnel to complete security and privacy trainings
- 
Device monitoring
- 
Require personnel to have a computer that is monitored
- 
Background checks
- 
Require personnel to complete a background check
- 
Custom onboarding task
Offboarding Tasks
- 
Access removal
- 
Require terminated personnel's access be deactivated from key systems
- 
Custom offboarding task
- 
Require admin to complete an offboarding task
