# Sunsetting Google Drive Shared Background Checks

Source: https://help.vanta.com/en/articles/11345610-sunsetting-google-drive-shared-background-checks
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Access and Additional Integrations
Fetched: 2026-11-17

## Article text

Starting May 2, 2025, Vanta will no longer support background checks shared directly through Google Drive. This legacy feature has been replaced with manually linked background checks <https://help.vanta.com/en/articles/11345935>, offering a more flexible and secure way to manage background check evidence. This change is part of our continued efforts to simplify data management and enhance security across the Vanta platform.
Moving forward, you will need to record background check evidence using one of the following supported methods:
- 
Manually submit background check evidence <https://help.vanta.com/en/articles/11345938> in Vanta.
- 
Run background checks within Vanta <https://help.vanta.com/en/articles/11345701-vanta-background-checks-powered-by-certn>, powered by our partner Certn.
- 
Connect your background check provider using one of Vanta’s supported integrations <https://www.vanta.com/integrations?filters=Background+checkers>
There will be no impact on your audit for existing background checks. Newly completed background checks can be recorded in Vanta in the three ways listed above. If you have any questions, please don't hesitate to contact [email protected].
Learn more about background checks in Vanta here. <https://help.vanta.com/en/articles/11345825>
