## Article text

When using Jamf, Vanta will look at the Applications list for a password manager solution. Shown below is how to properly configure this for Vanta.
 

## Procedure
Vanta will recognise if one of our supported password manager applications  <https://help.vanta.com/en/articles/11346116>is installed on the machine and available in the Applications list :
- 
Search Inventory
- 
Search for the computer
- 
Under Inventory tab
- 
Click on Applications
