# Access Reviews

Source: https://help.vanta.com/en/articles/11345416-access-reviews
Collection: Team Compliance ; Team Compliance › Access
Fetched: 2026-11-17

## Article text

✅ Feature availability: Access Management features (including access reviews) may require an add-on to your plan. Refer to Vanta Plans and Pricing <https://www.vanta.com/pricing?utm_source=help_center&utm_campaign=hc_pricing_cta> for details.
 
Access reviews help you confirm who should keep access to your applications, document each decision, and collect evidence of any access changes. Create an access review, start it when you’re ready, review the accounts in each application, then complete it once access change evidence is added. Vanta records your review decisions but does not change access in your applications.
 
⚙️ User permissions: Access Admins, Editors, and Admins can create, start, complete, export, rename, or delete access reviews, and manage access review settings. They can also manage all access reviews across all applications, including assigning reviewers. Collaborators can be assigned as Application Reviewers to upload access data, review accounts, and add evidence for assigned applications only (access is not granted until the review is started). Learn more <https://help.vanta.com/en/articles/11345590-user-permissions-by-product-area>
 
 

## Managing access reviews
To manage your access reviews, go to the Access page and select the Reviews tab.

 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2809173679/1f7e2e8c68b2db30604c4e79368a/image.png?expires=1794967200&signature=29450bbdc232952a2b492a50b8ac840ce1600cdd18a9bc81d4f42269a5faa2cd&req=dignH8h5nodYUPMW1HO4zRPusEWaJ%2FZmDgyoPK6zYULJgpc7zB0n%2BErF1aTv%0ASNGH0eK4FAIHaIjMAKk%3D%0A>
 

### Access review owners
 
Each access review has a Review Owner, assigned when the review is created:
- 
The Owner column shows who the Review Owner is.
- 
If you create a one-time review, you’re the owner.
- 
If a review is created from a schedule, the Schedule Owner is the owner.
- 
You can reassign the owner until the review is completed.
 

### Access review status
 
The Status column shows where each access review is in the process:
 | 
Status | 
How it’s determined
 | 
Draft | 
A review has this status when it’s created, until someone clicks Start review.
 | 
In review | 
A review moves to this status when someone clicks Start review. It stays In review until it’s completed.
 | 
Completed | 
A review moves to this status when someone clicks Complete. Once a review is completed, no changes can be made to it.
 

### Applications by inherent risk score
 
The Applications by inherent risk score chart shows how many of your applications fall into each risk score:
- 
The total number of applications refers to your vendors. Vendors you connect on the Integrations page are added to your vendor list automatically, and you can add other vendors yourself. Learn more <https://help.vanta.com/en/articles/11345559-adding-and-managing-vendors>
- 
Hover over an application score to see the applications at that level and when each was last reviewed. Application scores come from vendor inherent risk scores. Learn more <https://help.vanta.com/en/articles/11345560-vendor-risk-scoring>
- 
If you don’t have user permissions to access vendors, all applications will appear as Unscored.
 

### To-do list and key dates
 
The To-do list shows upcoming access review deadlines:
- 
Start review and Complete review deadlines for each review schedule, with the schedule name next to each deadline.
- 
One Complete access review deadline for the review that’s due soonest, whether it’s a one-time or scheduled review. Hover over the due date to see which review it is.
Key dates for each review include:
 | 
Date | 
How it’s determined
 | 
Date created | 
The date the review was created, either by a user who made a one-time review or automatically from a schedule.
 | 
Date started | 
The date someone clicked Start review.
 | 
Date completed | 
The date someone clicked Complete.
 | 
Schedule start date | 
When a scheduled review should start, as determined by the schedule timing settings.
 | 
Due date | 
When the review should be completed. It’s the day someone clicks Start review plus a number of days:
- 
One-time reviews: the number of days in the access reviews settings.
- 
Scheduled reviews: the number of days in the schedule timing settings.
 

### Exporting, renaming, or deleting
 
Click the ••• menu next to an access review to take the following actions:
- 
Export: Download an XLSX file with a summary of the applications in the review and a worksheet for each application that lists its accounts and review decisions. You can also export from within an access review, and it produces the same file. An access review needs to be in the In review or Completed status to export.
- 
Rename: Edit the name of the access review.
- 
Delete: Delete the access review to remove it. If the review was Completed, the access review file in the relevant document tests remains unless you delete it there.
 
 

## Creating access reviews
You can create a one-time access review, or set up a recurring schedule to automatically create draft access reviews on a repeating basis.
 
[image 02]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2809184551/fafc298935bbfa3b6a0887768242/image.png?expires=1794967200&signature=e1525f8520a072f3f5edcb98a0a9c37157ceedf5de76a477163edfff7fa13d95&req=dignH8h2mYRaWPMW1HO4zSg7ljwuoKcogm460nnBjxY3cxuhiIAW%2FrFpNiDD%0ASqy9mEkYlZUTjEF%2B9xc%3D%0A>
 

### One-time reviews
 
To create a one-time access review:
- 
Go to Personnel > Access > Reviews.
- 
Click Create > Create review.
- 
Enter a Review name.
- 
Select the applications to include.
- 
Click Create draft review.
​
⚠️ Note: You can upload access data when an access review is in Draft or In review. In Draft, you can delete an uploaded file and upload a new one. Once the review is In review, you can’t edit or remove an uploaded file.
 

### Recurring schedules
 
To create a recurring schedule for access reviews:
- 
Go to Personnel > Access > Reviews.
- 
Click Create > Create schedule.
- 
Select a starting point:
- 
Select Custom schedule to start from scratch.
- 
Select a Suggested schedule to start from a template.
- 
Configure the schedule settings and schedule timing:
- 
Schedule owner: Select the user who should be the default Review Owner of each access review created by this schedule.
- 
Schedule name: Enter a name for the schedule.
- 
Schedule start date: Select the date the first access review should start.
- 
Days to complete: Enter the number of days to complete each review after someone starts it. This sets the review’s due date.
- 
Recurrence: Select how often the schedule repeats.
- 
Select the applications to include:
- 
You can select up to 150 applications per schedule.
- 
Finalize your schedule:
- 
Review your settings and applications.
- 
Click Save schedule—the first access review will be created 7 days before the schedule start date in the Draft status.
To manage a recurring schedule:
- 
Go to Settings > Features > Personnel > Access reviews.
- 
In the Active tab, click the ••• menu next to a schedule to Edit or Archive it.
- 
In the Archived tab, click the ••• menu next to a schedule to Unarchive it (it’s not possible to delete a schedule).
​
ℹ️ Note: You can add or remove applications included in your access review while it’s in Draft status. Once it’s In review, you can only remove applications from the list. Editing the applications included in an access review does not update the application list in recurring schedule settings.
 
 

## Starting a review
To move a Draft access review to In review, open it and click Start review. Reviewers can be assigned and access data can be uploaded while a review is in either status. A review can start before every application has access data, and reviewers can upload what’s missing.

 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2809191365/a49c2e27c556672bf2d39a035557/image.png?expires=1794967200&signature=e1c5b064b4d0532a41fd64be4606c8631ce27ded3f17fc70fb91c5814e40c643&req=dignH8h3nIJZXPMW1HO4zYCFaXMbWuzLrYciKZQfchVnJ62IQoWhC5ORBViz%0AI9ans0DqiwdFGthhYJg%3D%0A>
 

### Application reviewers
 
Each application in an access review has an Application Reviewer responsible for reviewing accounts in that application:
- 
The Reviewer column in a review shows who the Application Reviewer is.
- 
You can assign a user or a team as the Application Reviewer.
- 
When you create a draft, reviewers are auto-populated using the Security Owner field from vendor profiles. Applications without a Security Owner show as Unassigned within a draft access review. Learn more <https://help.vanta.com/en/articles/11345559-adding-and-managing-vendors>
- 
If any applications are Unassigned when the review is started, the person who clicks Start review becomes the reviewer for them.
- 
You can reassign a reviewer until the access review is completed.
 

### Application status
 
The Status column within an access review shows where each application is in the process:
 | 
Status | 
How it’s determined
 | 
Not started | 
All applications have this status in a Draft access review. Once a review is In progress, an application has this status if it’s missing access data.
 | 
Processing | 
Once the access review is In progress, an application has this status while its access data is being processed.
 | 
In progress | 
An application moves to this status once the access review is In progress and the application has access data synced or uploaded.
 | 
Completed | 
An application moves to this status when someone clicks Submit after all of its accounts are reviewed.
 

### Access data status
 
Access data is the list of user accounts for an application that gets reviewed in an access review. Applications in an access review come from your vendor list <https://help.vanta.com/en/articles/11345559-adding-and-managing-vendors>. When a vendor is connected through an integration that provides account data, its access data syncs into the review. When it isn’t, you upload the access data. 
 
The Access Data column shows whether access data is provided for each application:
 | 
Status | 
How it’s determined
 | 
Synced | 
The application’s access data comes from a connected integration.
 | 
Needs access data | 
The application has no synced access data and no uploaded file.
 | 
File uploaded | 
The application has no synced access data, and access data was uploaded.
⚠️ Note: Some integrations, like HRIS and MDM integrations, may not be able to provide account data, so those vendors will need access data to be uploaded, even if they’re a connected integration.
 

### Uploading access data
 
To upload access data:
- 
Open the access review:
- 
In the application list, click Needs access data.
- 
After the review starts, you can also open the application from the list and click Upload.
- 
Select how to upload the access file:
- 
Select Upload screenshots of user accounts to use our AI-powered image parser.
- 
Select Prepare and upload your own access file to fill out a template. Download our CSV or Google Sheets templates, which contain formatting instructions.
- 
Upload your access file:
- 
Screenshots can be JPG or PNG files.
- 
Spreadsheets can be CSV, XLS, or XLSX files.
​
⚠️ Note: You can upload access data when an access review is in Draft or In review. Once you upload a file, you can’t edit or remove it.
 
 

## Reviewing accounts
Review the accounts in each application of an access review, then click Submit to move the application from In progress to Completed. 
 
[image 04]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2809206871/df9b184d9e03f5643859a56534fa/image.png?expires=1794967200&signature=7c6bf2009f8898da518cdb0454280ad39aa1db79752bf4b85cbc0544a4ec5ada&req=dignH8t%2Bm4lYWPMW1HO4zZDlCJ5lOBWAk%2BWNQocfNoDmymTLLAELoXrw3cTT%0AdvX91FjcKoFDPbcOAQA%3D%0A>
 
You can submit an application when:
- 
Every account has an Account Owner assigned.
- 
Every account has a Review decision.
- 
Every account marked as Deny has a decision note or linked task.
- 
Every account marked as Change roles has a decision note.
​
💡 Tip: Remediation for Deny and Change roles decisions can wait until after you submit, but evidence must be added before the access review can be completed.
 

### Account owners
 
Each account in an application has an Account Owner, the user the account belongs to:
- 
The Account owner column shows who the Account Owner is.
- 
Every account needs to be assigned to an owner before an application can be submitted.
- 
Owners are linked to personnel records, so make sure the personnel record exists. Learn more <https://help.vanta.com/en/articles/11345379-adding-and-managing-personnel>
- 
To assign or reassign an owner, hover over the row and click the pencil icon next to the owner:
- 
For someone in your company, find and select their name.
- 
For someone outside your company, select Assign to external person.
- 
For an account that isn’t a person, select Mark as service account.
 

### Review decisions
 
For each account, select a decision in the Review decision column:
 | 
Decision | 
What it means
 | 
Approve | 
The account should keep its current access level. No decision note required.
 | 
Deny | 
The account should have access removed. A decision note or a linked task is required to update the status.
 | 
Change roles | 
The access level of the account should change. A decision note required to update the status (a linked task alone does not suffice).
To resolve a flagged decision, you may need to:
- 
Add a decision note to explain why access should be removed or which role the account should change to and why.
- 
Create a linked task to track the access change in your task tracker. Learn more <https://help.vanta.com/en/articles/11345754-remediation-task-tracking-for-access-reviews>
​
⚠️ Note: If you’re reviewing an account you’re the owner of, you need to either have another user review it or enter a reason for the self-review before you can continue.
 

### Remediation and evidence
 
Go to the Access changes tab within the access review: 
- 
The Remediation status column shows which accounts need evidence to show the access change was made.
- 
The access review cannot be Completed until every account with a Deny or Change roles decision has evidence added.
- 
You can add, edit, or delete and re-add evidence as needed until the access review is Completed.
To add evidence, you need to do one of the following:
- 
Add a remediation note.
- 
Upload an evidence file.
- 
Close the linked task in your task tracker.
 
 

## Completing a review
To complete an access review, open it and click Complete. Once completed, you’ll see a list of the relevant document tests in Vanta where your completed access review file is uploaded.
 
[image 05]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2809222708/aa341d6b0fb427a76925407cd73f/image.png?expires=1794967200&signature=87a67b2376814b218b7d4cc9ba08ab4fec268a70dc96d0deb97f386ad7f4aa34&req=dignH8t8n4ZfUfMW1HO4zWXgzOg%2BZaR4m%2BmIfAVkzeLCIxJBLcWemc3ZtEyR%0A1%2FZDrEfCYSQWca3wQUU%3D%0A>
 
You can complete an access review when:
- 
Every application in the review was submitted and has an application status of Completed.
- 
Each account marked Deny or Change roles has remediation evidence added.
​
💡 Tip: Vanta does not provision or deprovision account access in your applications—you need to make access changes in your applications directly. You can export an access review to work offline on the list of accounts that need changes.
 
 

## Access review settings
Go to Settings > Features > Personnel > Access reviews to manage these settings:
 
[image 06]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2809232401/8eb9d9066ae285f21f988a7c84ed/image.png?expires=1794967200&signature=6a62347883a9dc011e1530ffdf0109a9e956f60ebbf3f875c45a850c4645ff89&req=dignH8t9n4VfWPMW1HO4zdR6oTxBoNDjBvNreRDg%2Bcms763Bci%2FvpMM996vY%0ARd72r9mWqBLJWDvmKpY%3D%0A>
 | 
Setting | 
Description
 | 
Access review schedules | 
Create, edit, or archive schedules that automatically create a draft review on a recurring basis.
 | 
Admin point of contact | 
Choose an admin as the point of contact for access reviews. Their name appears in the footer of emails sent to your external notification mailing lists.
 | 
Due date | 
The number of days to complete a review after someone starts a one-time review. Scheduled reviews follow their own schedule timing for due dates.
 | 
Reminders | 
Choose how many days before each date to send a reminder:
- 
Schedule start date: Send a reminder before the next access review should start. This applies to scheduled reviews only.
- 
Due date: Send a reminder before the access review is due. This applies to one-time and scheduled reviews that have started.
 | 
External notifications | 
Send an access review progress digest to mailing lists, including people who aren’t in Vanta. You can choose a daily or weekly digest.
💡 Tip: Users can turn off reminders from Settings > My account > Notifications > My alerts > When an Access Review assigned to me needs attention.
