# Adding Comments to Tests

Source: https://help.vanta.com/en/articles/11345545-adding-comments-to-tests
Collection: Evidence Collection ; Evidence Collection › Tests
Fetched: 2026-11-17

## Article text

Tests require a lot of collaboration, and users working through difficulties must annotate information about tests to make the process more seamless for those involved. Users can now add comments to tests through Vanta's Tests Page.
 

## Adding Custom Notes to Tests
- 
From the left-hand navigation panel, select Tests
- 
From the list of available tests, click on the test you would like to add comments to

 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/1992518718/339f062dcc23ea408c695448b516/Screenshot+2026-01-26+at+4_39_57%E2%80%AFPM.png?expires=1794967200&signature=9c182a3069f2784e61b9dbf4385b5287eef9e3d0d7359453762c67d5659105d2&req=dSkuFMx%2FlYZeUfMW1HO4zXKVRaowRUxG8qCBeRCM4pKifw3Pez6UTVzY9PgS%0AyXtUNlAXjnmkQEG9ghI%3D%0A>
 
- 
Underneath the name, description, and owner of the test, you will see a button titled Comments
- 
From here, you can add additional information through Comments
- 
Remember that a comment is visible to all Vanta users within your company.
- 
Select send icon.
