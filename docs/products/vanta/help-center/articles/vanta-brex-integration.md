# Vanta & Brex Integration

## Article text

Brex allows customers to connect tools like Vanta using an API Token. By connecting your Brex account with Vanta, Vanta can make API calls as the app, allowing you to connect and pull in Access Data (Users List) from Brex for auditing purposes.

## Connecting Vanta & Brex
- 
Navigate to the Integrations Page <https://app.vanta.com/integrations> in Vanta and search for Brex
- 
Click on Connect

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761060/883f7116c5fb7893c836e9d98f77/18781478406804?expires=1794967200&signature=fd480287d15caadee648ad0d784904514b62d074b7acd6799ea4e1e8fb3ef7f5&req=dSUmEM54nIFZWfMW1HO4zQHwh6KhuWlnCczbPx2bQBlyfTwi1X9rkWXAkigQ%0AqFLdt2RiZyqJIi7TgeU%3D%0A>
- 
An overlay window will appear with instructions on obtaining your Brex API key and using it to connect it to Vanta
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761063/f227bd46217eb302e669102c9e2d/18781532595220?expires=1794967200&signature=b0de7b0fc4f416a601468704ff497a183af827b65cff2dd2a413c5a8fb1e7f6a&req=dSUmEM54nIFZWvMW1HO4zVUfTnHnb4b70Bhx9UKQtyoDUX8CnVL%2FzHoVd04y%0AgPqcY49bStdxbb8Y6t8%3D%0A>
- 
If the API Key is valid, after hitting next, you will receive a notification saying a Brex Connection has been created
- 
You can then go to the Access page <https://app.vanta.com/access/accounts>, switch to Brex in the drop-down list, and see all your users from Brex within Vanta
