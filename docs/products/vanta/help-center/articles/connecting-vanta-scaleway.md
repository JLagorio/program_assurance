# Connecting Vanta & Scaleway

Source: https://help.vanta.com/en/articles/11345713-connecting-vanta-scaleway
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Cloud Providers
Fetched: 2026-11-17

## Article text

Scaleway allows customers to connect tools like Vanta using API tokens. By connecting your Scaleway account with Vanta, Vanta can make API calls with the token, allowing you to display users in Scaleway within Vanta under the Access page.

## Integrating with Scaleway
- 
In Vanta, go to the Integrations page, click Add integration, and search for Scaleway. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
The pop-up modal will ask for an API key. Keep this modal open.

## Obtaining your Scaleway API Key
- 
From the top right-hand corner, click on your user profile name...
- 
Select API Keys
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516759354/b2b8049243e4e3d8f48020b918eb/23343758046996?expires=1794967200&signature=f1d815102e3a02ea64298ba34b5c24475e24243820635156d035cebad7733d0e&req=dSUmEM57lIJaXfMW1HO4zYE%2FsJjDN8y3pdQAecW%2BKfnnBY2oq3Hnr6oD2cpc%0AKFrHt%2BtR3ogSxKYMekU%3D%0A>
- 
Select Generate an API Key
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516759352/c1ead6d421d25d4f643f5c11bbb5/23343750865684?expires=1794967200&signature=cc8fd933fc00b4f1cda22bbd590b720efdaeb7def434b9296f9bf9376b33dd97&req=dSUmEM57lIJaW%2FMW1HO4zQiTJ7qabZa3dBs7vGcPImjBYCADSJk%2B43vUgp86%0A7BXoh6gn81CLDIGiCiU%3D%0A>
- 
Keep the API Key bearer as "Myself"
- 
Set the description to Vanta or something else that lets you know its connection.
- 
You can set a custom expiration if you wish, but it should never be.
- 
Click "Generate API Key" once you have reviewed your settings.

Copy the API Key, and past it back into the pop-up modal in Vanta

## Obtaining your Scaleway Organization ID
- 
Please follow this link <https://console.scaleway.com/organization/settings> to access the Organization ID page directly; otherwise, follow the instructions below to find it.
- 
Click on your name on the top right to drop down the menu.
- 
Then click on your name again. (the first item in the drop-down list)
[image 06]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516759386/981b5deb72f5d8e10b37959865e6/23343750868372?expires=1794967200&signature=84e0b68007d4791fc9e9f093c7f20a950cf084f9a24e82adf1fc69e7dcb6d309&req=dSUmEM57lIJXX%2FMW1HO4zR0yZJoLj4gcgyAIBpOHvREfCG4sFOAO47OQoe29%0A%2Bei0mGiHEt7XCdPAVrg%3D%0A>

Click on Settings
- 
Copy the organization ID and paste it into the field within Vanta.
