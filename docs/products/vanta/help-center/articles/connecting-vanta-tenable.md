# Connecting Vanta & Tenable

## Article text

## Step 1: Start the connection in Vanta
- 
In Vanta, go to the Integrations page, click Add integration, and search for Tenable. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Click Connect. 
- 
Click the link to the Access Control Users page. This will open the Tenable portal.

## Step 3: Create a permission in Tenable 
- 
From the Create Permission page in Vanta, click the link to open the Access Control → Permissions page in Tenable.
[image 08]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135182408/6356d54c8edc627085b4990672cd/faf1deee-67b6-4f81-b31d-9d692829c904?expires=1794967200&signature=a7c2d3eabf7758f1a856127090c6560e5a679d493ff5ec1d7b1d13726a05b124&req=diEkE8h2n4VfUfMW1HO4zcL5ZUJhbcz%2B0fQkP7JEofaKVfyLYiJxz19sy2L7%0A4W6Mf%2FYqtLtZRldjmto%3D%0A>
- 
In Tenable, click + Create Permission. 
[image 09]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135184394/85aab7e073cfe8491356017a9f0b/8681fa1c-63ca-41ee-894b-33e16c5cb0e3?expires=1794967200&signature=626c49c42788386dc8a2c183b235317b0a9f969ef0d917805f01a8cda716d577&req=diEkE8h2mYJWXfMW1HO4zTaFSEsme%2BcAJYBjYL6YDl%2FzbvbD4m2LopZODtZr%0A60yYJwPMTfzqHowuDrw%3D%0A>
- 
Enter Vanta Scanner as the permission name. 
- 
Select the Vanta Scanner user you created. 
- 
Select the All Users group. 
- 
Assign the Can View permission.
[image 10]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135186872/6a3a4bbf8a40eaca89e5f3380ed1/d7613c25-7537-44a4-b19f-b6dca93c3f93?expires=1794967200&signature=25079976e6807e468833c158f012ef5e81cdfe43f3d1f9de0663f7813bc83129&req=diEkE8h2m4lYW%2FMW1HO4zVcKChHdWVVX%2BPrri06ejaqng5H6ePvsMYmdXlu6%0AbrxU%2F9q5DiSQkajLHZ8%3D%0A>
- 
Select All Assets, then click Save. 
[image 11]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135378651/b9ff4ffc347d01ffa99d7b0660ee/d6cb6228-662c-4a01-939a-e2a5c432f0f8?expires=1794967200&signature=1f1bf21e093e88a6aba23847ec55b0ce9534ea16fb0e0217c417b662c0f3db92&req=diEkE8p5lYdaWPMW1HO4zVIZ4MOgc%2B9YoNpTN5uNYBESDx2z05gDhvD26dfB%0AsnWitsjfQQngh945f%2Bk%3D%0A>
- 
Click Save again to confirm. 
[image 12]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135189635/3b6e55d7d600377118a8fcc21598/db7a7ab8-c8c9-4a0e-8bf7-8891420950e7?expires=1794967200&signature=ad03e1c7d73da30e0a82c564df28c540bf3da1bae37199e6d9a88109285f789d&req=diEkE8h2lIdcXPMW1HO4zY%2BqPV501Y%2BwOxhgOYmGhoTVn0naIlZYlV2Np6OL%0AVmL0NFKFUvqr8i8mNW4%3D%0A>
- 
Return to Vanta and click Next.

## Step 4: Generate an API Key
- 
In Tenable, return to the Users table. 
- 
Right-click the Vanta Scanner user and select User Assist. 
[image 14]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135196894/7b7dd3662d16c5b938e9dae28051/842f7320-2658-4aaa-90ab-759644738bb3?expires=1794967200&signature=d2214d5d715b439ff4824c54d926bdd0e5df5b71caa4608c521357528e563225&req=diEkE8h3m4lWXfMW1HO4zSRBOZ6JVpcUiDPLg3mYo8aSVLD0xSdM4yEvXjvO%0AMcwvIEQ2%2FsAUrzLsm3w%3D%0A>
- 
Click the API Keys page link in Vanta to navigate to the correct page in Tenable.
[image 15]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135355412/5dee29636826d6c9f8337e6047d1/1c962847-3d38-42ee-834b-705568269a3d?expires=1794967200&signature=3c90811496b445da03004cd6332f9ec9aec09bf01cf2af471219e7d99c2d983a&req=diEkE8p7mIVeW%2FMW1HO4zVCrUDH1iKA0XByO8hVV73KlkIdU3lWdItIsRLyd%0Ar7tw1UBXK0W%2B81KkKTo%3D%0A>
- 
 Click Generate, then select Continue. 
[image 16]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135358135/30850d6f81a72176e06707ae999c/0b08083f-89df-4964-bd54-6f252aa557e4?expires=1794967200&signature=4978e3e6b3278cc2f88f92924dff38d8c79d7074e32dda589fb2dafd44a7897b&req=diEkE8p7lYBcXPMW1HO4zV61Z9K7c7bQT1AZBYs2qXrgAa7x7XgMR6WHOrqM%0A0lNcY39mzSXLOghgOVs%3D%0A>
- 
Copy the generated Access Key and Secret Key. 
[image 17]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/2135367631/49e42152f59dd4f071ff61d89495/149f9f45-fe66-4b5d-bd85-806a6311a3f2?expires=1794967200&signature=8b6def137a211d17b021d9bba8ada0f2967636d2268d12c92a59f0e27c78972f&req=diEkE8p4modcWPMW1HO4zQD%2FbmBWbDh1l3aekTRYr5OFXGJ9ut%2BZdclE2F6O%0AdjXlxdFsgwHcTkIDdOg%3D%0A>
- 
Return to Vanta and paste the Access Key and Secret Key into the corresponding fields. 
- 
Click Done to complete the integration.
