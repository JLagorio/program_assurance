Fetched: 2026-11-17

## Article text

Vanta supports multiple languages across the platform, though the level of language support varies depending on the feature you're using. Some areas of Vanta are fully translated, while others may display content in English by default. This article outlines where language support is available today, so you can know what to expect as you navigate the platform
 

## Language settings 
Please note: This will only apply to notifications sent via email from Vanta and to Slack communications that require translation.
Currently, the Vanta platform does not support translating the central platform or the onboarding page. 
- 
In your account header, click the Settings icon.
- 
In the Settings page menu, select Language.
Select a language from the dropdown.

## Policies in multiple languages
With Vanta, you can create and manage policies in multiple languages. For example, if some of your employees only speak English and others speak French, you may want to maintain policies in both languages. Vanta makes it easy to ensure employees view documents in their preferred language.
 
Note: The current supported languages (templates) are English, Spanish, German, French, Portuguese, Japanese, and Korean.
 

### Creating a policy in multiple languages
- 
From the left-hand navigation panel, select Policies
- 
Click into the Policy you would like to edit
- 
From the languages drop-down, select the languages you would like to create a version of the policy for

### Specifying a language for an existing policy
- 
Policies created before Vanta enabled policies with multiple languages to have a language of "Not specified" because Vanta could not determine the language of those policies.
- 
Select Edit, Renew, or Create a new version.
- 
A modal will appear, asking you to confirm the policy's language. Choose the appropriate language and select Confirm.

### Adding additional languages after policy creation
If a policy has already been created, you can still add additional languages.
 
If the policy has not been approved:
- 
Click into the policy, select the three-dot menu
-

### Changing the language when accepting a policy
Employees can choose the language they want to use when reviewing and accepting a policy. This ensures everyone can complete their required tasks in the language that works best for them.
 
When an employee opens the Accept security policies task, a Preferred language dropdown appears above the list of assigned policies.
 
To change the viewing language:
- 
Open the Accept security policies dropdown from your task list
- 
Select the Preferred language menu
- 
Choose the language you want to use
- 
The assigned policies will reload in the selected language if that language version exists

## Trust Center 
We don’t currently support multi-language Trust Centers natively, though it's on our radar and collection feedback to help prioritize. In the meantime, consider:
- 
Browser translation: Modern browsers can handle much of the translation for Trust Center pages. This works well for most on-page content, but won’t translate uploaded documents, email notifications, or chatbot interactions.

## Questionnaire automation: private preview
Questionnaire automation has a private preview option for automating questionnaires in French, German, Portuguese, and Spanish.

## My security tasks 
The My Security Tasks page, where employees complete tasks like policy acknowledgement and training, is translated into four languages: English, German (Deutsch), Spanish (Español), and French (Français).
Please note: The language displayed is based on the user's browser language setting.
