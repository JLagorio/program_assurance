## Accessing Task Sets Settings
- 
In your account header, click the Settings icon.
- 
In the Settings page menu, scroll to the Features section and select Personnel.
- 
Review the options across the page tabs: SLAs, Security tasks, and Access reviews.
From here, you can:
- 
Configure predefined SLAs for personnel tasks during onboarding and offboarding.
- 
Deactivate an employee task across all Task Sets. 
- 
Deactivating the task will also deactivate monitoring for the corresponding test. When deactivating a test, you'll need to provide a reason.
- 
Once a task is deactivated, the corresponding test will be deactivated, and the task will no longer appear on the people page.

## Disabling an personnel tasks from the Tests page
- 
Go to a test corresponding to an employee security task and click Deactivate monitoring.
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516754936/fc606839c2d6e338030daa76db37/16c445e4-9c84-403b-8314-e8c29aba8be4?expires=1794967200&signature=3fe403831085df110f74d0c26d412eb51b93c729115e8e5bc9ff7218487dd5f4&req=dSUmEM57mYhcX%2FMW1HO4zSjG1%2BhOzWuwHjx7loSDL41WhqbDh1g3LtgoW4Wg%0AsUaDnEiXZIBv5FYU3l4%3D%0A>
- 
Admins will now be warned that deactivating monitoring for the test will also deactivate the corresponding employee security task.
[image 04]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516754938/ae676733f76dbadb22fa0b6e6b26/5ecc11dd-fa6b-404c-a61b-4d6534cb44af?expires=1794967200&signature=e0fb79d9f4dfce844f4508937f8d732815fbc74915de4ad695e597c45aeb548c&req=dSUmEM57mYhcUfMW1HO4zVXkoq3HxeCxQfybUcDHHY2rUt13GIkQ8m%2BUQZSW%0AKGna3uMj6UItmSXtCqM%3D%0A>
- 
Once the test (and corresponding task) are disabled, the experience will be the same as the above section (employees will not be required to complete the task, and the task will be disabled on all create/edit Task Sets flows).
