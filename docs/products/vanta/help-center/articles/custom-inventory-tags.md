# Custom Inventory Tags

Source: https://help.vanta.com/en/articles/11345392-custom-inventory-tags
Collection: Continuous Monitoring ; Continuous Monitoring › Inventory
Fetched: 2026-11-17

## Article text

Customers can now use their tagging taxonomy for bulk tagging in Vanta. By mapping their custom tags one-time to Vanta's tags in the Vanta UI, Vanta will be able to read the information directly from their tags.
 

## Adding Custom Tags
- 
Navigate to the Inventory <https://app.vanta.com/inventory> page <https://app.vanta.com/inventory> from the left-hand column under Assets
- 
Select Edit Bulk Tag in the upper right corner
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516757988/2a6551056f9cdc505c8254b57e54/35184219467668?expires=1794967200&signature=614027f6e61260561a67561e1099d25cbba9ac3f3edefcd7e7645c963e1b3564&req=dSUmEM57mohXUfMW1HO4zUpRRlb4%2F%2BvL9yXu5ax%2BefttuKUrOhm1nQxhfK%2F0%0AkZv2WFxlHUNdrA3uRKU%3D%0A>
- 
Choose the appropriate service from the left-hand menu, and then select Custom Tags.
- 
In the table, enter tag names and values of the custom tags in the input fields to map them to Vanta tags.
- 
In the below example, the custom tag owner maps to the Vanta tag VantaOwner, and the custom tag environment with the value of development maps to the Vanta tag VantaNonProd
