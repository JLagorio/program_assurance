## Deleting all Custom Controls
- 
From the left-hand navigation panel, select Controls 
- 
From the top right-hand corner, select More
- 
Choose Delete all custom controls 
- 
Select the date for which you would like this to become effective
- 
Please remember that this action cannot be undone once controls are deleted. 
- 
Select Delete
