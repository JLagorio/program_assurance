In today's fast-paced, data-driven business environment, consistently sharing reports with stakeholders is crucial for maintaining transparency, alignment, and informed decision-making. Regularly scheduled reports ensure that key information is communicated on time and build trust and accountability across teams and leadership. With Vanta's reporting functionality, you can share key insights into your security and compliance program on a schedule.
 

## Scheduling Report Delivery
- 
From the left-hand navigation panel, select Reports
- 
Choose the report for which you would like to configure a scheduled delivery

## Create a New Schedule 
- 
Select Create schedule 
- 
See the Report time frame. This is the default time frame for the data that will appear on the report when first opened.
- 
Select the frequency of how often you would like this report to be sent and on which day.
- 
Include the recipients and a message providing additional context.
- 
Please note: Recipients must  <https://help.vanta.com/en/articles/11390685-sharing-reports>have access  <https://help.vanta.com/en/articles/11390685-sharing-reports>to the report before being included in a scheduled delivery.

## Edit a Current Schedule 
- 
Select the three-dot menu next to the schedule, and select Edit
- 
Make any necessary changes to the schedule, including frequency and recipients.
