## Article text

Vanta provides instructions to help customers remediate tests. When remediating Cloud tests, customers either remediate the test directing within the Console or use Infrastructure as Code (IAC). Tests that can be remediated with IAC by copying Vanta’s Terraform code. Human experts manually write this code or dynamically generate customs for your tech stack leveraging AI.

## FAQs
Why can’t I see this feature?
- 
Check that you are on a Cloud test. Non-cloud tests do not have this option.
- 
If you are on a Cloud test and cannot see AI remediation instructions, you must turn on Vanta AI. <https://help.vanta.com/en/articles/11345365> You can do that within your account settings
