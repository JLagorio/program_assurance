# Deactivate a Document

Source: https://help.vanta.com/en/articles/11345966-deactivate-a-document
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

You may need to disable monitoring for a specific document in certain cases. If the document is unnecessary or not required, you can deactivate the document request.
 

## Deactivating a Document
- 
Open the Documents page from the left-hand navigation panel. Documents can also be filted from the Tests page
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763386/badfa3c5a7e2565caa709da728ec/33082571584916?expires=1794967200&signature=0cc9989d18f252940edae3de6931e6e8ce6de3b8a413d5397f93418bc075c35c&req=dSUmEM54noJXX%2FMW1HO4zYpnjjO1H%2BZzTp05VZzAHS%2BcUXUqQWoAQCdf05%2Bw%0A1GM%2Bx1dtFzIUFR9zyus%3D%0A>
 
- 
Click on the specific document you would like to deactivate
- 
In the top right-hand corner, select the action button represented by 3 dots. Select Deactivate
 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763380/e3397c4d27ea3a9889282418bec5/33082571585940?expires=1794967200&signature=581522de9232d9ee8fe5c29c65cf2920e9d9132277705addc7c935a973f545ad&req=dSUmEM54noJXWfMW1HO4zaWxcjHOMTpttqQZxhIEK2xvPztJkBxnEgzgcO3n%0Af6Lcn%2Bc17TIV9zIlnmc%3D%0A>
 
- 
Choose how long you would like the test to be deactivated for
- 
Indefinitely
- 
Until specified date
- 
Provide reasoning for deactivation. This will help your team and auditor understand the reasoning behind this decision
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763382/be2e682dee986316538f56fddac6/33082594782484?expires=1794967200&signature=51f49376e95a3b4f4dbb2922074ae4eb5239a6ee7974729111a5f4099149f7f8&req=dSUmEM54noJXW%2FMW1HO4zVEqUv%2Fr7k03PgjWH%2FmnJSYqm1O0Or0UBuFEeNi4%0AKlepuHEQSsKa7kc5ZCY%3D%0A>
 
- 
When ready, select Deactivate
- 
This will remove the Document from your list. We recommend doing so only if this does not apply to your company.
 

## View Deactivated Documents
- 
To view all documents that have been deactivated, select All deactivated under Category section on the Documents page
 

## Reactivate a Document
- 
Open the Document page, and select All deactivated under Category. 
- 
Click on the document you would like to reenable
- 
Select Activate
