## Add a Custom Document
- 
Click Add Document in the top right-hand corner of the Documents page, and select + Add document from the dropdown
- 
Complete the information requested in the pop-up modal
- 
Select Create document
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516770447/54ce8770017b901b653e90383a7e/18936327407252?expires=1794967200&signature=b5cfcbd97a187e0a9598bc8302d837fc2ac51f209a58aa77e7d2499f0a5c0527&req=dSUmEM55nYVbXvMW1HO4zWzaBADEF18QMhLSwL5E6YVwhYO561Tg7jLx0DM7%0AUVya2kJ4z9eCDKAfMqA%3D%0A>
- 
Next, you'll be brought to the new document and be able to add Controls.
- 
- 
If the Add document to control modal doesn't appear automatically, you can open it by clicking More in the upper right corner of the new document and selecting Add control.
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516770444/9609e05b9cfdee536d3fb1e1aa78/26388917542292?expires=1794967200&signature=8b9d6040ca16cf0be9e3fb7206ef03c2c586b927214a922db605244d4e256707&req=dSUmEM55nYVbXfMW1HO4zUFJbEX7UbkM4zgL7nU8mXcHwWM3%2BqtVb31zrAxv%0AQTm3KS%2FwLDRS0e4bsyw%3D%0A>
- 
In the Add document to control modal, search for the name of the desired Control
- 
You can use the Framework dropdown to narrow down the search results
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516770448/83b25b1043b0aea91e1915ffdbab/26388885178644?expires=1794967200&signature=edffff0884fa59c806c13d2e2f58ded539e8dd335f93f056182ba0818d891a4e&req=dSUmEM55nYVbUfMW1HO4zcTCW251iojMk94QxcEIb0qSs8GZLkLdI2tuQAEl%0AhzZqjBSLhvwPAyOxUrg%3D%0A>
- 
When you locate the desired Control, select the name and click the Add button on the right.
[image 04]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516770445/2e53ab1a8f62778d40feb4c8d61f/26388917556116?expires=1794967200&signature=12bc2143226d0dd1965e88dd628d5e2e9caf5386b0c30a30fb95054bb00d037e&req=dSUmEM55nYVbXPMW1HO4zaBGjxClm2tdlYhP1mx%2BRdyWQH48ADtKUsIkBTAj%0AqN2aqh8zst3DHwH8H9w%3D%0A>
- 
To add files to the new document, select Upload from the top.
- 
If the document is linked in another platform, select Add Link and paste the URL into the open field.

- 
Choose the file you would like to upload
- 
Add a description and the document's effective date
- 
Select Upload 

## Adding Custom Evidence to a Control
- 
From the left-hand navigation panel, select Documents
- 
Select the appropriate document name by clicking on it directly
- 
You can also filter by Status > Needs Document 
- 
Select Upload from the top Add New Document modal
- 
If the document is linked in another platform, select Add Link and paste the URL into the open field.
