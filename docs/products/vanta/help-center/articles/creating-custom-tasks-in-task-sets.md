# Creating Custom Tasks in Task Sets

Source: https://help.vanta.com/en/articles/11345604-creating-custom-tasks-in-task-sets
Collection: Team Compliance ; Team Compliance › Employee Onboarding & Offboarding
Fetched: 2026-11-17

## Article text

Vanta allows you to create a custom task in your security task sets. Admins who want to go beyond the default employee security tasks can do so with less effort.

## Creating a Custom Task
- 
From the left-hand navigation panel under Personnel, select People
- 
Go to the Groups tab
- 
Select the Group to which you would like to assign custom tasks
- 
Choose Custom onboarding task
