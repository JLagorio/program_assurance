# Change your GitHub Integration from Showing Vanta 'all repositories'

Source: https://help.vanta.com/en/articles/11345930-change-your-github-integration-from-showing-vanta-all-repositories
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

This article details how to change your GitHub integration from showing Vanta 'all repositories' to only a select few.
 

## Prerequisites
- 
Administrator Access to GitHub
 

## Procedure
- 
Sign in to GitHub and click on your profile picture on the top right
- 
Click on Your organizations
- 
Scroll down and Click Applications
- 
Select Configure for Vanta GitHub Integration
- 
You will see the Repository Access is on the All repositories bubble; click on the second Only Select bubble
- 
Select your desired repositories, one at a time, then click the green save button
