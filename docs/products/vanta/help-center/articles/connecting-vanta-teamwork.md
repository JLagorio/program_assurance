# Connecting Vanta & Teamwork

Source: https://help.vanta.com/en/articles/11345712-connecting-vanta-teamwork

Fetched: 2026-11-17

## Article text

Teamwork allows customers to connect tools like Vanta using an API Token. By connecting your Teamwork account with Vanta, Vanta is able to make API calls as the app, allowing you to connect and show Access Data, Task Tracking, and Vendor Procurement data within Vanta from Teamwork.

## Integrating with Teamwork
- 
In Vanta, go to the Integrations page, click Add integration, and search for Teamwork. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
a pop-up modal will appear; select Connect Teamwork.
- 
Vanta will request access to your teamwork account; select Continue .
