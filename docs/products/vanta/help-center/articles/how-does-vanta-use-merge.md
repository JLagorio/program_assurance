# How Does Vanta Use Merge?

Source: https://help.vanta.com/en/articles/11345736-how-does-vanta-use-merge
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Access and Additional Integrations
Fetched: 2026-11-17

## Article text

Merge is a API aggregator <https://www.merge.dev> used by Vanta to collect data from certain HRIS, Task Trackers, and Access systems.
 
Merge encrypts all of your data and provides Vanta read-only access or Access system. Merge provides write access to certain Task Tracker Systems so that you can create tasks within Vanta. You can learn more about Merge and its security practices here <https://www.merge.dev/security>.
