# Assigning Group Ownership to Inventory Items

Source: https://help.vanta.com/en/articles/11345484-assigning-group-ownership-to-inventory-items
Collection: Continuous Monitoring ; Continuous Monitoring › Inventory
Fetched: 2026-11-17

## Article text

With custom ownership functionality, Vanta users can enter any value as an inventory owner in addition to Vanta users through the Inventory Page. This can be helpful in instances where the item owner is not a user within Vanta.

## Assigning Custom Ownership to Inventory
- 
Find the asset you would like to assign customer ownership from the inventory page
- 
Select the owner drop-down, and scroll to the bottom to Select Assign Group Owner
