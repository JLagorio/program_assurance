## Article text

Feature availability: This article discusses Advanced Trust Center and Advanced Questionnaire Automation features, which may require an upgrade or add-on. Refer to Vanta Plans and Pricing <https://www.vanta.com/pricing?utm_source=help_center&utm_campaign=hc_pricing_cta> for details.
 
Tags help you organize and automate different parts of your security program in Vanta. By adding tags you can easily manage access, assign tasks, and streamline your workflows saving time and reducing manual effort:
- 
Use tags to organize your knowledge base <https://help.vanta.com/en/articles/11345465-managing-your-knowledge-base>.
- 
Use tags to share sets of resources in the Trust Center <https://help.vanta.com/en/articles/11345455>.
- 
Allow users to filter content on your Trust Center <https://help.vanta.com/en/articles/11345455>.
- 
Tailor the content used to answer questionnaires <https://help.vanta.com/en/articles/11345454>.
​
 

## Create tag categories
Tags are grouped by category to facilitate the application of related tags to specific workflows. The categories and tags within each category are entirely customizable for your needs.
- 
Go to your Settings page.
- 
From the page menu, select Tags.
- 
Select + Create tag category.

Complete the Category name field.

Press Enter to add a value or separate tags with a comma.

Select Create.

## Remove a category
- 
Select the category you would like to remove.
- 
From the top left-hand corner, select the three-dot menu.
- 
From here, you can edit or delete the category.

## Add or edit tags
- 
From the Tags tab, click on the category you would like to edit.
- 
If you want to add additional tags to the category, select + Add tag values. 
- 
Add the desired tags and select Save.
