# Downloading a Draft Version of a Policy

## Article text

## Prerequisites
- 
Editor or Admin permissions in Vanta. For more details on permissions see Permissions in Vanta <https://help.vanta.com/en/articles/11345590>
 

## Procedure
- 
Navigate to your Policies page and select the specific policy
- 
Once opened, click the Edit button
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516757730/130731089b8f5e8b96c43a99b027/28297275097748?expires=1794967200&signature=c97569e39789351419bb97af115e1ec4e4e9b74a6159c36481a273b45bfbd48c&req=dSUmEM57moZcWfMW1HO4zfJkUGADVgP9TuNHkNEp8JtVQNG9nj4Qfz%2BR7d7P%0Af%2Fr3ITR8HLwT%2FeomCtA%3D%0A>
- 
Select the three-dot menu, and choose Preview as a PDF
 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516757727/145cd15eb015eca5772ef28a6384/28297249887892?expires=1794967200&signature=64574d4bead5c992749b0d94d3b3073c0064314cc28997aa02a63f77ceb5b57f&req=dSUmEM57moZdXvMW1HO4zWf6EESqs3ITX7Dbz1c3jE5HB1%2BZ70P526pQb0Hl%0AHkMILxpHQvDXnxYsCVQ%3D%0A>
 
- 
Select the download icon
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516757725/d2d1d83dcec0fccc6042bc43792e/28297275099412?expires=1794967200&signature=086509f2dbf923ef865607ccfb9ef005012b91152df09432eb82772796b5c5a2&req=dSUmEM57moZdXPMW1HO4zbtNWrjhQ78OIoskwwiCSMTV7zWIdjt7VmnV89ZK%0AjNYkvLJPVg0g56Ntmn8%3D%0A>
 
- 
The draft version of the policy will then be available in your download folder as a PDF file
