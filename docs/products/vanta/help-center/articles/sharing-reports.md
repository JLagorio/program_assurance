Sharing reports with stakeholders is a practical and effective way to keep them informed without requiring full access to the Vanta platform. This approach provides visibility into key compliance information while controlling sensitive data and system settings. By offering dynamic access to reports that update as new data becomes available, teams can ensure stakeholders always have the latest security and compliance status insights. 
 

## Sharing Reports 
- 
From the Report page, select Share
- 
Select Manage access
- 
To be shared to a report as a viewer, an individual must have collaborator <https://intercom.help/vanta-ceb3b688ec0b/en/articles/11121320-understanding-user-roles-and-permissions-in-vanta> permissions.
- 
Please note: Anyone with editor or higher permissions is automatically given access to all reports. 
- 
The user will be notified by email that they have been given access to the report
- 
As long as the individual maintains access, the link will remain live for them to view the report.

## Removing Access
- 
From the Report page, select Share
- 
Select Manage access
- 
Select the three-dot menu next to the person whose access you would like to edit
- 
Select Remove access

## Sending a One-time Notification
- 
 From the Report page, select Share
- 
Select Manage access
- 
Select the envelope icon 
- 
An email notification will be sent.
- 
You also have the opportunity to schedule the delivery <https://help.vanta.com/en/articles/11390625-reporting-schedules> of these reports to those who have access.
