# How to Remove Devices from Vanta for Microsoft Endpoint Manager (Intune)

Source: https://help.vanta.com/en/articles/11345965-how-to-remove-devices-from-vanta-for-microsoft-endpoint-manager-intune
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

In some cases, not all devices need to be covered in Vanta for an audit. Here is how they can be removed for Intune (formerly Microsoft Endpoint Manager).
 

## Procedure
- 
Go to Integrations
- 
Go to Microsoft Endpoint Manager
- 
Click on Configure Scope
- 
Locate the device and toggle it out of scope
