How do I track the resources that Vanta does not support fetching?
- 
Administrators have the option to add these unsupported resources to their custom inventory items. You can view details on Bulk Upload Custom Inventory Items  <https://help.vanta.com/en/articles/11345483>and Tracking Inventory in Vanta <https://help.vanta.com/en/articles/11345485> for more information. Once the items are added, admins can add a description and specify if the resource contains user data or not.
- 
Administrators will also need to work with their auditor to collect manual evidence for these resources and store this evidence as a Custom Document <https://help.vanta.com/en/articles/11346017> in Vanta.
