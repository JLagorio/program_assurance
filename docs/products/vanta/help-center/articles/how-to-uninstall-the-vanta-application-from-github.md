# How to uninstall the Vanta Application from Github

Source: https://help.vanta.com/en/articles/11345929-how-to-uninstall-the-vanta-application-from-github
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

## Prerequisites
- 
Administrator Access to Github
 

## Procedure
- 
Sign in to GitHub, then click on your profile image on the top right and select Your organization. 
​
​
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761384/cf77b7dada0474096217c045c349/16936744883604?expires=1794967200&signature=0a1a7847a8ef1a36e422d57c8783ad03cb34b216d8a053c2a86e17986368c256&req=dSUmEM54nIJXXfMW1HO4zWEcIOubuQIyLEhyqnx7q4N9anAs1F4isQxfajV5%0AcMJn%0A>
 
- 
Scroll down on the left-hand side until you get to the integration section.
- 
Click Applications
​
​
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761376/ae85166897073a87fa06c5454d6d/16936803701012?expires=1794967200&signature=b2dd25652a5447679ea7e11120eea53f5c13b0e188f5d50e05316b62ef9c8a8a&req=dSUmEM54nIJYX%2FMW1HO4zRdyOIZMFemAA6eB2amMdIOlrTIyubheVGRFIGTB%0AvEvL%0A>
 
- 
Select Configure for Vanta GitHub Integration, and on the application settings page, scroll down immediately to the Danger Zone
​
​
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761386/2746c76ae20d6f73aa1ad0f4d6e9/16936828107412?expires=1794967200&signature=4d8dc9242e89df1ddd6a0c876d5c3176c48f19422839d04ec39f3e2e495c7a01&req=dSUmEM54nIJXX%2FMW1HO4zVuow3Bxb%2BtnGXX%2BcVzCNUiAwzDjSwMhorUv4gla%0AHgD6%0A>
 
- 
Enter the Danger Zone and click the Uninstall button:
​
​
[image 04]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761375/6fdc3fa4e222e0ae778f9cd375d1/16936853222932?expires=1794967200&signature=32272bcffffcf31150731e812997c8ff6785517db6569d3054bc3f3e7ba6d53e&req=dSUmEM54nIJYXPMW1HO4zVW%2BVc9iFkqtqhJ3HB4hK0r%2BbCmfvJC864OqED2M%0AqySm%0A>
 
- 
The webpage will warn you: "This action cannot be undone. Are you sure you want to uninstall
this GitHub App from X repositories?", click OK
​
​
[image 05]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761389/a9d18fae1c357c356149b69014ce/16936830413076?expires=1794967200&signature=b63c737e11383e3278e3aaa187d1792f5d2c5dd57fb349f6dfb4daf6e3737d8e&req=dSUmEM54nIJXUPMW1HO4zRBErlONXazeQHYg6zu5cMYPEdyeuT88qXWtJsAX%0ATB0H%0A>
 
- 
Once this is done, your integration will break with Vanta, and you will see this message appear on the integrations page.
[image 06]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761405/c6f16835136fad7cd004bd875955/16936894772116?expires=1794967200&signature=b9e54997a8912141247c6b3fa0c12ed2a16d75363592acabbed3fffd2b029019&req=dSUmEM54nIVfXPMW1HO4zX0tQSWM%2FdTJ2gD%2FXvcXIC%2BCGm%2F1IkMimNL81p9H%0APWz1rNXUzgIC3KZzX%2FM%3D%0A>
 
- 
Your repos will also no longer appear in Vanta. This is expected
- 
This is typically done before re-connecting the integration, or when one encounters the Github Error: “Internal Server Error" <https://help.vanta.com/en/articles/11346033-github-error-internal-server-error>. You can proceed with the re-connection steps now
