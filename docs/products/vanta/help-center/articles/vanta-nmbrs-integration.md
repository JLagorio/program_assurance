# Vanta & Nmbrs Integration

Source: https://help.vanta.com/en/articles/11345910-vanta-nmbrs-integration
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

Nmbrs allows customers to connect tools like Vanta using an API Token. By connecting your Nmbrs account with Vanta, Vanta is able to make API calls as the app, allowing you to connect to find people and use onboarding/offboarding dates from your HR system.
 

## Prerequisites
- 
Vanta leverages Merge, a third-party platform, to pull in your data from Nmbrs. See their documentation <https://docs.merge.dev/integrations/hris/nmbrs/provider-interactions/> for details on the API interactions used.
 

## Procedure
- 
To connect, go to the Integrations page, click Add integration, and search for Nmbrs. For help navigating the Integrations page, see Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Click Connect. 
- 
A pop-up will show you that we use Merge.dev a third-party platform to pull in your data from Nmbrs.

A popup module is displayed, allowing you to review the requested permissions. Click on continue after reviewing the affected read data.

- 
You will then need to enter your Nmbrs sub-domain by visiting your Nmbrs portal and copying it from the address bar in your browser.
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516760186/032778314b602d19689c7bde5316/17741994113428?expires=1794967200&signature=9d95ac5f7e830a49b5a6c5b8d0d10a72c1fb09edfe5dd4dcd83d2a78608d7bc0&req=dSUmEM54nYBXX%2FMW1HO4zRdrqQ7niTkho%2BsUjAk38sZdrXaFbqw56%2Bl9PsMK%0AelqnRlk0ocWpIJ5Zozk%3D%0A>

Afterwards you will need to follow the instructions in order to get your Nmbrs API Key and connect it through Merge.

- 
Once the API Key has been input successfully, you will also need to verify the email address that is associated with the API Key as required by Nmbrs.

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516760210/c45f7c26f0b843cfd70bfea1e02c/17742070871828?expires=1794967200&signature=2c3a42025a7be723899d3e3eacad714c997d7f783ee54a83c2c9d0bf3c6ebae2&req=dSUmEM54nYNeWfMW1HO4zQR2ia7C%2Bl6NlaqdUJZ805L80oFFaKE3D%2B1XvsO7%0Ar%2FwSCrhb9EFrBRKlO1k%3D%0A>

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516760216/f4fd316fa6dcb3ae237199a96e25/17742102730772?expires=1794967200&signature=69d0d258562037155c680d4aaf4c30d7a29c4669550580cb97d1f10a2862c3a3&req=dSUmEM54nYNeX%2FMW1HO4zfVXv159ITTPdbKa3GW08WQWvcmRStL1TBorfGsD%0AM097PFNfPXX%2FPG50VwI%3D%0A>
