# Error: Auditors Unable to Have Default Access to Documents

Source: https://help.vanta.com/en/articles/11345924-error-auditors-unable-to-have-default-access-to-documents
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

## Environment Details
Auditors who cannot access a document do not have default access. A document must be linked to a control in order to appear in the auditor's view.
 

## Cause
- 
Document is not linked to a control, hence unable to access while selecting view as Auditor
 

## Resolution
- 
Select the Audits page
- 
Open any active audit

- 
If a document isn't visible, ensure the document is mapped to a control on the Documents Page <https://app.vanta.com/documents>. To map a document to a control, follow these steps:
- 
Select the document you'd like to map
- 
Next to Related frameworks and controls select Add Control
