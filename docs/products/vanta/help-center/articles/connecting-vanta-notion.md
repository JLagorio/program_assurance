# Connecting Vanta & Notion

Source: https://help.vanta.com/en/articles/11345719-connecting-vanta-notion
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Access and Additional Integrations
Fetched: 2026-11-17

## Article text

Notion allows customers to connect tools like Vanta using OAuth. By connecting your Notion account with Vanta, Vanta can make API calls as the connecting user, allowing you to display User accounts within Vanta on the Access page. The Notion integration will also enable Vanta to pull in your task information and allow you to create Notion tasks directly from Vanta tests.
 

## Connecting Vanta & Notion 
- 
In Vanta, go to the Integrations page, click Add integration, and search for Notion. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
A pop-up modal will appear; select Connect Notion.

- 
If you are not logged in, you will be asked to log in to Notion before continuing.
- 
If you are logged in, you will be greeted with the authorization screen. 
- 
Click Select Pages 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516759711/b6f63ad8bff94b71ce910d86ed0d/37010679214868?expires=1794967200&signature=8090ef0b9843ec122454cd5af71422fddcb9b51613ee68266cefd8a177e26d85&req=dSUmEM57lIZeWPMW1HO4zV1BOi589d8yUzW2Pk2bNiIHevDCQ0uMDPXiNegU%0As7fMZy26zIDOtnzlCNE%3D%0A>
- 
You will be prompted to select pages for Vanta to view; however, no pages are required for Vanta to import users.
- 
Select Allow Access
Please note: If you intend to use Notion as a task tracker in Vanta, please ensure you are selecting the pages that contain your task tracking projects.
⚠️ Note: If a Notion database has multiple data sources, Task Tracking Settings only supports fields from the first data source. Vanta syncs and creates tasks only in that source. Fields from other data sources aren't supported.
 
- 
You should return to Vanta with a successful connection screen.
