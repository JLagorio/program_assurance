# How to Manually Install the Vanta Device Monitor on MacOS via Terminal

Fetched: 2026-11-17

## Article text

This guide provides instructions on manually installing the Vanta Device Monitor on a Mac device using Terminal.
 

## Prerequisites
- 
Administrator permissions on the device. If you do not have administrator access to your computer, please contact the system administrator or your company's IT team. 
- 
Vanta Admin permissions, or assistance from your Vanta Admin to obtain the Vanta Key & pre-generated script. We are unable to give it to you since the key is confidential information. 
​

## Procedure
- 
Open terminal (easiest way is cmd + space bar & search for 'terminal')
- 
Locate the pre-generated script that contains the company Vanta Key & Vanta Region. This can be provided to you by your admin.
- 
A Vanta Admin can locate this within Vanta using the following steps: 
- 
Navigate to the Computers Page <https://app.vanta.com/computers>
- 
Click on the Unmonitored <https://app.vanta.com/computers?tab=unmonitored> Tab
- 
Click on View Setup Instructions

Click on Option 3: MDM and Vanta  Device Monitor
- 
Under For Mac, click on the Copy button to copy the script as is
- 
Paste the script into the terminal, and replace [email protected] with the Vanta Registered email for the device's primary user
- 
The Vanta Device Monitor will run as a silent installation.
