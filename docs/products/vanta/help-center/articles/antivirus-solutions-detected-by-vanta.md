##  Linux Antivirus
- 
Currently, we are not able to detect Antivirus programs for Linux.
Additional Information
- 
Vanta will detect any antivirus solutions that show up in the Windows Security Center.
- 
Windows Security is built into Windows 10 and 11 and includes an antivirus program called Microsoft Defender Antivirus. See this Windows article for information on enabling: Stay protected with Windows Security <https://support.microsoft.com/en-au/office/stay-protected-with-windows-security-ae70cc96-a9cd-4443-a210-e41cb973d3a6>
If you are using an antivirus solution that is not listed on this page, please submit a feature request to [email protected] with your request.
