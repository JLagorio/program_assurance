# Remove a Computer from Monitoring when using the Vanta Device Monitor

Source: https://help.vanta.com/en/articles/11346036-remove-a-computer-from-monitoring-when-using-the-vanta-device-monitor
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

## Prerequisites
- 
Administrator access to Vanta
- 
Administrator/Sudo privileges on the computer

## Procedure
- 
From the device, uninstall <https://help.vanta.com/en/articles/11345408> the Vanta Device Monitor
- 
Search for the original owner on the Computers page, located under the Personnel category. 
- 
Remove the Computer from the Computer page by selecting the three-dot menu and clicking Remove Computer.

- 
If the asset is to be reassigned to another user. In that case, the new owner will follow the process of downloading the Vanta Device Monitor, and the machine will reappear on the computer page under the new owner.
Please note: If an administrator sees multiple computers listed under a user and can confirm that the user does not use multiple devices, likely, a previous Vanta Device Monitor installation was not adequately removed from the device. 
 
- 
Click the Remove computer button to remove the machine from the user. Only do this if the uninstall command does not remove the device from the user's profile. If an administrator performs this action rather than using the uninstall command, the device will be permanently disabled. Please contact [email protected] to re-enable the node key, allowing for future installations.
