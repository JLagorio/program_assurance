# Bulk Update Policies

Source: https://help.vanta.com/en/articles/11345495-bulk-update-policies
Collection: Policies
Fetched: 2026-11-17

## Article text

Save time updating your policies with Vanta's Bulk Update Policies feature. This feature functions as a search and replace, allowing you to update words and phrases across multiple policies and drafts created using the Policy Editor <https://help.vanta.com/en/articles/11345499>.
This function does not currently apply to policies created using the Policy Builder <https://help.vanta.com/en/articles/11345488>.
 

## Bulk Updating Policies
- 
From the left-hand navigation panel, select Policies
- 
From the top right-hand corner, select the More dropdown
- 
Choose Bulk Update Policies

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516770383/2bace54e8f0ed1efa9500759f92f/35310044215572?expires=1794967200&signature=564c2043c332e717d202e03ab7be46591375ff1ea3abf44d4c1e1d554deb30fe&req=dSUmEM55nYJXWvMW1HO4zY790Z2QkBia6Mpyozp2jf0PbeG6syjLhQpil9Z%2B%0AQCsXXiP8Kb7Dk0Kk6xo%3D%0A>
- 
Type in the text you would like to replace. Vanta will search for this text among all policies
​​
- 
Choose from the following options regarding the syntax of your text
- 
Use company name
- 
Case insensitive
- 
Search should be case-insensitive
- 
Match the whole word
- 
The update should only be applied where the search matches the whole word. If not selected, it can be applied to parts of words.
​
- 
If you want to update only drafts, choose 'Updates should be contained to only policies in a draft state. If not selected, this will create draft versions for approved policies.'
​Note: Editing is limited to policies that are in a 'Draft' or 'Approved' state. 
Policies that are 'Pending Approval' must first have the approval request cancelled to return the policy to a draft state before edits can be made. 
​​
- 
Select Next

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516770381/fca0e7237a84e5b64eea87b2e846/13825665199892?expires=1794967200&signature=2714a9d35e17f4f3445565eb3dacd628a2ad3586278594ff071a0ed0b328b6fc&req=dSUmEM55nYJXWPMW1HO4zeREMwZpVItJYVbHLAetkSoxquCwYRkn%2Fs3Fd7Sk%0AWoFHE8LbVQ300YtdAlU%3D%0A>
- 
You will then be notified of how many instances of your defined text will be replaced.
- 
Select Update
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516770382/9dd154af8aa62b5f2dfa9c3640bd/13825659012116?expires=1794967200&signature=ad303f01d45a2b0a5313f771e2c13aff71df49318d86091d2af1ed91a1e33cb7&req=dSUmEM55nYJXW%2FMW1HO4zbDP97IGRyhWEAuRrH0%2F%2Bb2I6BLev8Ks3mXR7C95%0AM%2BAFLOEHqnyZ3fKKWUY%3D%0A>
- 
Select Update when you are ready to make the changes
