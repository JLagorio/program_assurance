## Article text

Vanta integrates with Jobvite to monitor and manage access to your tools. By syncing user access data, Vanta helps ensure that only active employees retain access and that access is promptly removed when personnel leave. This supports automated compliance needs, streamlines access reviews, and powers automated access requests.
 
Estimated setup time: Less than 10 minutes
 

## How It Works
Vanta connects to Jobvite to sync user data on a regular basis. This data supports three key workflows:
- 
Automated compliance tests – Vanta automatically checks that accounts are linked to employees and deprovisioned when personnel leave
- 
Access Reviews – Synced users appear in Vanta’s Access Reviews, where approvers can validate appropriate access, confirm least-privilege access, and provide audit evidence
- 
Access Requests – Entitlements from Jobvite are pulled into Vanta. Requesters can ask for specific access levels, approvers can review with context, and admins can track provisioning
Please note: Vanta connects to Jobvite through Merge.dev <https://merge.dev/>, a secure third-party integration platform.
 

## Use Cases
Connecting Jobvite to Vanta will enable you to:
- 
Monitor and manage personnel access to Jobvite in real time
- 
Ensure only active employees retain access to company systems
- 
Simplify access reviews and support compliance requirements
 

## Requirements
- 
Vanta administrator account
- 
Jobvite administrator account
- 
Jobvite API Key and Secret Key
 

## Connect the Integration
- 
Contact Jobvite Support <https://www.jobvite.com/support/> to obtain your API Key and Secret Key
- 
In Vanta, go to the Integrations page, click Add integration, and search for Jobvite. For help navigating the Integrations page, see Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect Jobvite

## Permissions
Vanta accesses the following data from Jobvite:
 
Vanta can read:
- 
Data about your users
- 
Used to confirm only active employees retain system access
- 
Ensures terminated employees are deprovisioned promptly
- 
Enables Access Requests <https://help.vanta.com/en/articles/11345423-managing-access-requests-in-vanta> to display available users when tracking or assigning access
Vanta can write:
- 
Nothing (Vanta does not have write permissions)
