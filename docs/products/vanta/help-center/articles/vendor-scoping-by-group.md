# Vendor Scoping by Group

Collection: Team Compliance ; Team Compliance › Employee Onboarding & Offboarding
Fetched: 2026-11-17

## Article text

Leveraging groups <https://help.vanta.com/en/articles/11345836> within Vanta can help make onboarding and offboarding personnel a much more seamless process. To make offboarding more efficient for admins, you can now adjust the scope of vendor access for personnel based on the group they belong to.
 

## Adjusting Group Settings for Offboarding
- 
From the left-hand navigation panel, select Personnel 
- 
Select People followed by Groups
- 
From the list, choose the group you would like to edit
- 
From the Offboarding section, Select Access removal

Under Access removal, choose any non-integrated systems and vendors you wish to be included on offboarding task sets. Select Add
 
[image 02]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/1543477598/7c181360cfacb62a70d57d4af38d/Screenshot+2025-05-27+at+1_57_20%E2%80%AFPM.png?expires=1794967200&signature=4f112b09c16eb9238a753ce1ecb3590218683bb1b5a5cc258d6d64fdd095406e&req=dSUjFc15moRWUfMW1HO4zazt9HT008m%2FkbcXNiLVRlGW1CXMTLQ2uJcftS%2Bi%0AnV4j%2F0iafaJsfuepXWc%3D%0A>
 
- 
For integrated systems, we will automatically enforce access removal
- 
Select Save
- 
The selected system will now appear as a system to deactivate the personnel being offboarded.
