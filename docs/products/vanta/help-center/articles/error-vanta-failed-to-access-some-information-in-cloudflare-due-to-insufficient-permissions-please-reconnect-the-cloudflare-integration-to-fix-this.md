## Article text

## Environment Details
When connecting your Cloudflare account to Vanta you may come across the following error:
 
Vanta failed to access some information in Cloudflare due to insufficient permissions. Please reconnect the Cloudflare integration to fix this.
 

## Cause
The connecting Cloudflare account is missing the API permissions required for Vanta to fully connect to Cloudflare.
 

## Resolution
- 
Make sure the steps are followed carefully in the Cloudflare Connect article
- 
Connecting Vanta & Cloudflare <https://help.vanta.com/en/articles/11345752>
- 
Make sure that the connecting account is a full administrator and has access to all API permissions.
