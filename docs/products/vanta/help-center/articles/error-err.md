# Error: “ERR_TLS_CERT_ALTNAME_INVALID” while connecting JAMF Premium Cloud

Source: https://help.vanta.com/en/articles/11345928-error-err
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

When you are a JAMF Premium Cloud Customer, you may see this error appear when connecting it to Vanta
 ERR_TLS_CERT_ALTNAME_INVALID
 

## Cause
- 
This error can appear if you are trying to connect to Vanta using a custom domain. This feature is available to JAMF Premium Cloud customers.
- 
Vanta does not currently support custom domain names for JAMF Cloud Premium.
 

## Resolution
- 
Revert your custom domain back to the JAMf-provided domain, and then use that to connect to Vanta.
