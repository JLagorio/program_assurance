# Vanta Sandbox Mode

Source: https://help.vanta.com/en/articles/11345370-vanta-sandbox-mode
Collection: Getting Started Hub ; Getting Started Hub › Getting Started Guides
Fetched: 2026-11-17

## Article text

Vanta allows users to see a fully built, read-only Vanta instance through Sandbox mode. The Sandbox can be used to learn the product and understand how a fully-formed instance should look and function while you are in the early stages of implementation.
 

## Enter Sandbox Mode
- 
From the top right-hander corner, select the profile icon
- 
Select Enter sandbox mode

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516755742/5f597fb7fffcc1bf809c0fb470f2/35559816652692?expires=1794967200&signature=cc7fde88b7de10f3538a9b12a03d9f9d49b78411a67c5d5ff2b9c58e79e831ff&req=dSUmEM57mIZbW%2FMW1HO4zYRXhIo7q6NgAGmtPtZfhIfee%2BFNJ0zVRubOqJ32%0Ach0uqJZzRAAznS%2BrThE%3D%0A>
- 
Sandbox mode provides access to a fully built Vanta instance. From here, you can explore Vanta's pages, functionality, and tools.
- 
Anything done in the Sandbox will not affect your Vanta instance.
- 
Please note that all of Vanta's features are visible from the Sandbox; if you have questions about any of Vanta's premium features, please contact your CSM.

## Exit Sandbox Mode
- 
To exit Sandbox mode, select Exit Sandbox from the top banner.
