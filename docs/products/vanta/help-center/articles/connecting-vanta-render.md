# Connecting Vanta & Render

Source: https://help.vanta.com/en/articles/11345727-connecting-vanta-render
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Access and Additional Integrations
Fetched: 2026-11-17

## Article text

Render allows customers to connect tools like Vanta using API tokens. By connecting your Render account with Vanta, Vanta is able to make API calls with the token, allowing you to display users in Render within Vanta under the Access page.

## Integrating with Render
- 
In Vanta, go to the Integrations page, click Add integration, and search for Render. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
A pop-up modal will appear; with instructions on creating an API token with Render.

In a new tab, login to your Render account

## Obtaining your Render API Key
- 
From the top right-hand corner, click on your email to open the account menu
- 
Select Account Settings
- 
Select API Keys from the sidebar
- 
Select Create API Key button from the right-hand side.
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516760075/8e82426c03d0639ac56a6e44d03e/22753515168532?expires=1794967200&signature=a66a756fadf41c2f90f66557fdf8d7d509f502e8ada5ece88b1344cf86ac9e73&req=dSUmEM54nYFYXPMW1HO4zZnIqzSJM1U8sOuF%2F3VWYY9s80RYeA0RcuZ5mze4%0AgTYJIQyGRcoRIDXqRQ4%3D%0A>
- 
In the pop-up Modal, name your API Key, and click Create API Key.
- 
We recommend naming the key Vanta so you know what it is linked to.
