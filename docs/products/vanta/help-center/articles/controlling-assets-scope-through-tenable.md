## Article text

Vanta's Tenable integration enables you to control which assets should be pulled into Vanta.

## Assign a tag to Assets in Tenable
- 
Navigate to the Assets page
- 
Select a device to add the tag to
- 
Click Add Tags
- 
Create and apply the new tag to the device
- 
Apply this tag to all of the devices you would like to pull into Vanta

## Edit Permissions
- 
Navigate to Access Control -> Permissions
- 
Select the Vanta permission
- 
Under Objects -> remove All Assets
- 
Add the new tag to Objects
- 
Save
