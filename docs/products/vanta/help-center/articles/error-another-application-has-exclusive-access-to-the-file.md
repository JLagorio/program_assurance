## Procedure
Sometimes, you may see the following error message when trying to uninstall the Vanta Device Monitor from your device: ''Another application has exclusive access to the file <filepath>." Please shut down all other applications, then click retry.
​
Double-check if any of the following services are running on the device:
- 
autoupdater.exe
- 
launcher.exe
- 
lorca.exe
- 
metalauncher.exe
- 
osquery-vanta.ext.exe
- 
osqueryd.exe
- 
vanta-agent.exe
- 
vanta-cli.exe
- 
vanta.exe
 
Terminate any of these services if they are active, and then attempt to uninstall the Vanta Device Monitor again.
