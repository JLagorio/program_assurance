# Current Policy and Policy Editor are not showing the Same Content

## Article text

Administrators may need to update an existing policy, and in the process of doing so, they notice they are given a file to edit that is different from the currently approved policy. This occurs when the currently approved policy is uploaded to Vanta rather than created with the built-in policy editor. Editing and managing policies in Vanta involves different processes, such as handling policies uploaded as PDFs, created using templates, or edited through the built-in policy editor. Each scenario requires its own workflow, as administrators must navigate the conditions for each type of policy to make updates efficiently.
 

## Editing Policies Uploaded as PDFs
If the policy was uploaded as a PDF:
- 
Edit the original document on your computer.
- 
Reupload the edited PDF as a new version of the policy.
- 
During the approval workflow, you’ll be asked if users need to reaccept the policy. To avoid reacceptance, select No when prompted.
