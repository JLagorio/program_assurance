# Deactivate monitoring for a Resource on a Test

Source: https://help.vanta.com/en/articles/11346051-deactivate-monitoring-for-a-resource-on-a-test
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

This article will show you how to deactivate monitoring for individual resources both indefinitely and temporarily.
 

## Deactivate indefinitely
- 
There must be at least one failing resource flagged by the test for you to deactivate the monitoring
- 
Select the eyeball icon with the line through it for the failing item on the test that needs attention:
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516768413/b191bbe462062f52073a71c9d868/27569484095508?expires=1794967200&signature=aa29a24c61b236642ac8ea85a3651c4742db55e9cbe21eca2807b8eb596509d3&req=dSUmEM54lYVeWvMW1HO4zbGDx3omHW8q6XJPq8rZLJSyDCbsaykIogM1od3T%0AxS%2Bu9prqd1phgqk020k%3D%0A>
 
- 
In the pop-up select Deactivate indefinitely. Enter a Reason for deactivating and upload a screenshot as manual evidence (optional), then select Deactivate:
 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516768417/10a521f349f03dad3b15b838faeb/27569484103828?expires=1794967200&signature=d49e570ae55472c9fd12c122281370df1090dcf63a20d60107a5b52f421594d3&req=dSUmEM54lYVeXvMW1HO4zT0olJYUgKy6QZksD7ogUmMPmt2K3jAele8JuWlI%0AKN1fngmgEa3%2F4xK3mhc%3D%0A>
 
- 
Once this is done, if there are no other resources flagged by the failing test, if you refresh it or if it runs again on its own, the test should be in a passing state, and the resource will show under "Deactivated" with the option to reactivate monitoring by selecting the eye icon:
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516768421/7d143fa8dd76636fa07d5d6f9927/27569484108564?expires=1794967200&signature=19baadb021a7c8f34111ecf0110a22bad3c3ae1aac17a7dfc4effa692848b779&req=dSUmEM54lYVdWPMW1HO4zUO9bK%2But2jAEPJ7hbXl797pPs9da29keYgJqk6c%0AAa3ZvJLgvKZ5u4j9Fg8%3D%0A>
 
- 
Please note, if you select Reactivate monitoring you will need to click "Reactivate" in the pop-up to confirm:
[image 04]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516768410/1c101eb799a0853cb5d4d6aa6355/10258348930068?expires=1794967200&signature=c4f55e269fca75ae627b6dbe7ab67e9e8868a582ab9e823f10d0b4a8b9f73f79&req=dSUmEM54lYVeWfMW1HO4zWLlcAZvGXgOjY%2F%2BRCcqapNP7JIYRappMveUbPjI%0A%2BZL6DjIxl0PHZFoWVyQ%3D%0A>
 

## Deactivate Temporarily
Admins can add end dates when deactivating a resource on a test. This gives Vanta Admins more control of flagged resources on tests and the ability to temporarily deactivate or pause monitoring to fit your organization's needs.
- 
In the pop-up select Deactivate until a specified date and input the date you would like monitoring to be deactivated until. Add in a reason for temporarily deactivating and upload evidence(optional):
 
[image 05]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516768430/630af7deec50c8b7178a433d5b73/21388613109268?expires=1794967200&signature=a90f5767a69059215986ced547817856007208c2a94cc720fbbcdb9bf0698bfd&req=dSUmEM54lYVcWfMW1HO4zcxNaXIhl1XP%2FcUIlZWQNd0schJf343sUdtEOI92%0A85k%2BvFL9PSypuPNotOw%3D%0A>
 
- 
Once this is done the resource will show under Deactivated tab with the Deactivated Until date. This will remain deactivated until the selected date, or you have the option to reactivate monitoring manually by selecting the eye icon:
 
[image 06]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516768437/6ef28e4974084c2c2a9662b9df65/27569484117012?expires=1794967200&signature=6ee5a29ea77da5f4134edecdd8c9be8500e1a4112996763f793d1231e4c2b3ca&req=dSUmEM54lYVcXvMW1HO4zcii1RrKMuiDQt0fsM9WuHFECy8rnXNoDSKb1b7n%0ASWOqNPb4BKvdykNGoUM%3D%0A>
