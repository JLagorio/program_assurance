# Create a Custom Document

Source: https://help.vanta.com/en/articles/11346017-create-a-custom-document
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

Custom documents help you organize and track important compliance information. Whether you're creating a new document, linking it to a control, or making edits, the process is straightforward. Follow the steps below to manage your custom documents efficiently.
 

## Creating Custom Documents
- 
Select the +Add document button in the upper right-hand corner of the Documents page
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766915/a039847734406d1d99a2f08538bb/27576699620756?expires=1794967200&signature=3d10d19493f0afaf5a195498ef38d79f6b733247748e3fa89aedf7f63e3942e0&req=dSUmEM54m4heXPMW1HO4zU9hoFIVv2UvMMVEnTKbSoZabLXDjwr3KBq%2F5Awz%0A37iYLCK%2BanCbqO20eDw%3D%0A>
 
- 
In the box that appears on the screen, fill out all applicable fields.
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766908/f26ddad93cba4fdefe297c8e8df1/19440671428628?expires=1794967200&signature=02fb6fa72857dadbeee6337a448bdf79fd67935c9948ae720eb006d748fde708&req=dSUmEM54m4hfUfMW1HO4zbPD8gD3wGBgnN7whQTta6cInR1kXPlf3QVswkj9%0A9xsOit%2BHKFNIsVaTJWo%3D%0A>
 
- 
When done, click the Create document button on the bottom.
- 
Next you'll be brought to the Add document to control window
- 
If the Add document to control modal doesn't appear automatically, you can open it by clicking More in the upper right corner of the new document and selecting Add control
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766905/e9808425824aeed33c9a3b3a024e/26389860077332?expires=1794967200&signature=ca4ae92cfde27569b7d09540616b25abffdc606969566cfc92da7a7ed309f014&req=dSUmEM54m4hfXPMW1HO4zaUrIW0YwNAFKkhIQjeIoItc7CE7Y8Cv0aqZ1bvm%0AxQFUr4mWUAvsZyGPz4I%3D%0A>
- 
In the Add document to control modal, search for the name of the desired Control
- 
You can use the Framework dropdown to narrow down the search results
 
[image 04]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766907/f84e86c4abac4cc73312fd0c00dc/26389876355860?expires=1794967200&signature=688007a3d18b53647c01cb14f4fbe3d5e7419f32501a4af26c0286691b4528d5&req=dSUmEM54m4hfXvMW1HO4zdNxJ%2BNfO4BpVGSvYuUFIHBA6w5kacql7JGsO3xs%0A2MES2htqsrSIlPIrdMU%3D%0A>
- 
When you locate the desired Control, select the name and click the Add button on the right
 
[image 05]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766932/8bf13ebedbe530c9188a33e23b5b/26389860108564?expires=1794967200&signature=2eef6a2a191cd6f23bc6178dbc8af8919d8062bdd893e18b2c34696c2aafc305&req=dSUmEM54m4hcW%2FMW1HO4zVkfeLsJUfaigZpTeVtbHNNUpZiNxVQNrQntq94Q%0Ah%2FBkCA2goYh8XV9Db7Q%3D%0A>
 
- 
To add files to the new document, select Upload under Add a new document
- 
If the document is linked in another platform, select Add Link and paste the URL into the open field.
 
[image 06]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766928/4fa50114b7761717786606e3ea5d/26389876382228?expires=1794967200&signature=ed1ca52f5874383dac89e5fae19a84529430f469b48bab5f2435f5345fe8f2b2&req=dSUmEM54m4hdUfMW1HO4zR3YP15QZEW3o3%2FSB6SpQOtuEvLZOPcjzdPrDMb2%0AalZBOIqugna27S4hPMw%3D%0A>
- 
Choose the file you would like to upload
- 
Add a description and the document's effective date
- 
Select Upload

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766929/4706748c212b419c9fffdf3c8bc5/26389860135572?expires=1794967200&signature=3a2c9b2c071ab8c02815e04b187171b2ecd3993ac26799ed12f20caee7811888&req=dSUmEM54m4hdUPMW1HO4zZeGwErXyLY6lEuqVB8dHs9cchPnsUICEUcejy1F%0A5rqLoCPwXqwrG1v79LA%3D%0A>
 

## Editing Custom Documents
- 
Click on the More button in the top right corner from the document's page.
 
[image 08]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766934/9dc0fcb2d4a3a19c12f9d8a7e589/15764410688276?expires=1794967200&signature=2cbc44d8926d7769360497292f6cf1f967ca313a90a7dd316cdd5bbc7f1f660d&req=dSUmEM54m4hcXfMW1HO4zeIxMnCn753GDdgQI1Xu6FvXAkJmq7pyGrLDnmnl%0AWw4G%2BEvZseuJnEycLsY%3D%0A>
 
- 
Select Edit Custom document from the dropdown.
- 
On the box that appears on the page, fill out all changes to the Custom Document.
[image 09]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516766943/45b949365ceee776816edcf7b8ce/12651286266260?expires=1794967200&signature=45109734e5fd2d7030db2e5231bf3257190269d706d892e17d6eb9bbb70f7a90&req=dSUmEM54m4hbWvMW1HO4zdR0XaCaflnaehKPU1pPs4YevgpSTUtk%2Bc1ooX8a%0Aejlqy5%2BSDoMWvKuT3CA%3D%0A>
- 
When done making changes, click the Save button on the bottom
