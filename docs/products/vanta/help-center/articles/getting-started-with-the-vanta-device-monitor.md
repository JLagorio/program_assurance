# Getting Started with the Vanta Device Monitor

Source: https://help.vanta.com/en/articles/11345407-getting-started-with-the-vanta-device-monitor
Collection: Continuous Monitoring ; Continuous Monitoring › Vanta Device Monitor
Fetched: 2026-11-17

## Article text

If your organisation is not currently working with an MDM (Mobile Device Manager), the Vanta Device Monitor is an excellent option for performing security checks on your employees' devices. It can be installed on all company computers to continuously monitor compliance.
 
This software uses OSQuery to detect specific settings and applications installed on devices. The Vanta Device Monitor is a lightweight program designed to run in the background of your computer. It has a minimal performance impact: once you install the app and register your device, you shouldn’t notice any difference.
 
The Vanta Device Monitor is read-only, meaning it will not modify any settings on your machines. It has limited functionality for reading data (Vanta deploys a modified version of osquery that excludes tables that we find dangerous). The Vanta Device Monitor does not read sensitive information, such as passwords, emails, or browsing history. 
 

## Installing the Vanta Device Monitor
- 
Employees should download the Vanta Device Monitor as part of their security tasks. Once they log into https://app.vanta.com/onboarding <https://app.vanta.com/onboarding>, they will be instructed to download the Vanta Device Monitor for their operating system.
