## Article text

The Computers page serves as an overview of the computers that your company is monitoring with the help of the Vanta Device Monitor or a supported MDM (mobile device manager).
​

## Computers with the Vanta Device Monitor Installed
Once the Vanta Device Monitor has been installed on your employee's computers, a list will populate. Each row includes information about each of your employees' computers. Each user will have a check mark or an X for each security measure column.
 

## Accessing the Computers Page
- 
Select Computers from the left-hand navigation panel
- 
From here, you will find a list of assets being monitored and tracked within Vanta
- 
Clicking a specific User name will show you additional information related to the person, such as their onboarding status, what access they have, offboarding status, and computer information

## Column Information
A green check indicates that the asset's security protocol has been met. An X indicates that the asset does not meet that security protocol.
- 
Owner: The owner of the asset
- 
Monitoring: What is monitoring this asset?
- 
OS: What OS is the asset running on?
- 
PW: Does this asset use a password manager?
- 
HD: Is the hard drive encrypted?
- 
AV: Is an anti-virus installed?
- 
SL: Is screen lock enabled? (Does the device lock after inactivity)
- 
Last Check: When was the last time this asset was scanned by the Device Monitor or MDM

## Reassigning or Removing a Computer
- 
Select a specific name from the list
- 
From the Computers tab, expand the Monitored By dropdown of the device you wish to reassign/remove
- 
Select 'Reassign Owner' to reassign the device to a different user, or select 'Remove Computer' to remove the device from monitoring in Vanta.

## Exporting Computer List
- 
To export the list of your assets, click Export from the top right-hand side of the page.
- 
This will initiate a download of the .csv file containing the computer list.

## Automated Vanta Device Monitor Install with MDM
- 
If you do not want your employees to self-install the Vanta Device Monitor, you have the option to run a script for automated installation on your MDM-provisioned computers. That script can be located on the Use your MDM system to install the Vanta Device Monitor at the bottom of the page.
