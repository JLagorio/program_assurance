# How to Configure JumpCloud - Screen Lock

Source: https://help.vanta.com/en/articles/11346041-how-to-configure-jumpcloud-screen-lock
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

When using JumpCloud, Vanta will check to ensure the Screen Lock policy is configured. The name does not matter in this case.
 

## Create a Screen Lock Policy
- 
Log in to the JumpCloud Administrator Portal and then go to "Policy Management"
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516767836/3d27ac12f7077d86b6b6aa283623/10493168360980?expires=1794967200&signature=f502d83532ad1ccc79e2486b4bcd794e544fe8a97b53afe0d40cf74ca6633618&req=dSUmEM54molcX%2FMW1HO4zeVoicAxh4Iym3zhH%2BI2Odm9hEMkEmxwp9JVrRa%2B%0A1SJ25Pe%2F3APi99IxlZg%3D%0A>
 
- 
Look for a green + button that will allow you to add a new policy.
 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516767846/7d7d7c7f3526538c02bd9737f57f/10493193229844?expires=1794967200&signature=631f30e2f8293536bde0b27cccfa660c6775c207f6129a48b345522dd38b9f38&req=dSUmEM54molbX%2FMW1HO4zfltm0Oa%2FAJgVVfPiwCHDZPquQhsbQjadOQO4gkz%0ASOOl6fNj4sg%2BNYFMUMg%3D%0A>
- 
Select Windows, Mac, or Linux, then search for "Lock Screen".
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516767847/7d774114f426a43ab84c2c7f37e5/16323241825684?expires=1794967200&signature=fcdbb62f9bd8fbe32193f4a1482778fcedae7567937b04208d982f59988d4594&req=dSUmEM54molbXvMW1HO4zYVn4vTecWvjfp%2BYDDLNA5%2BJbAxJ%2FJviUQt5JyX1%0AIp2KBeGlp4BMgf%2FIANA%3D%0A>
 
- 
The policy name can be left as default as it does not affect it.
- 
Set a timer function for the Screen Lock policy to take effect.
- 
Note: The timeout is in seconds.
- 
Note: The max timeout that Vanta will accept is 60 minutes or 3600 seconds.
 
[image 04]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516767840/f396fe02049231dcc690276f55f1/16323277614996?expires=1794967200&signature=e8249a833a668650ce5eb62569ba5eaf475972074602ba945e68d5995d68d4ab&req=dSUmEM54molbWfMW1HO4zSBqCEMZYPDWH0dfAIpPBv9l%2Fzw0onUa26KzIwtZ%0A9qqfPBvI8B3n3ixOK6E%3D%0A>
[image 05]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516767863/18b97ad3d8ba6c3c023a228a2bc7/16323412447508?expires=1794967200&signature=92248af8527e035188f3ee5128a2e4403482845898d520fafb84dfa01ca6965c&req=dSUmEM54molZWvMW1HO4zapDjfqjomtipcQ4jo7aLEIPz8Qrm2dBG%2BX1M5ND%0ABOflDLEKWV5Qz2EdEMU%3D%0A>
 
- 
Afterwards make sure you select a device group and then save the policy. If you save the policy without saving it to a device group then the policy will have no effect.
