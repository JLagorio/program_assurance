# Edit Unmonitored Accounts Offboarding List

Source: https://help.vanta.com/en/articles/11345961-edit-unmonitored-accounts-offboarding-list
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

When offboarding a user, Vanta will automatically add all integrated vendors (monitored accounts) and ALL non-integrated vendors (unmonitored accounts) to the offboarding task set for employees. The list of non-integrated vendors can be edited by a task set for groups and removed from the offboarding process.
 

## Procedure
- 
Go to Personal > People > Groups
- 
Select the desired group
- 
Under Offboarding select, Access removal
- 
Edit Access removal of non-integrated systems
