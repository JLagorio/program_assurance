# Vanta and Gorgias

Source: https://help.vanta.com/en/articles/11345737-vanta-and-gorgias
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Access and Additional Integrations
Fetched: 2026-11-17

## Article text

Gorgias allows customers to connect tools like Vanta using an API Token. By connecting your Gorgias account with Vanta, Vanta can make API calls as the app, allowing you to connect to find people and use onboarding/offboarding dates from your HR system.

## Prerequisites
- 
Vanta leverages Merge, a third-party platform, to pull in your data from Gorgias. See their documentation <https://docs.merge.dev/integrations/ticketing/gorgias/provider-interactions> for details on the API interactions used.

## Procedure
- 
Navigate to the Integrations Page <https://app.vanta.com/integrations> in Vanta and locate the Gorgias connector
