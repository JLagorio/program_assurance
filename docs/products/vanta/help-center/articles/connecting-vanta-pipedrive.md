## Article text

Pipedrive allows customers to connect tools like Vanta using OAuth. By connecting your Pipedrive account with Vanta, Vanta can make API calls as the connecting user, allowing you to display users in Pipedrive within Vanta under the Access page.

## Integrating with Pipedrive
- 
In Vanta, go to the Integrations page, click Add integration, and search for Pipedrive. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
A pop-up modal will appear; select Connect Pipedrive.
- 
If you are not logged in, you will be asked to log in to Pipedrive first.
- 
If you are logged in, you will see the below screen asking you to "Allow and Install" the Vanta App.
