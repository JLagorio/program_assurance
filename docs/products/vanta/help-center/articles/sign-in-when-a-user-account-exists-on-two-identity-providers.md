# Sign in When a User Account Exists on Two Identity Providers

Source: https://help.vanta.com/en/articles/11346002-sign-in-when-a-user-account-exists-on-two-identity-providers
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

When an organization has two Vanta domains, or a user is present in two different identity providers on two different domains, they will not be able to sign in using an identity provider. This means that the SSO sign-in options will not work (Google, Microsoft, Okta, OneLogin). The user will need to use the sign-in with magic link option:

## Steps
- 
When signing into Vanta, first enter your email address
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516765471/3cb62470ed4630103105ab4322a7/25115636775956?expires=1794967200&signature=5718d0a2b192783683cb1c3cb07b3416a20662a6ef1cdd6b45ed51841b482ca5&req=dSUmEM54mIVYWPMW1HO4zeCC8KBI0SmxwbXpeDXM8d%2FB3gU8rkxrdaq7zxYd%0A%2FaqDDEVw14fZnv3wfk0%3D%0A>
 
- 
Next, select Send me a magic link
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516765484/b03e1645108111d75f9c6dfaefe6/25115636772116?expires=1794967200&signature=19747b9f6ae0e5003f10cd218cf7dca549e40845647e09fd3d7fb780e33a4b4d&req=dSUmEM54mIVXXfMW1HO4zQlUtD5LH87ZPh5NZbBK1YfBXt2abxMBbGbNj8Sy%0AMAyc0Sa4xnZvYrdMnXk%3D%0A>
 
- 
Once this is selected, you should see a pop-up confirming the email has been successfully sent
- 
You should receive an email from [email protected] shortly afterward. If you do not see it in your inbox, check your spam folder. Click the Click here link to be taken to the sign-in page
- 
This page will allow the user to decide which Vanta instance they wish to sign into
