## Article text

Vanta integrates with Xero to monitor and manage access to your tools. By syncing user access data, Vanta helps ensure that only active employees retain access and that access is promptly removed when personnel leave. This supports automated compliance needs, streamlines access reviews, and powers automated access requests.
 
Estimated setup time: Less than 10 minutes
 

## How It Works
Vanta connects to Xero to sync user data on a regular basis. This data supports three key workflows:
- 
Automated compliance tests – Vanta automatically checks that accounts are linked to employees and deprovisioned when personnel leave
- 
Access Reviews – Synced users appear in Vanta’s Access Reviews, where approvers can validate appropriate access, confirm least-privilege access, and provide audit evidence
- 
Access Requests – Entitlements from Xero are pulled into Vanta. Requesters can ask for specific access levels, approvers can review with context, and admins can track provisioning
 

## Use Cases
Connecting Xero to Vanta will enable you to:
- 
Monitor and manage personnel access to Xero in real time
- 
Ensure only active employees retain access to company systems
- 
Simplify access reviews and support compliance requirements
 

## Requirements
- 
Vanta administrator account
- 
Xero administrator account
 

## Connect the Integration
- 
In Vanta, go to the Integrations page, click Add integration, and search for Xero. For help navigating the Integrations page, see Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect Xero
- 
You’ll be redirected to the Xero login page
- 
Log in with your Xero credentials (if prompted)
- 
On the authorization screen, select Allow access

## Permissions
Vanta accesses the following data from Xero:
 
Vanta can read:
- 
Data about your users
- 
Needed to confirm that only active employees retain system access and that terminated employees are deprovisioned promptly. In Access Requests <https://help.vanta.com/en/articles/11345423-managing-access-requests-in-vanta>, this allows Vanta to display available users when tracking or assigning access.
Vanta can write:
- 
Nothing (Vanta does not have write permissions)

## Troubleshooting FAQ
“I got a connection error in Vanta during the linking flow.”
- 
Likely cause: Xero enforces a limit on the number of connections allowed. If this occurs, the limit has been reached. Vanta is working on increasing this limit.
