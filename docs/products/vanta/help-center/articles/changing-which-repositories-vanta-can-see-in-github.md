# Changing which Repositories Vanta can See in Github

Source: https://help.vanta.com/en/articles/11345931-changing-which-repositories-vanta-can-see-in-github
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

## Prerequisites
- 
Administrator access on GitHub
 

## Adding a new Repository
- 
Sign in to GitHub
- 
Click on your profile picture on the top right
- 
Click on Your organizations
- 
Scroll down and Click Applications
- 
Select Configure for Vanta GitHub Integration
- 
To Add new repositories to monitor in Vanta, click Select Repositories
- 
Search for the repository you want to add and then click on it
- 
Click Save
 

## Removing a Repository
- 
Sign in to GitHub and click on your profile picture on the top right
- 
Click on Your organization
- 
Scroll down and Click Applications
- 
Select Configure for Vanta GitHub Integration:
- 
Scroll down to repository access, click the X on the right of the repo you want to withdraw from monitoring in Vanta, and click the green Save button
