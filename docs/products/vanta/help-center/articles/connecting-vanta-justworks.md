## Article text

Justworks is designed to help you manage human resources tasks, such as payroll, staffing, benefits, and healthcare enrollment.
To authenticate your Justworks account, you will need to login to Justworks and authorize the integration in the linking flow.

## Prerequisites
Please ensure you fulfill all the requirements to set up the integration:
- 
You are an Administrator in your company's Justworks instance, or someone has shared their access with you.
- 
Your company is on an active paid plan with Justworks

## Integrating Vanta and Justworks
- 
In Vanta, go to the Integrations page, click Add integration, and search for Justworks. For help navigating the Integrations page, see Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect
- 
Click I am an admin
- 
You will need to verify you are an admin with Justworks in order to proceed
- 
Vanta leverages Merge, a third-party platform, to create the connection between Vanta and Justworks

Merge is a API aggregator <https://www.merge.dev/> used by Vanta to collect data from certain HRIS, Task Trackers, and Access systems. Merge encrypts all of your data and provides Vanta read-only access or Access system. Merge provides write access to certain Task Tracker Systems so that you can create tasks within Vanta. You can learn more about Merge and its security practices here <https://www.merge.dev/security>.
