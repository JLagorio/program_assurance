# Error: “Vanta Device Monitor Setup Wizard Ended Prematurely”

Source: https://help.vanta.com/en/articles/11345998-error-vanta-device-monitor-setup-wizard-ended-prematurely
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

When installing the Vanta Device Monitor on a Windows device, the following error is encountered: 'Vanta Device Monitor Setup Wizard Ended Prematurely.'
 

## Resolution
- 
Use the steps in the Microsoft article below to set your default browser to Chrome https://support.microsoft.com/en-us/windows/change-your-default-browser-in-windows-10-020c58c6-7d77-797a-b74e-8f07946c5db6 <https://support.microsoft.com/en-us/windows/change-your-default-browser-in-windows-10-020c58c6-7d77-797a-b74e-8f07946c5db6>
- 
Restart your device
- 
Download a fresh version of the Vanta Device Monitor https://app.vanta.com/downloads <https://app.vanta.com/downloads>
- 
Right-click on the download and select Run as Administrator
- 
Follow the prompts
If the above option does not work, you can install the Vanta Device Monitor using the command line. 
- 
Use the steps in the article below to install using the command line for Windows: How to install Vanta via a command line on Windows <https://help.vanta.com/en/articles/11346047>
