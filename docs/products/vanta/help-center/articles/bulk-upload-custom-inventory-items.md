# Bulk Upload Custom Inventory Items

Source: https://help.vanta.com/en/articles/11345483-bulk-upload-custom-inventory-items
Collection: Continuous Monitoring ; Continuous Monitoring › Inventory
Fetched: 2026-11-17

## Article text

Inventory items that exist outside of the services you have integrated in Vanta can be manually added individually or through a bulk upload. The bulk upload process allows you to save time and add multiple items simultaneously rather than one by one.

## Bulk Uploading Inventory Items
- 
From the left-hand navigation panel, select Inventory 
- 
Select All Custom Items
- 
Select the Add Item button from the top right-hand corner and choose Import Custom Items

Click Download Excel Template, and use this to create a file for uploading
- 
The template includes the following columns
 | 
Identifier | 
Description | 
Contains user data? | 
Contains EPHI data? | 
User data stored | 
Owner email
- 
Once you have completed the template, click the + button and upload the file back into Vanta
