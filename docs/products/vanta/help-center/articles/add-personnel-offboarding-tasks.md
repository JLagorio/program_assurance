# Add Personnel Offboarding Tasks

Fetched: 2026-11-17

## Article text

Properly offboarding personnel is essential to maintaining your organization’s security and compliance posture. Ensuring that access to systems, applications, and vendors is removed in a timely and documented manner helps reduce security risk, protect sensitive data, and maintain audit readiness. Vanta streamlines this process by automatically generating offboarding tasks and tracking completion across your organization.
 
When you offboard personnel in Vanta, the offboarding task set automatically includes:
- 
All integrated vendors (monitored accounts)
- 
All non-integrated vendors (unmonitored accounts)
Offboarding tasks are managed at the group task set level. Any changes you make will apply to personnel assigned to that group, based on the effective date configured.
- 
Navigate to Personnel
- 
Select People
- 
Click Groups
- 
Select the three dots next to + Add Group
- 
Click Manage task sets

Click Offboarding.
- 
To add a custom task:
- 
Select Custom offboarding task
- 
Click Add
- 
Click + Create a custom offboarding task
- 
Enter the task details
- 
Click Create​
- 
Toggle the new task on
- 
Select the task
- 
Click Set date to define the effective date
The custom offboarding task will apply only to personnel who started after the selected date.
- 
Click Save and then Save again in the dialogue box

### Additional notes
- 
Integrated vendors (monitored accounts) are automatically included in offboarding.
- 
Non-integrated vendors (unmonitored accounts) can be adjusted within the task set.
- 
Changes to task sets do not retroactively apply to personnel who started before the selected effective date.
