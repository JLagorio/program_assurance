# Bulk Removal of the Vanta Device Monitor

Source: https://help.vanta.com/en/articles/11345960-bulk-removal-of-the-vanta-device-monitor
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

## Prerequisites
- 
Administrator access to Vanta
- 
Confirmation that the device will not be given to another employee

## Procedure
- 
Sign in to Vanta
- 
Head to the Computers page <https://app.vanta.com/computers>
- 
Set the results to 100 per page 
- 
Use the status filter to filter by last check over 14 days ago (this is optional and useful if you want to see all devices that may not have been checking in for 2+ weeks)
- 
Click on the checkbox next to owners; this selects all of the devices; feel free to unselect any you do not wish to do this on
- 
Select Disable Vanta Device Monitor

- 
We recommend uninstalling the Vanta Device Monitor from the end devices first. If the device still appears in Vanta, then these steps should be taken as the following action.
Please note: This does not uninstall the Vanta Device Monitor from the end device; instead, it stops the device from being monitored and checked in. An administrator or the end user is still responsible for uninstalling the Vanta Device Monitor.
