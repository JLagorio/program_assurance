## Additional Information
- 
We do not consider the macOS keychain a password manager, as it's preinstalled with all macOS installations and there's no way to confirm its use.
- 
Desktop Apps that have been sunset will continue to be detected by the Vanta Device Monitor while installed, but may no longer function as expected. It's recommended only to use apps that are supported and in use.
- 
If you are using a password manager not listed on this page, please submit a feature request to [email protected] with your request.
