## Github Connection Troubleshooting
When connecting GitHub repositories you may run into a situation where you selected 5 repositories but only 4 show up within Vanta.
 
The highlighted archive below is marked as Archived in Github.
 
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763665/914c036d2f562d93c5fe19bf3928/14774221808148?expires=1794967200&signature=42a842c16968d198405d4463efc8edfb964cb151c1941e7ab780280022547b4c&req=dSUmEM54nodZXPMW1HO4zZsLEhYHG2BjvaXwcII9IzYfEn2A8W0pdXXyMxID%0A4BvpdI3H2imaz3AWTqs%3D%0A>
 
Upon connecting to Vanta we see the GitHub Repository was skipped:
 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763664/b7bc50859059161241c7d6d698ea/14774253909268?expires=1794967200&signature=b94cc31e80a3bd7d6da2d140aabe6ceb6e1f790eb036ebbd5df9564cff8a7e1c&req=dSUmEM54nodZXfMW1HO4zRvlnHVdUHaWQjO%2B6ToNL%2B7H86VLxbd3f%2FXMnwf6%0Aed8OISw6QEUiWULt03k%3D%0A>
 

## Cause
Github Repositories marked as "Archived" will not be pulled into Vanta
 
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763676/e984e2a75a787912f94c4d30adae/14774181329684?expires=1794967200&signature=6b666d62f1f6a7d8e515b032456265b4be3062b66355e15937717e0896bef9bd&req=dSUmEM54nodYX%2FMW1HO4zQupDZcAcTntAm%2Br2PXDuKShuE2z0RnGL939FyXT%0ABNyPdsY4aK%2FIL%2FsWgOQ%3D%0A>
 

## Resolution
- 
Go to the archived repository on Github
- 
Go to Settings
- 
Select "Unarchive this repository" to make it show up as an option in Vanta.

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763663/dc925464a0bbb33db30ef6196606/14774258203156?expires=1794967200&signature=9fc7cbb447f8f7f32e512d07f5f95102d4f3af04b0a985e362494f6c476cd523&req=dSUmEM54nodZWvMW1HO4zbZOuITTnZ%2BG%2BGd6Ttb2c6HG6Mq0as%2Bq09gmxT9k%0Ae1%2B6PZMG8hh3EHlKuAM%3D%0A>
