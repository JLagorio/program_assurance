## Article text

Box allows customers to connect tools like Vanta using OAuth. By connecting your Box account with Vanta, Vanta can make API calls as the connecting user, allowing you to display users in Box within Vanta under the Access page.

## Integrating with Box
- 
In Vanta, go to the Integrations page, click Add integration, and search for Box. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect
- 
a pop-up modal will appear; choose Connect Box
- 
Vanta will request access to your Box account; select Continue
