# Adjusting Personnel Start Dates when using an Identity Provider

Source: https://help.vanta.com/en/articles/11345955-adjusting-personnel-start-dates-when-using-an-identity-provider
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

Many organizations use an HR integration to pull in accurate start/end date data; however, if you do not use a HRIS platform, or use one not currently supported within Vanta, your Identity Provider will be used as the source of truth for Start and End dates. In some cases, this date may need to be revised.
 

## Adjusting the Start Date
- 
Due to limitations on creating accounts in Identity Providers like Google or Okta, the employee's start date in Vanta will align with the date the account was created in the IdP. If this does not align with their actual employment start date, you can manually adjust this from the people page in Vanta.
 

## Process
If the date that is reflected in Vanta is not the accurate start date for this employee, you can:
- 
Navigate to the employee on the People <https://app.vanta.com/people/people> page, click on their name, then click the pencil icon on the right of the employee start date

- 
This change will immediately take effect for that person. When the time comes for offboarding, Vanta will continue to look to the Identity Provider for the end date.
