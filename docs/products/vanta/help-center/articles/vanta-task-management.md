## Article text

With Task Tracker integrations, admins can create tickets straight from Vanta and put them into supported task trackers.
What will the two-way integration populate in the respective platforms? 
- 
Users now see a box at the top of a test details page saying Create a ticket
- 
When creating a ticket, they can set information such as Project, Assignee, and Description
- 
Vanta will populate all relevant info into the ticket, like what’s failing and how to fix
- 
Users can create one ticket for the whole test or individual tickets per failing test items
- 
Vanta will reflect the assignee and status of the ticket on the test page
What task trackers have two-way functionality within Vanta?
-

## Connecting Task Trackers & Vanta
- 
From the left-hand navigation panel, select Integrations 
- 
Open the Available tab
- 
Choose Task Management

## Creating a Task
- 
Open the Tests page from the left-hand navigation panel, and open a test by clicking on it
- 
From the Tasks section, you will see the option to leverage your task tracker integrations
- 
Choose the integration you would like to use, and then select Create
