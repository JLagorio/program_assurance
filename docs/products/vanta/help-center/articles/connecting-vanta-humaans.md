## Integrating with Humaans
- 
In Vanta, go to the Integrations page, click Add integration, and search for Humaans. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
a pop-up modal will appear; select Connect Humaans.
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761253/18f94e95ea2b105c3ad0b2d42873/18479327050004?expires=1794967200&signature=ae5f4aa44fa7267690a531c502244b61fd4093378123b53acc0634623cb804a8&req=dSUmEM54nINaWvMW1HO4zbFvcMlcHFuO%2BBXOH8O4wcb6lCl2qfhS5IpoMUid%0AUWwqLY%2FRlRQCGENTyHM%3D%0A>
- 
Vanta will request access to your Humaans account; select Continue 
[image 02]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761257/cfbd6e193a7e42a28c35735ec069/18479341043988?expires=1794967200&signature=9323fc710efd02a048841c0e665119f58e209d360ec5a66713c19232d42e9864&req=dSUmEM54nINaXvMW1HO4zUFyFf8wQRN7%2B1Kop%2Fx2ZPQgTefN8o6I9rRdkm%2BI%0A2EaL%2FXkMKRtHt%2Bm1S2M%3D%0A>
- 
The pop-up modal will ask for an API key. Keep this modal open.
- 
In a new tab, login to your Humaans account

## Obtaining your Humaans API Key
- 
From the top right-hand corner, select the three stacked dots icon to open the account menu
- 
Select API Access Tokens
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761261/e053349fe4f0850e0e7e82ce61dd/18479320864276?expires=1794967200&signature=34a7e23399e00a0b234e7c6a20da8aa8451c570ff6d9f25404cfd726be7e352e&req=dSUmEM54nINZWPMW1HO4zQBzd%2FEEmHBLZghaM5mSVm07x%2Bloebzjnv%2BRKbhp%0AMECQOhUp7mFeoighlNM%3D%0A>
- 
Select Generate New Token
[image 04]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761260/784b88c2b7afb42345646cef51be/18479334387732?expires=1794967200&signature=87df73ec50f79208677b2d4d647ad651908bf157462005ab04db73126ed9143c&req=dSUmEM54nINZWfMW1HO4zT1EQjPX3aMBDYdr8Ux4GdKwtGPGl22Nxhc8vorp%0Ar0s%2F1ITTCclcvj8H5LI%3D%0A>
- 
Label the API token (use a label to help you identify the purpose, such as Vanta)
- 
Select  View Public Data and View Public and Private Data for the scope
 
[image 05]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/1638815785/a5d152f981da24ad4a9a266a2b12/Frame+1.png?expires=1794967200&signature=c42746cfc84ef66134bca7bc5adc5a13cb7de20abd83843220fccf11a919831f&req=dSYkHsF%2FmIZXXPMW1HO4zQNyJQOgh2OXHvZbaH9ttx%2BuAzNQM9Kil4vJ0BQZ%0Ad6CuE5d07TVT93pXk48%3D%0A>
 
- 
Copy the API Key, and past it back into the pop-up modal in Vanta
- 
Select Submit
[image 06]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516761277/d51c069313de90b231cd31ca0881/18479296407060?expires=1794967200&signature=a63ceabda0a02eb6d19bee584a1107e0e947926a7e1cc06b173b90e48ac88954&req=dSUmEM54nINYXvMW1HO4zbAKeO0m3ZZ3gh9a19r4tb%2FqWq%2BxEwlfjClwfogu%0AtgQh%2BpTSTcceYQRCZ78%3D%0A>
- 
Select Continue
- 
Select Finish
- 
People Import settings
- 
You can choose which people you’d like to import from Humaans. If you’re in audit, make sure to import people who’ve left and set the date to the beginning of your audit period.
- 
Select Save
