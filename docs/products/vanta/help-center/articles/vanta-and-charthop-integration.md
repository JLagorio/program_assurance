# Vanta and Charthop Integration

Source: https://help.vanta.com/en/articles/11345670-vanta-and-charthop-integration
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › HR Systems (HRIS)
Fetched: 2026-11-17

## Article text

Chathop allows customers to connect tools like Vanta using an API Token. By connecting your Charthop account with Vanta, Vanta is able to make API calls as the app, allowing you to connect to find people and use onboarding/offboarding dates from your HR system.

## Prerequisites
- 
Vanta leverages Merge, a third-party platform, to pull in your data from Charthop. See their documentation <https://docs.merge.dev/integrations/hris/charthop/provider-interactions> for details on the API interactions used.

## Procedure
- 
In Vanta, go to the Integrations page, click Add integration, and search for ChartHop. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
-
