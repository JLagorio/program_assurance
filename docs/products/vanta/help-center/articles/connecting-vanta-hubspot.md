## Article text

✅ Feature availability: This integration is now available for Vanta Government <https://www.vanta.com/solutions/public-sector> customers. 
HubSpot allows users to connect tools like Vanta using OAuth2 <https://developers.hubspot.com/docs/api/working-with-oauth>. Users can configure a HubSpot account and connect with Vanta, enabling Vanta to make API calls on behalf of the app.

## Integrating Vanta & HubSpot
- 
In Vanta, go to the Integrations page, click Add integration, and search for HubSpot. For help, see our guide to the Integrations Page <https://help.vanta.com/en/articles/11345761-integrations-page>.
- 
Select Connect.
- 
Select Connect HubSpot

Connect your HubSpot account.
- 
You will be redirected back to Vanta.
- 
If you return to the Connected tab and filter by HubSpot, you will see the HubSpot integration active.
