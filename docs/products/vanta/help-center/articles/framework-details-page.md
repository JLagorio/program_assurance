# Framework Details Page

Collection: Getting Started Hub ; Getting Started Hub › Navigation
Fetched: 2026-11-17

## Article text

Each Framework you are working towards under Vanta has an overview page that helps you understand what progress has been made and what action items need to be completed.
- 
From the Frameworks page, you will see a list of the Frameworks you are working towards.
- 
Columns include:
- 
Evidence completion: Percentage of evidence that meets the requirements of the Framework
- 
Control completion: Percentage of controls that are passing
- 
Audit ends: Audit end date
- 
Status: Framework status
- 
Domain
- 
Click the three-dot menu to delete (if it is a custom Framework <https://help.vanta.com/en/articles/11345497>) or snooze the Framework. <https://help.vanta.com/en/articles/11345391>

## Framework Requirements
The Framework details page will show you the full list of controls and framework completion progress and detail the evidence readiness to ensure the control is passing.

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516755671/3beb772b0bba9561e5073610b5cd/35776759333908?expires=1794967200&signature=e47c66c26f81bbb1820c930da15ff86d0be722928f121577d42929005c2de69f&req=dSUmEM57mIdYWPMW1HO4zbao7%2BDb%2FvQ0DV6hNRjl8oaJTNli%2Fql7TlApXwZR%0Ae6al163HiPDx%2FiVDfW4%3D%0A>
 
- 
To make adjustments to the Framework, you can select + Create new control to add custom controls <https://help.vanta.com/en/articles/11345435>, or
- 
Select More, to:
- 
Change control set
- 
Export controls
- 
Export all framework evidence
- 
Export custom control history
- 
Export gap assessment <https://help.vanta.com/en/articles/11345512>
- 
Remove Vanta controls
 

## Updates
Updates made to the Framework will be outlined here and provide information about the update and any items in Vanta that were affected; such a new controls or new policies sections.
