# Manually Linking Background Checks

Source: https://help.vanta.com/en/articles/11345938-manually-linking-background-checks
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

Background checks can be uploaded to a cloud drive (such as Google Drive or Dropbox) and then manually linked to an employee's background check in Vanta. It's not currently possible to upload a file (like a PDF) directly into Vanta for a background check.
 

## Prerequisites
- 
Background check needs to be uploaded to a cloud drive service that can provide a viewable link to the file
 

## Procedure
- 
Upload the background check to a cloud drive, and copy the link from the cloud drive
- 
Go to People <https://app.vanta.com/people/people> page
- 
Click on the desired user's profile
- 
Under the Tasks tab, click the link next to the background check:
