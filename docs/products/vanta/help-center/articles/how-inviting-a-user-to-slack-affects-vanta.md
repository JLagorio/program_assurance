# How Inviting a user to Slack affects Vanta

## Article text

## Prerequisites
- 
Administrator access to Vanta
- 
Administrator access to
 
When a user is invited to slack, they have an account type of invited member, and a billing status of inactive:
 
[image 01]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516757024/4a699cfcefe38560c61924a3413c/27020739007508?expires=1794967200&signature=9eea088db03937a01f4c4e913aa2aaaed952bfe34e4286f7fae8e3c9d0f6260a&req=dSUmEM57moFdXfMW1HO4zZROyMNj0Aq8NNr3uLcT3OsahrZ2cL8qykw6eeWE%0AsCoNM5Hh1lmqCkvCQPM%3D%0A>
 
This user will also be fetched into Vanta and listed on the access page under slack, even if the user has not yet accepted the invitation.
 
In a case where a user never ends up accepting their invite, administrators will need to go into Slack --> Manage Members and then find the account, click the three dots, and finally revoke invitation:
