# Previewing Vanta as an Auditor

Source: https://help.vanta.com/en/articles/11345983-previewing-vanta-as-an-auditor
Collection: Audit Readiness ; Audit Readiness › Audits
Fetched: 2026-11-17

## Article text

You can preview audits in Vanta to see what your auditor will have access to You can preview audits in Vanta to see the data and evidence your auditor will have access to before scheduling an audit or granting auditors access. 
 
To use the preview feature, you need to create an audit first. Feel free to create a test audit to explore auditor access and delete it when you're done.
 
The preview experience depends on the type of request list your audit uses. In some cases, the audit preview shows the auditor's experience directly, while in others it allows you to configure what is visible:
 | 
Request list type | 
Steps to preview
 | 
Default request list (most common) | 
The preview shows the auditor view directly:
- 
From the Audits page, click Open audit.
- 
Review the audit as your auditor would see it.
- 
Click Exit audit view to return to your account.
 | 
Information request list (IRL) <https://help.vanta.com/en/articles/12293647-information-request-list-irl-in-vanta-public-preview> | 
The preview allows you to see what's shared from within the request list:
- 
From the Audits page, click Open audit.
- 
In the Requests tab, review the evidence you'll need to provide to your auditor to fulfill the request list.
- 
In the Controls tab, view controls linked to each request.
- 
In the Data & populations tab, click View to see what’s included for each section.
💡 Tips: 
- 
Managing auditor views <https://help.vanta.com/en/articles/11565398-managing-auditor-views>: For IRL audits, Data & populations pages are hidden by default. Before previewing, enable the sections you want to share so they appear in the auditor view.
- 
Auditor visibility into test data <https://help.vanta.com/en/articles/11345526-auditor-visibility-into-test-data>: Previewing is especially helpful for checking controls and supporting evidence (tests, documents, and policies) that need action or are pending auditor review.
- 
How will your auditor use Vanta <https://help.vanta.com/en/articles/11345844-how-will-your-auditor-use-vanta>: The preview shows auditor-visible data only. Auditor actions like accepting, flagging, or marking evidence as not applicable are only available in the auditor's own session.
