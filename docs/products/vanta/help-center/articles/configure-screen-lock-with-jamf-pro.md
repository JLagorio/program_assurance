# Configure Screen Lock with Jamf Pro

Source: https://help.vanta.com/en/articles/11346044-configure-screen-lock-with-jamf-pro
Collection: Optimizing your Workflow ; Optimizing your Workflow › Troubleshooting
Fetched: 2026-11-17

## Article text

To enforce screen lock, Vanta requires a configuration to be created and requires every device to install this profile.
 

## Procedure
- 
Go to Computer
- 
Select Configuration Profiles
- 
Create a new configuration profile (or edit the existing one)
- 
Go to log in Windows, select Options, and enable Start screen saver after
- 
Go to Security and Privacy and enable Require Passcode to Unlock Screen
- 
Save
