# Resolving the "Nice to Meet you Message" Message when Installing Vanta Device Monitor

## Article text

To resolve the 'Nice to Meet You' message when installing the Vanta Device Monitor, please ensure you meet the following requirements and follow the instructions in the video below.
 

## Prerequisites:
- 
Confirm your default browser is set to Google Chrome. If you do not have Google Chrome, you must install this browser <https://www.google.com/chrome/dr/download/?brand=CHBD&geo=US&gclid=CjwKCAiAuOieBhAIEiwAgjCvcmPoNZo0Xtiic3v05s69cBRMP9lGVr-jrDOf6TAcjw83NNK2DSv2SBoCrIcQAvD_BwE&gclsrc=aw.ds> to resolve this message.
- 
Confirm you have Admin access to the device you are downloading the agent to.
