# Syncing Policies from Google Drive

Source: https://help.vanta.com/en/articles/11345638-syncing-policies-from-google-drive
Collection: Integrations ; Integrations › Integrations by Type ; Integrations › Integrations by Type › Access and Additional Integrations
Fetched: 2026-11-17

## Article text

To leverage this integration, Google Drive must first be connected <https://help.vanta.com/en/articles/11345637> through the integrations page within Vanta.
 
Please remember to allowlist Vanta in your Google Workspace domain
 

## Prerequisites
- 
In order to prevent unauthorized access to private files, Vanta will only sync Google Docs from the shared drive titled Vanta policies (this drive name is case sensitive). Google Workspace admins must create this drive within Google for the connection to work successfully. 
- 
For instructions on creating a shared drive, Please see Google's help article here <https://support.google.com/a/users/answer/9310249?hl=en&ref_topic=9298590&sjid=4465504165598179960-AP>
- 
The person who connects the Google Drive integration must have Write permissions for the Vanta policies folder within Google Drive. If permissions are modified after integration setup, this may result in sync errors. It is recommended to verify user access permissions regularly and make adjustments as needed.

## Creating a Custom Policy by Syncing through Google Drive
- 
Open the Policies page from the left-hand navigation panel
- 
Select + Add custom policy 
[image 05]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763158/82db51452bd4daf00361ef1708f8/27523895761556?expires=1794967200&signature=253b0cf63df4ff5f419ad9ed504b02ec50ece679131ff7635457316aaacc3334&req=dSUmEM54noBaUfMW1HO4zU2Tf2rnBFZ1KV21fVlH2RAO9gd4d6U7%2B1AjI1w2%0AiLuejGrTCvXqTKw38A8%3D%0A>
- 
Add a policy title and description. Select Create 
- 
Select Sync a file
[image 06]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516763157/f95008f681a1e3b1e82fa5dce434/14471381459604?expires=1794967200&signature=87119454bdae9ff2facb8c6626314fd05b26b4d6b4a68246975177d9771f7952&req=dSUmEM54noBaXvMW1HO4zVI2R5ZNJeEG5pryCaRxGC0wKNzxcELKVT2OtqQr%0AQ8s%2FOwdxUW2IQeB9MS8%3D%0A>
- 
Filter by name and choose the appropriate file
Policies are synced from Google Drive into Vanta once an hour, and will not affect any previously approved policies.
 

## Keep in Mind:
- 
The Google Drive sync will only work with Google doc files and .pdf files. If the files are of another file type, it will show a "No results found" message.
