# Adding Controls to a Test

Source: https://help.vanta.com/en/articles/11346072-adding-controls-to-a-test
Collection: Optimizing your Workflow ; Optimizing your Workflow › Frequently Asked Questions
Fetched: 2026-11-17

## Article text

In some cases users may want to add controls to a test that would not otherwise be associated with that Framework or Control.
 

## Add controls to a test
- 
Navigate to the Tests page <https://app.vanta.com/tests> and click into the test you want to edit
- 
Click the Controls tab at the top of the test and select Add control

 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516758394/65d03d7b84f17d6d91a10836756d/27508643320596?expires=1794967200&signature=ce4b8dcb6a406a168082d28cff1981cd279333eaa39f6adb9c82752b8db2cfbd&req=dSUmEM57lYJWXfMW1HO4zWb8x3nnjl3yy18r8XtSVyd4Md1DHWMqx%2BBs3obO%0ArHJj0GlvEFc7fbi%2B%2BGg%3D%0A>
- 
In the pop-up modal, search for the desired Control by typing keywords into the search bar
- 
Click the Framework menu to filter for Controls related to your domain's active Frameworks
- 
[image 02]
 <https://downloads.intercomcdn.com/i/o/t4a8cs4z/1520734722/69c44e3ef63080c4751aa6b1f562/23329382247316?expires=1794967200&signature=e4972bba3bc4403cbf18f3e4b0824fac64cb0ed1dd893d61c6d09578f0191689&req=dSUlFs59mYZdW%2FMW1HO4zZpVe2s6enuOTATpcSCF5WH3O4hUXJSvobc2S0WC%0AZX3Z%0A>
 
- 
If the desired Control doesn't exist, go here to learn how to create a Custom Control <https://help.vanta.com/en/articles/11345435>
- 
Click the Control name on the left to view details on the right
[image 03]
 <https://vanta-e0817867462a.intercom-attachments-7.com/i/o/t4a8cs4z/1516758395/b16a45dffb7a5856248fff8bcfb5/23329382276500?expires=1794967200&signature=7fdab6d19e7f5024028b294b923454d161e1f8b942a4981f98c3918e57b66841&req=dSUmEM57lYJWXPMW1HO4zQ2Z7SQ1yRX9LZEng37z%2B8EK8igJ2oQgUHhYY6lF%0ALJJ0HjQJMX3MVBygfqs%3D%0A>
 
- 
Click the arrow button to view the full details on the Controls page <https://app.vanta.com/controls>
- 
Click the Add button to add the Control to the test
- 
After a moment of processing, you should see a notification at the bottom of the page letting you know the Control has been added
