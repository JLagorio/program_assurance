# Configure Idle Session Timeout

Source: https://help.vanta.com/en/articles/11345384-configure-idle-session-timeout
Collection: Getting Started Hub ; Getting Started Hub › Account Settings
Fetched: 2026-11-17

## Article text

- 
From the top right-hand corner, select Settings (gear icon)
- 
Select Login and Security
- 
Click the Security tab
- 
From the drop-down menu, select the Idle Session Timeout length. If your team members remain idle during this period, they'll be logged out automatically
