## Article text

## About this article
- 
This integration pulls users and groups using Merge provider from 7Shifts.
- 
Estimated setup time: Less than 10 minutes

## How it works
7Shifts is a team management platform specifically designed for restaurants, typically called HRIS. We use Merge provider <https://www.merge.dev/integrations/7shifts> to pull in employees and groups.
 

## Use Cases
- 
Monitor and manage tasks for your personnel.
 

## Overview
To connect 7Shifts to Vanta, you will need to get you company ID and create a API Key token
 

## Requirements
- 
7Shifts administrator account to access Settings

-

- 
Data about your employees
 Vanta will be able to do:
- 
Vanta does not have write permission
