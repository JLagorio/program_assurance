# Test 55: Employees Acknowledge the Code of Conduct

Source: https://help.drata.com/en/articles/4776957-test-55-employees-acknowledge-the-code-of-conduct
Collection: Monitoring Test Guidance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspects your company records to determine if the Code of Conduct has been been acknowledged by all employees.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Employee Requirements **control that ensures your company requires all employees to read and acknowledge the Code of Conduct and Data Protection policy upon hire.

**WHAT TO DO IF A TEST FAILS**

If Drata finds employees that have not acknowledged the Code of Conduct the test will fail. With a failed test, you will receive a list of employees that have not acknowledged the Code of Conduct.

To remediate a failed test, you will need to advise these employees to acknowledge the Code of Conduct as soon as possible.

**STEPS TO REMEDIATE**

1. Navigate to the Policy Center page.
2. Add a 'Code of Conduct Policy' and ensure that the newly added policy has been approved.
3. For each Current Employee and/or Contractor, ensure that they navigate to their onboarding page (/employee) and click on the 'Acknowledge Policy' for the Code of Conduct
