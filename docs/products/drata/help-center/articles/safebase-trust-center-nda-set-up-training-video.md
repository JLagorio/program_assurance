## Article text

This video explains how to configure NDA collection for Trust Center access requests. You’ll learn how to set up Clickwrap using approved or custom language, name the NDA template, forward signed copies, and choose a default NDA provider. It also covers DocuSign and Ironclad integrations, as well as the NDA Bypass feature for eligible plans and CRM-based workflows.

**Key takeaways:**

- Configure the built-in Clickwrap NDA with custom or autogenerated language, a template name, and forwarding email addresses.
- Choose a default NDA provider, including Clickwrap, Signed Outside SafeBase, or No NDA.
- Understand how DocuSign, Ironclad, and NDA Bypass support more advanced NDA workflows.
