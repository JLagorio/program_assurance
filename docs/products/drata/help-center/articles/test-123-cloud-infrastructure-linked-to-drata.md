# Test 123: Cloud Infrastructure Linked to Drata

Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspects your company cloud infrastructure to ensure it is successfully linked to Drata.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Cloud Infrastructure Linked to Drata** control that ensures your company is using Drata to monitor the security and compliance of its cloud infrastructure configuration.

**WHAT TO DO IF A TEST FAILS**

With a failed test you will receive messaging in Drata outlining the failed API response from your infrastructure.

To remediate a failed test you will need to establish a connection to your cloud infrastructure within Drata.
