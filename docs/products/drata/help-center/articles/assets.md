## Article text

The **Asset Inventory** is Drata’s system of record for assets that are **in scope for compliance and audits** (such as SOC 2).

Assets represent the systems, tools, documentation, and people that support your controls. Drata uses the Asset Inventory to evaluate control coverage, test readiness, and audit evidence.

## View and manage the Asset Inventory

To open the Asset Inventory:

1. Select **Risk → Assets**.

From the Asset Inventory, you can:

- Filter assets by **Class**, **Type**, **Source**, **Owner**, or **Owner status**
- Search for assets by name
- Download the asset list for audit review

Each asset includes **Asset Notes**, which provide additional context for auditors and internal reviewers. To view or add asset notes:

1. Select an asset
2. Add or update notes as needed.

Use asset notes to document:

- Ownership or responsibility
- Exceptions or clarifications
- Audit-specific explanations

## Manually add an asset

If an asset is not automatically discovered, you can add it manually.

1. Select **Create asset**.
2. Complete the required fields.
3. Save the asset.

Manually added assets behave the same as automatically discovered assets for testing and audit purposes.
