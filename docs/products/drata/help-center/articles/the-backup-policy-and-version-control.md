# The backup policy and version control

Source: https://help.drata.com/en/articles/5168457-the-backup-policy-and-version-control
Collection: GRC Best Practices › Compliance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: How should backups be done for your version control system

## Article text

Many customers have asked how to handle backups for their version control system, and if a separate system is needed to manage these backups.

It is not necessary to have a backup of code in your version control system if you are comfortable with the embedded backup process. You would want to review your version control system's SOC 2 report as part of your vendor management controls.
