# Test: Backups Checked for Integrity

Collection: Monitoring Test Guidance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspects your backup restoration testing results to determine if the integrity and completeness of backup information is tested.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Backup Integrity and Completeness **control that ensures your company tests the integrity and completeness of backup information on an annual basis.

**WHAT TO DO IF A TEST FAILS**

If Drata is unable to locate your Disaster Recovery Report or finds that it has not been re-uploaded within the last 12 months the test will fail. To remediate a failed test, you will need to run a Disaster Recovery simulation, and upload the results in a report in the 'Reporting' section. Please make sure to select the type of "Disaster Recovery".
