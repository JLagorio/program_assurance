# Test 128: Physical Security Policy

Source: https://help.drata.com/en/articles/4777004-test-128-physical-security-policy
Collection: Monitoring Test Guidance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspects your company records to determine if a Physical Security Policy is in place and currently valid.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Physical Security **control that ensures your company has security policies that have been approved by management and detail how physical security for the company's headquarters is maintained. These policies must be accessible to all employees and contractors.

**WHAT TO DO IF A TEST FAILS**

If Drata finds that a Physical Security policy either does not exist or has not been approved within the last 12 months the test will fail.

To remediate a failed test, you will need to either upload or build a Physical Security policy within Drata or notify the owner to click 'Approve Policy' as soon as possible.
