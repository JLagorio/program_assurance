# Upload or Update Personnel Data for Access Reviews (New Experience)

Collection: Understand the Drata Platform › Access Review
Updated: 2026-02-17
Fetched: 2026-11-22

## Article text

You can upload personnel access data using a CSV file **only for manually added applications**.

If the application is connected to Drata (from the Connections page), access data syncs automatically. You can sync but CSV uploads are not supported.

---

## Upload a Personnel CSV

1. Open the manually added application in **Governance > Access Reviews**.
2. Select **Upload personnel**.
3. Download the template and complete all required columns.
4. Upload the completed CSV file.

- Attachment: personnel_manual_upload.csv (text/csv)
