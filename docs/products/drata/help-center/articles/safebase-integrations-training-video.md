## Article text

This video explains where to access, connect, and configure integrations in SafeBase. You’ll learn how the Integrations section connects SafeBase with CRM, communication, document management, ticketing, data systems, and Drata, as well as where to manage API keys and SafeBase Partners. It also shows where to configure SAML/SSO and SCIM in User Management & Authentication, including how admins request SSO enablement through Technical Support. Finally, the video points you to the [Help Center Integrations Collection](https://help.safebase.io/en/collections/3412845-integrations) for detailed integration and SSO instructions.

**Key takeaways:**

- Access and configure integrations that connect SafeBase with other business systems, including Drata.
- Manage API keys and SafeBase Partners from the Integrations section.
- Configure SAML/SSO and SCIM settings in the Security section and learn how to request SSO enablement.
