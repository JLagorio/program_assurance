# Test 48: Contractors Acknowledge the Code of Conduct

Source: https://help.drata.com/en/articles/4776948-test-48-contractors-acknowledge-the-code-of-conduct
Collection: Monitoring Test Guidance
Updated: 2026-10-27
Fetched: 2026-11-22
Description: Drata inspects your company records to determine if the Code of Conduct has been acknowledged by all contractors.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Contractor Requirements **control that ensures your company requires all contractors to read and acknowledge the Code of Conduct, the Acceptable Use Policy, and pass a background check.

**WHAT TO DO IF A TEST FAILS**

If Drata finds contractors that have not acknowledged the Code of Conduct the test will fail. With a failed test, you will receive a list of contractors that have not acknowledged the Code of Conduct.

To remediate a failed test, you will need to advise these contractors to acknowledge the Code of Conduct.

**STEPS TO REMEDIATE**

1. Navigate to the Policy Center page.
2. Add a 'Code of Conduct Policy' and ensure that the newly added policy has been approved.
3. For each current contractor, ensure that they navigate to their onboarding page (/employee) and select the 'Acknowledge Policy' for the Code of Conduct.4. Alternatively, establish a Contractor Group and apply a scalable exclusion for the Acknowledged Policies requirement. This ensures contractors remain in scope for audits without requiring individual acknowledgment of the Code of Conduct.
