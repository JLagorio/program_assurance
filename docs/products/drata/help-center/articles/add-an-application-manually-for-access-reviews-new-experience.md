# Add an Application Manually for Access Reviews (New Experience)

## Article text

If an application is not detected automatically, you can add it manually so it can be included in Access Review periods.

### Add an Application

1. Go to **Governance → Access Reviews**
2. Select the **Applications** tab
3. Select **Add application**
4. Enter the **Website URL** to display its logo.
5. Enter the **Reviewer**.
6. Select **Save**

Manually added applications can be included in review periods.
