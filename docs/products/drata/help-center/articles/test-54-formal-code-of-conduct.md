# Test 54: Formal Code of Conduct

Source: https://help.drata.com/en/articles/4776955-test-54-formal-code-of-conduct
Collection: Monitoring Test Guidance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspects your company records to determine if a Code of Conduct is in place and has is before the policy renewal date.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Code of Conduct **control that ensures your company has a documented Code of Conduct that is in place and provides guidance to employees on acceptable conduct standards.

**WHAT TO DO IF A TEST FAILS**

If Drata finds that a Code of Conduct either does not exist or if the policy renewal date has passed, the test will fail.

To remediate a failed test, you will need to either upload or build a Code of Conduct within Drata, set a renewal date that aligns with your compliance program goals, or notify the policy approval to click 'Approve Policy' as soon as possible.

**STEPS TO REMEDIATE**

1. Navigate to the Policy Center page
2. Add a 'Code of Conduct Policy' and ensure that the newly added policy has been approved
3. Set a policy renewal date that aligns with your compliance program goals. Many frameworks require that policies are reviewed/approved annually
4. For each Current Employee and/or Contractor, ensure that they navigate to their onboarding page (/employee) and acknowledge the Code of Conduct
