## Article text

In this training video, we walk through how the Framework Mapping Agent recommends controls for each requirement in your custom or unsupported framework. You'll learn how to create a framework, review the suggestions, and run the agent again when you add requirements. See how it gives you a working draft to start from, instead of matching every requirement by hand.

**Key Takeaways:**

- **Start with a working draft:** Create a custom framework and upload a CSV of requirements. The more detail you add to the framework description, the better the control suggestions will be.
- **Let confidence guide your review:** Move quickly through high-confidence matches. Spend more time on medium-confidence and unmatched requirements. Nothing reaches your live compliance program until you select **Map**.
- **Refine as your framework grows:** Run the agent on newly added requirements, or choose **Update recommendations** to generate a fresh set of suggestions. For requirements without a strong match, map them manually.
