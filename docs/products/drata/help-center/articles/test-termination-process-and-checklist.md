# Test: Termination Process and Checklist

Source: https://help.drata.com/en/articles/4797463-test-termination-process-and-checklist
Collection: Monitoring Test Guidance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspects your company System Access Control Policy to determine if there is a termination checklist being followed appropriately.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Offboarding Checklist **control that ensures your company uses a termination checklist to ensure that system access, including physical access, for terminated employees has been removed within one business day

**WHAT TO DO IF A TEST FAILS**

If Drata finds that a termination checklist does not exist as part of the current policies the test will fail.

To remediate a failed test, you will need to ensure that a policy has been uploaded within Drata that contains the offboarding termination checklist.
