# Test 62: Password Manager Required

Source: https://help.drata.com/en/articles/4777028-test-62-password-manager-required
Collection: Monitoring Test Guidance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspected your companies' security policies to determine if employees are required to use a password manager for cloud services.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Password Manager **control that ensures all company-issued laptops have a sufficient password manager installed.

**WHAT TO DO IF A TEST FAILS**

If your password policy is either not in Drata or has not been approved by the owner within the last 12 months the test will fail.

Please verify that your password policy is uploaded in Drata. If it is uploaded in Drata you will need to notify the owner to approve the policy as soon as possible.

**STEPS TO REMEDIATE**

1. Navigate to the Policy Center page
2. Add a 'Password Policy' and ensure that the newly added policy is approved
