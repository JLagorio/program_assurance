# Test 46: Performance Evaluation Process

Source: https://help.drata.com/en/articles/4778550-test-46-performance-evaluation-process
Collection: Monitoring Test Guidance
Updated: 2026-08-05
Fetched: 2026-11-22
Description: Drata inspects your company records to determine if there is a formal process to evaluate employee performance.

## Article text

**ASSOCIATED DRATA CONTROL**

This test is part of the **Annual Performance Evaluations **control that ensures your company evaluates the performance of all employees through a formal, annual performance evaluation process.

**WHAT TO DO IF A TEST FAILS**

If Drata is unable to find an uploaded template for performance evaluation the test will fail.

To remediate a failed test, you will need to upload your performance evaluation report as soon as possible.

**STEPS TO REMEDIATE**

1. Navigate to the Human Resources page (account-settings/human-resources)
2. Add an 'Employee Performance Evaluation Process'
