#### Integration Scope Reference

All integrations use read-only access. Drata cannot modify configurations, push changes, or access user passwords or application data.

| **Integration Type** | **Examples** | **What Drata Reads** |
|---|---|---|
| Identity Provider (IdP) | Okta, Entra ID, Google Workspace | Users, groups, MFA status, password policies, SSO configuration |
| MDM / Endpoint Management | Jamf, Kandji, Intune, Rippling | Device inventory, encryption status, OS versions, compliance state |
| Cloud Infrastructure | AWS, GCP, Azure | Resource configurations, IAM policies, logging, network security settings |
| Version Control / SDLC | GitHub, GitLab, Azure Repos | Repo settings, branch protection rules, required review configurations |
