## Article text

In this training video, we walk through how the Custom Control Mapping Agent recommends related framework requirements, risks, policies, tests, and evidence for your custom controls. You'll learn how to start the agent, review each recommendation, and confirm the mappings you accept. See how AI-assisted mapping saves you time while keeping you in control of every decision.

**Key Takeaways:**

- **Start the agent your way:** Learn the three ways to generate recommendations: import controls from Recommendations, import or create controls from Controls, or select existing custom controls and choose **Recommend Objects**.
- **Review before you apply:** See how confidence levels, rationales, and the **Map** and **Dismiss** actions help you accept only the recommendations that fit each control's purpose and scope.
- **Know where it applies:** Understand that the agent analyzes custom controls only, so you know which selections trigger recommendations.
