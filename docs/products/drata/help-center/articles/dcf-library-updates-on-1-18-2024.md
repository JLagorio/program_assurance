## Article text

From time to time, Drata updates certain DCF controls to be more accurate. To learn more about how Drata creates and maintains the DCF library, check out [this article](introduction-to-the-drata-control-framework-dcf.md).

On 1/18/2024, Drata updated 203 of our controls in our control library to be more accurate. You can always access Drata's latest control template in your account by using the steps outlined in [this help article](https://help.drata.com/en/articles/8840054-revert-to-drata-s-latest-control-template-on-any-control-in-the-dcf-library).
