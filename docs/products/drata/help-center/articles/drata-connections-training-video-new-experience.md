## Article text

In this training video, we break down how Connections drive Drata’s automation. You’ll learn how integrating your key systems not only streamlines evidence collection, but also ensures continuous compliance monitoring. From identity providers to infrastructure and HR systems, see how the right connections power Drata’s ability to keep your security program running smoothly.

Key Takeaways:

- **Power automated evidence collection:** Understand how connections enable continuous compliance monitoring across your systems.
- **Prioritize critical integrations:** Learn which primary and secondary systems to connect first for a strong compliance foundation.
- **Support automated testing:** See how Drata uses integrations to verify configurations and run monitoring tests automatically.
