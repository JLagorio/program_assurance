# Layout layer: deep-dive and follow-up plan

2026-09-13, after the parts batch landed (see `layout-composability-audit.md`). Josef asked whether the layer is over-engineered and what else is there. This is the answer: a line-by-line read of `packages/design-system/src/layout/*` and `styles/layout.css`, an inventory of every app call site, the story coverage, and the storage, SSR and listener hygiene.

## Landed

Same evening, on Josef's "do it all", with every recommendation below taken. Batch 1: A1–A5, B1–B7, E1–E6, F1. Batch 2: C1 (`layout/shell/{context,root,top-nav,side-nav,splitter,panel,index}.tsx`, exports unchanged), C2 (`styles/shell.css` beside `layout.css`), C3 (the parts export by name from their modules, so `<ArgTypes of={Shell.Panel.Title} />` renders; the docs quote the breakpoint tokens). Batch 3: D1, nine `PageHeader.Lead` sites. F3 stays for the next minor. What the checks said is in the CHANGELOG entry and in the session's report; staged, not committed.

## Verdict

Not over-engineered. Every part is one element that forwards its props and its ref; composition is nesting; there is no layer between the app and Base UI. The layer is 1,960 lines with four contexts, eleven internal context consumers and six listeners, all matched. What follows is residue and hygiene, not a redesign.

## Checked and fine

- No render-scope or module-scope `window`/`document` access in any layout file; storage is try/caught and `document`-guarded.
- All six `addEventListener` calls have matching removals with the same capture flag; the ResizeObserver disconnects.
- No stale Radix or `data-state` selectors, no `moreLabel`, `Shell.Slot` or `layoutWide` left in live code.
- The app passes the toggle once, as `toggle={<Shell.SideNav.ToggleButton />}`. Profile already uses `description`.
- The shell context has eleven consumers, all inside the layer: splitting it into state and actions is not worth doing.
- The portal targets hide themselves with `:empty`; the unlayered `[data-shell-*]` rules beat layered utilities on purpose.
