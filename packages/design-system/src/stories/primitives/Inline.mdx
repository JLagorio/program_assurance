# Inline

For a row with one gap, optionally wrapping. `display="inline-flex"` keeps it inline-level for a chip or a count beside a label. The key props are `space`, `rowSpace`, `alignBlock`, `alignInline`, `spread`, `shouldWrap`, `separator`, `grow` and `display`.
