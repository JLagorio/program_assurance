# Metrics

Dimension is this system's own tier. Control heights are a themed axis rather than each component's own, so a control, a row, an icon and a layout region each have a token. The motion tokens share this sheet and have their own page (Tokens/Motion); the icons have theirs (Tokens/Icons).

## Controls

| Token                      | Value | Utility                                   | Use                                                    |
| -------------------------- | ----- | ----------------------------------------- | ------------------------------------------------------ |
| `dimension.control.xsmall` | 24px  | `h-control-xsmall`, `size-control-xsmall` | Button xsmall, the densest chrome.                     |
| `dimension.control.small`  | 28px  | `h-control-small`, `size-control-small`   | Button small, chips, menu items, side nav items.       |
| `dimension.control.medium` | 32px  | `h-control-medium`, `size-control-medium` | The default: Button, Input, Select, Combobox triggers. |
| `dimension.control.large`  | 36px  | `h-control-large`, `size-control-large`   | Reserved for hero forms.                               |

## Rows

| Token                   | Value | Utility         | Use                          |
| ----------------------- | ----- | --------------- | ---------------------------- |
| `dimension.row`         | 40px  | `h-row`         | The default table row.       |
| `dimension.row.compact` | 36px  | `h-row-compact` | A compact table row.         |
| `dimension.row.header`  | 32px  | `h-row-header`  | The table header row.        |
| `dimension.row.menu`    | 28px  | `h-row-menu`    | Menu, command and tree rows. |

## Icons

| Token                   | Value | Utility            | Use                                        |
| ----------------------- | ----- | ------------------ | ------------------------------------------ |
| `dimension.icon.small`  | 14px  | `size-icon-small`  | An icon inside a small or medium control.  |
| `dimension.icon.medium` | 16px  | `size-icon-medium` | A standalone icon, an icon button's glyph. |

The sizes, the stroke, the colour and the naming rules are on the [Icons](?path=/docs/tokens-icons--docs) page.

| `dimension.layout.banner`  | 48px  | `h-layout-banner`      | The banner area above the top nav, when one is shown.         |
| `dimension.layout.topnav`  | 48px  | `h-layout-topnav`      | The top nav.                                                  |
| `dimension.layout.sidenav` | 228px | `w-layout-sidenav`     | The side nav, expanded. The reader may resize it.             |
| `dimension.layout.panel`   | 320px | `w-layout-panel`       | The panel beside the main area, before the reader resizes it. |
| `dimension.layout.list`    | 340px | `w-layout-list`        | The list column of a WorkPane.                                |

## Breakpoints

| Token                        | Value  | Variant  | Use                                                                              |
| ---------------------------- | ------ | -------- | -------------------------------------------------------------------------------- |
| `dimension.breakpoint.sm`    | 40rem  | `sm:`    | Tailwind's sm. Pagination's words, Stat's columns and a two-month Calendar from here. |
| `dimension.breakpoint.md`    | 48rem  | `md:`    | Tailwind's md. `TopNav.End` shows its `overflow` menu below it.                   |
| `dimension.breakpoint.lg`    | 64rem  | `lg:`    | Tailwind's lg. The side nav is inline from here and an overlay below.            |
| `dimension.breakpoint.aside` | 75rem  | `aside:` | The aside sits beside Main from here while no panel is open.                     |
| `dimension.breakpoint.panel` | 80rem  | `panel:` | The panel is a full-height column beside the page; below, it replaces Main.      |
| `dimension.breakpoint.wide`  | 110rem | `wide:`  | The aside sits beside Main even while a panel is open.                           |
| `dimension.breakpoint.xl`    | 80rem  | `xl:`    | Tailwind's xl, the panel breakpoint under its Tailwind name for Grid's `xl` count. |

One source for three readers: `layout.css` writes `@media (width >= theme(--breakpoint-panel))`, the shell reads `tokenValue("dimension.breakpoint.panel")` for `matchMedia`, and a class takes the variant. `sm`, `md`, `lg` and `xl` restate Tailwind's values so a class and a media query cannot drift apart.

`src/styles/layout.css` adds the few templates a class string cannot say, each reading these tokens: `grid-cols-main-rail`, `grid-cols-list-detail`, `sticky-rail`, `min-h-work`, `fill-window` and `shell-root`, the navigation grid. The shell sets `--shell-top` (banner plus top nav) so a sticky rail knows where to stop, and its main area sets `--shell-inset-bottom` so a filled register knows where to end.
