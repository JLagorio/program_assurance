# WorkPane

You are working through a list. The list stays on the start side and is the navigation; the detail on the end side changes; choosing never leaves the page. The rows are [Item](?path=/docs/components-item--docs)s that select in place, a Dot for the state and the id under the name, the chosen one filled; the detail is an [ActionBar](?path=/docs/shapes-actionbar--docs) pinned above [Block](?path=/docs/shapes-block--docs)s of work with an [Inspector](?path=/docs/shapes-inspector--docs) beside them. Mail clients and Jira's issue navigator are the model; neither Carbon nor Atlassian names it, and Carbon's structured list with a selectable row is the nearest part. It replaces click-in and click-back: a queue, a scope list, a control set worked one at a time.

## Anatomy

| Part       | What it is                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------------- |
| List label | Above the list, staying put while it scrolls: what the list is and how many. It names the list's landmark.                  |
| List       | An Item.Group, compact, in a column `dimension.layout.list` wide, sticky under the top nav, scrolling inside itself.         |
| Row        | `WorkPane.Row`: a Dot for the state, the name, and under it the id and a word of meta. The chosen one filled.               |
| Rule       | `color.border` between the list and the detail.                                                                             |
| Detail     | The chosen row's work: an ActionBar, Blocks, an Inspector. `space.300` from the rule.                                       |
| Empty      | What the detail shows when nothing is chosen: a compact Empty, "Choose a control".                                          |

## Variants

WorkPane has one appearance. What varies is the list's width and what the rows are:

| Pane           | Use                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------ |
| Controls       | The default width, 340px: a control's id, name and state, worked one at a time.                              |
| A short list   | `listWidth` narrower, 240px: the wizard's scopes, a handful of short names.                                  |
| Rows as Items  | Items with `onSelect` and `isActive` in place of WorkPane.Row, when a row needs a mark or a trailing value.   |

Not built, and why: a list that navigates to a page (a row that links), because then it is an index table and the record is its page; a resizable rule, because the list has one width per kind of row and the reader resizes the shell's panel, not the page; a collapsed list showing only marks, because the list is the navigation and its names are the point; a third pane, because the detail's rail is the Inspector.

## Sizes

| Column | Width                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------ |
| List   | `dimension.layout.list`, 340px, or `listWidth` in pixels for a short list.                        |
| Detail | The rest.                                                                                        |

The pane is at least the viewport under the shell's header and a page header (`min-h-work`), so the list's sticky column has room. Below the large breakpoint the list stacks above the detail.

## States

| State   | What changes                                                                                     |
| ------- | ------------------------------------------------------------------------------------------------ |
| Chosen  | The row filled `color.background.selected`; the detail is its work.                              |
| Hover   | A row `color.background.neutral.subtle.hovered`.                                                 |
| Empty   | Nothing chosen: the compact Empty in the detail.                                                 |
| Sticky  | The list stays under the top nav while the detail scrolls; past the viewport it scrolls itself.  |

## Modifiers

- **`listLabel`**, **`list`**, **`detail`**, **`empty`**, **`listWidth`** as in Anatomy and Sizes.
- **Row**: **`id`**, **`title`**, **`meta`**, **`tone`**, **`isActive`**, **`onSelect`**.

## Content

- **The list label is the kind and the count**: "5 controls", "Access control · 6".
- **A row is the name and, under it, the id and a word**: the state, the method, how long ago. The Dot is the state's colour; the word carries it.
- **One fill per list**: the chosen row. State is a Dot, not a Badge, so the column stays quiet.
- **The empty state says what to do**: "Choose a control", and one line on what happens.
- **The detail is the record's work**, not its page: the ActionBar's states and actions, the Blocks; a link to the full record if there is more.

## Style

| Element | Token                                                                                                                       |
| ------- | --------------------------------------------------------------------------------------------------------------------------- |
| List    | `dimension.layout.list` · `color.border` at the end · `space.200` before the rule · sticky at the shell's header plus `space.300` |

| Detail  | `space.300` after the rule · `min-h-work`                                                                                   |

## Accessibility

- **The list is a complementary landmark named by its label**: "5 controls, complementary". Without a label it is named "List".
- **The rows are an ordered list of buttons**, each named by the row's name; the id and the meta are read as the text beside it. Enter or Space chooses; the chosen row says so in its detail.
- **Choosing does not move focus.** The reader stays in the list and arrows on; the detail is read on request.
- **The detail's heading is the ActionBar's h1**; the Blocks are its h2s, so the outline is the work's.
- **The empty state is text, then nothing to press**: "Choose a control" and the line under it.
