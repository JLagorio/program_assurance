# PreviewSplit

An index table and, beside it, the [PreviewRail](?path=/docs/patterns-previewrail--docs) of the chosen row, sized by the reader. The first child is the list; what follows, the open rail or nothing, is the second pane. Closed, it is the list at full width; open, a [Resizable](?path=/docs/components-resizable--docs) with the list at least 55% and the rail from 18 to 45, 26 at first. This is the rail beside a table, not the record's rail, which is the ShowPage's.

## Anatomy

| Part   | What it is                                                                        |
| ------ | --------------------------------------------------------------------------------- |
| List   | The first pane: the table, at least 55% of the width.                             |
| Handle | The Resizable's hairline between them; it lights on hover and takes the arrow keys. |
| Rail   | The second pane: the PreviewRail of the chosen row.                               |

## Variants

| Split  | Use                                                          |
| ------ | ------------------------------------------------------------ |
| Closed | Nothing chosen: the list alone, at the width of the page.    |
| Open   | A row chosen: the list and the rail, the handle between.     |

<Canvas of={Stories.PreviewSplitMatrix} />

Not built, and why: a rail on the start side, because the reader reads the list first; a vertical split, because a preview under a table is a Drawer on a narrow screen and the rail stacks there on its own; a width remembered across pages, because each index is its own page and the default is right for a rail; a third pane, because the record's rail is the shell's, not the split's.

## Sizes

| Pane | Width                                  |
| ---- | -------------------------------------- |
| List | At least 55% of the split.             |
| Rail | 26% at first; from 18% to 45%.         |

The split is as wide as the page. Below the large breakpoint the rail stacks under the table.

## States

| State    | What changes                                                              |
| -------- | ------------------------------------------------------------------------- |
| Closed   | The list alone.                                                           |
| Open     | The rail beside it at its last width.                                     |
| Dragging | The handle in `color.border.brand`; the panes follow the pointer.         |
| Focused  | The handle in `color.border.brand`; the arrow keys move it.               |

## Modifiers

- **`open`**: whether a row is chosen.
- **`children`**: the list first, then the rail or nothing.

## Content

- **The list first, the rail second**, nothing else. What the rail says is the PreviewRail's.
- **Open when a row is chosen**, closed when none is; never open with an empty rail.

## Style

| Element | Token                                                                                 |
| ------- | ------------------------------------------------------------------------------------- |
| Handle  | Resizable's: a hairline `color.border` · `color.border.brand` on hover and focus      |
| Panes   | Aligned to the top; the rail draws its own `color.border` at the start                |

## Accessibility

- **The handle is a separator** with its position as a value; the arrow keys move it and the panes announce nothing, so the reader's place in the table is kept.
- **The list keeps focus** when the rail opens; the rail is a landmark after the table, named by the PreviewRail's eyebrow and id.
- **Closing the rail** returns the width to the list without moving focus.
