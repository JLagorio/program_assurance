# PreviewSheet

A modal record detail surface built from shadcn's Base UI Sheet. It composes record identity and Sheet parts and supports work in place: editable properties, evidence review and related-record navigation.

<Canvas of={Stories.PreviewSheetStory} />

## Anatomy

| Slot                     | Purpose                                                                  |
| ------------------------ | ------------------------------------------------------------------------ |
| id, title, status        | Record identity and current state. The title names the dialog.           |
| subtitle, facts          | Optional supporting context; absent content renders no placeholder rows. |
| onBack                   | Return to the previous record within the caller's navigation stack.      |
| children                 | Scrollable work area.                                                    |
| openTo, links            | Real links to the record or related destinations.                        |
| actions                  | Actions performed in the current sheet.                                  |
| initialFocus, finalFocus | Native Base UI focus targets for the consuming workflow.                 |

## Variants and states

Choose this surface when the current task benefits from containing focus; use Shell.Panel for selected work alongside a queue. Both support actions. The sheet defaults to 720px and fits narrower screens; footer actions wrap.

The caller controls `open` and owns dismissal, in-progress work and the related-record stack. Back changes the frame; Close dismisses the sheet. Keep browser history aligned when that stack is represented in the URL.

<Canvas of={Stories.CompleteReview} />

## Accessibility

Base UI provides the dialog semantics, modal focus containment, Escape dismissal and focus return. By default, PreviewSheet focuses its title so users encounter the identity before the record's structured content. Use `initialFocus` for an appropriate field in a task-oriented form, and `finalFocus` when completing work removes the opener. A short supplied subtitle becomes the description; an absent subtitle creates no empty description.

The visible Close remains available. Keep pending/unsaved-work handling in the caller, including dismissal guards where the actual workflow needs them. Footer navigation uses named anchors; mutations use buttons.

Sources: [shadcn Base Sheet](https://ui.shadcn.com/docs/components/base/sheet), [implementation](https://github.com/shadcn-ui/ui/blob/main/apps/v4/registry/bases/base/ui/sheet.tsx), [Base UI Dialog](https://base-ui.com/react/components/dialog), [WAI-ARIA dialog guidance](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).
