# PreviewSheet

A modal record task surface built from shadcn's Base UI Sheet. It supports focused work such as evidence-version review. Collection browsing normally uses Shell.Panel with PreviewNavigation. The outer header holds global navigation and Close. The body begins with an inner PageHeader for the record's name and commands; metadata follows below it.

## Anatomy

| Slot                        | Purpose                                                                                                    |
| --------------------------- | ---------------------------------------------------------------------------------------------------------- |
| title                       | The inner PageHeader's h2; its SheetTitle also names the modal.                                            |
| actions                     | Record commands in PageHeader.Actions beside the title; use small controls.                                |
| id, status, subtitle, facts | Optional body metadata below the record header; absent content leaves no placeholder rows.                 |
| onBack                      | Return to the previous frame from the outer header.                                                        |
| navigation                  | Global controls in the outer header, normally PreviewNavigation with previous/next and a full-record link. |
| openTo                      | Fallback full-record link in the outer header when navigation is absent.                                   |
| links                       | Related destination links in the footer; no repeated full-record link.                                     |
| children                    | Scrollable work area after the record header and metadata.                                                 |
| initialFocus, finalFocus    | Native Base UI focus targets for the consuming workflow.                                                   |

## Variants and states

Choose this surface when the current task benefits from containing focus; use Shell.Panel for selected work alongside a queue. Both support record actions in the inner record header. The sheet defaults to 720px and fits narrower screens. Keep commands concise: one small primary action and an overflow menu for additional commands.

The outer header never repeats the visible record name or holds record commands. It contains Back when provided, collection navigation or the fallback full-record link, and Close. Supplying `navigation` suppresses `openTo`; include the full-record destination in that navigation. The footer, when present, contains related links only.

The caller controls `open` and owns dismissal, in-progress work and the related-record stack. Back changes the frame; Close dismisses the sheet. Keep browser history aligned when that stack is represented in the URL.

## Accessibility

Base UI provides the dialog semantics, modal focus containment, Escape dismissal and focus return. By default, PreviewSheet focuses its title so users encounter the identity before the record's structured content. Use `initialFocus` for an appropriate field in a task-oriented form, and `finalFocus` when completing work removes the opener. A short supplied subtitle becomes the description; an absent subtitle creates no empty description.

The visible Close remains available in the outer header. Keep pending/unsaved-work handling in the caller, including dismissal guards where the actual workflow needs them. Navigation uses named anchors; record commands use buttons in the inner header.
