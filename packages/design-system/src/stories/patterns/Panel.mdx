# Panel

The surface inside the shell's Panel area, beside the page under the top nav. Two uses. The detail of a selected row beside its table: it comes with the selection and goes when it clears, has no title and no close because the row names it, and is `flush` so the Inspector inside runs its rules edge to edge. And a panel the reader opens, a thread, a history, a form: a header with the title, up to two actions and the close, a subheader that stays put, a footer for the form's buttons, and `Panel.Trigger` in the toolbar to open it. The area scrolls; the header and the footer do not. The shell draws the area; a record's side panel and a comments panel are the two uses. It is neither the record's rail, which is the ShowPage's beside the overview tab, nor the peek, which is a Sheet.

## Anatomy

| Part      | What it is                                                                                                         |
| --------- | ------------------------------------------------------------------------------------------------------------------ |
| Back      | A chevron before the title, only after a link inside the panel opened a new view.                                  |
| Icon      | A small mark before the title.                                                                                     |
| Title     | An h2 in `font.body` medium, one line: the object shown or the action completed.                                   |
| Actions   | Up to two icon buttons before the close: expand, open in a new tab, more.                                          |
| Close     | The X at the end, for a panel the reader opened.                                                                   |
| Subheader | A row under the header that stays put: a status, a breadcrumb, the object's name when the title is an action.     |
| Body      | The content, inset `space.300` inline and `space.200` block; `flush`, no inset, for an Inspector.                  |
| Footer    | Pinned to the bottom, right-aligned: Cancel, then the primary.                                                     |
| Trigger   | An icon button in the toolbar, selected while the panel is open.                                                   |

## Variants

| Panel                        | Use                                                                                          |
| ---------------------------- | -------------------------------------------------------------------------------------------- |
| The detail of a selected row | `flush`, no header, no close. An Inspector inside. The selection opens it and closes it.     |
| A panel the reader opens     | A title, a close, a trigger. A thread, a history, a form with a footer.                      |
| A view inside a panel        | The same panel a frame deeper: `onBack` returns to the one before.                           |

Not built, and why: the record's rail in the panel, because the rail belongs beside the overview tab so the tab strip runs the full width; the peek in the panel, because a preview is a Sheet over the page and it stacks; tabs in the header, because a panel shows one thing; a collapsed state with an icon strip, because the panel is mounted when there is something to show and unmounted when there is not.

## Sizes

One width, the shell's: 320px by default, dragged wider from 240 with the Panel.Splitter, and the shell remembers it. Below the large breakpoint the panel overlays the page.

## States

| State          | What changes                                                        |
| -------------- | ------------------------------------------------------------------- |
| Closed         | Not rendered. The trigger is unselected.                            |
| Open           | Rendered beside the page; the trigger selected and expanded.        |
| Scrolled       | The header and the footer stay; the body scrolls under them.        |
| A frame deeper | The back chevron before the title.                                  |

## Modifiers

- **`title`**, **`icon`**, **`onBack`**, **`actions`**, **`onClose`**, **`subheader`**, **`footer`**, **`flush`** as in Anatomy.
- **`Panel.Trigger`**: `isOpen`, `onClick`, `label`.

## Content

- **The title is the object or the action**: "Comments", "History", "Edit settings". Never "Panel" or "Details".
- **The row's detail has no title.** The row is selected beside it; a title would repeat it.
- **The subheader names what the action is on** when the title is an action: "Default field scheme" under "Add fields".
- **The footer is Cancel and the primary**, in that order.
- **The trigger's label is the panel's title.**

## Style

| Element   | Token                                                                                                                                 |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Header    | `space.075` block · `space.300` start (`space.100` with the back) · `space.100` end · `color.border` under · `elevation.surface`, sticky |
| Title     | `font.body` medium · `color.text`                                                                                                     |
| Subheader | `font.body.small` · `color.text.subtle` · `space.300` inline · `space.100` block · `color.border` under                                |
| Body      | `space.300` inline · `space.200` block · none when flush                                                                               |
| Footer    | `space.300` inline · `space.100` block · `color.border` above · `elevation.surface`, sticky · `space.100` between buttons               |
| Area      | Shell.Panel: `color.border` at the start · `elevation.surface` · `elevation.shadow.overlay` below the large breakpoint                  |

## Accessibility

- **The area is a complementary landmark** named by what is in it, Shell.Panel's `label`: "Comments", "Preview". It is last in the landmark order, after Main.
- **The title is an `h2`**, the first heading in the landmark; the row's detail has none, and the Inspector's groups are its headings.
- **The back and the close are labelled icon buttons.** The trigger says `aria-expanded` and is selected while open, so it reads "Comments, pressed, expanded".
- **Focus stays on the page.** Opening a panel does not move it; the reader tabs into the landmark. A form that must be finished before anything else is a Dialog.
- **Escape is not the close.** The panel is not modal; the close is the close, and clearing the selection closes the row's detail.
