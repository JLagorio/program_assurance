# Shapes

The layer between the parts and a screen. A traceability matrix, a work surface, a decision queue and a reference document are different jobs; pouring all of them into "header, tab strip, stack of sections" is why every screen looked the same. Four shapes, each answering a job the page archetypes could not. None takes a description prop: a heading plus a count is the whole label.

| Shape                                               | Job                                                                                                                                                                                                                                       |
| --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[WorkPane](?path=/docs/shapes-workpane--docs)**   | You are working through a list. The list stays; only the detail changes. The list column is `dimension.layout.list`.                                                                                                                      |
| **[Inspector](?path=/docs/shapes-inspector--docs)** | The facts stay put while the content scrolls: in a ShowPage's rail or a WorkPane's detail, sticky under the top nav, every group open until the reader folds it. Inside a Panel, the detail of a selected row, it scrolls with the panel. |
| **[ActionBar](?path=/docs/shapes-actionbar--docs)** | Identity, current state, and the actions that change it, pinned above the work. A blocked action carries its reason instead of hiding it. The first state is the headline and the bar's only pill; the rest read as dot and text.         |
| **[Block](?path=/docs/shapes-block--docs)**         | A block of work, always open. Collapsible is its closed twin.                                                                                                                                                                             |
