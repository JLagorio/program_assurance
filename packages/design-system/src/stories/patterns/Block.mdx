# Block

A block of work, always open: a rule, a heading with a count or an action, and the work under it. It is one of three regions the system draws and the one for what the reader does. [Section](?path=/docs/patterns-section--docs) is the plain region for what the reader reads, with a rule under its heading; [Collapsible](?path=/docs/components-collapsible--docs) is reference that folds. Content the reader will read is never folded; a Block is that content. None of the three takes an explanation under the heading: a heading carries a count or a constraint, and that rule is why the shapes exist.

## Anatomy

| Part    | What it is                                                                              |
| ------- | --------------------------------------------------------------------------------------- |
| Rule    | `color.border` above the block, so blocks stack with one line between them.             |
| Title   | The work, a noun, an h2 in `font.body` medium.                                          |
| Count   | After the title: how many rows the block holds. Zero shows; `null` hides it.            |
| Action  | At the end of the heading's line: one small button, the verb that adds to the block.    |
| Body    | The work: a table, a form, a list, a narrative. `space.050` under the heading, `space.200` below. |

## Variants

Block has one appearance. What varies is the work it holds:

| Work        | Use                                                                         |
| ----------- | --------------------------------------------------------------------------- |
| A list      | Open findings, evidence requests: Indicators or Items.                      |
| A table     | Parameters, contributors: a Table, edge to edge under the heading.          |
| A form      | The determination, a narrative: fields, an Editable.                        |

Not built, and why: a description under the heading (Section has one, for a constraint or a source), because a block of work explains nothing; a block that folds, because that is Collapsible; a card around the block, because the rule is the frame and a card in a card is noise; nested blocks, because two levels of work is two tabs.

## Sizes

One size. The block is as wide as its column; the heading row is `dimension.control.small` tall so a small button in it adds no height.

## States

A block has none. It is always open; its count changes as the work does.

## Modifiers

- **`title`**, **`count`**, **`action`** as in Anatomy.

## Content

- **The title is the work, a noun**: "Evidence", "Open findings", "Determination". Not a sentence, not a question.
- **The count is the rows**: 7 findings, 2 parameters. Zero is a fact and shows; pass `null` for work that has no count.
- **The action is the verb that adds**: "Add finding", "Request evidence". One, small; the rest are the body's.
- **No sentence under the heading.** A constraint or a source that the reader needs goes in a Section's description; an explanation goes nowhere.

## Style

| Element | Token                                                                         |
| ------- | ----------------------------------------------------------------------------- |
| Rule    | `color.border` above · `space.100` under it                                   |
| Title   | `font.body` medium · `color.text`                                             |
| Count   | Count · `space.100` after the title                                           |
| Heading | `dimension.control.small` tall · the action at the end, `space.100` before it |
| Body    | `space.050` above · `space.200` below                                         |

## Accessibility

- **A block is a `section` with an `h2`**, so the page's outline lists its work; inside a WorkPane's detail the ActionBar's title is the h1 above them.
- **The count is text** after the title, read with it: "Open findings, 2".
- **The action is a stop after the heading**, before the body.
- **Nothing is hidden**, so nothing needs to be found.
