# Glance

A compact record summary: an id and status, a title, a meta line and selected facts. It supplies content for a [HoverCard](?path=/docs/components-hovercard--docs); the product chooses the facts and the link's destination.

<Canvas of={Stories.GlanceStory} />

## Anatomy

| Part          | Behavior                                                                              |
| ------------- | ------------------------------------------------------------------------------------- |
| Id and status | The id uses small subtle text; the optional status sits at the other end of the line. |
| Title         | Medium body text, clamped to two lines.                                               |
| Meta          | Small subtle text for kind, path, owner or other context.                             |
| Facts         | Up to four KeyValue rows with 88px labels. Additional facts are omitted.              |

Use a Badge or Indicator with a text label for status. Select facts that help readers decide whether to open the record; keep any essential information available at the destination.

<Canvas of={Stories.GlanceMatrix} />

## Surface and interaction

Glance supplies content and has no width or open state of its own. These examples use a 300px surface. A HoverCard defaults to 256px; set `style={{ width: 300 }}` on `HoverCardContent` when the summary needs more space.

HoverCard opens after delayed pointer hover or keyboard focus on its trigger, and dismisses on leaving, outside press or Escape. Its content does not add a Tab stop or move focus. Use the trigger link to reach the destination, where the summary's information and actions remain available.

When rendered on a page, Glance's text reads in order: id, status, title, meta, then facts. The component has no interactive controls.
