# Line

**Status: Stable.**

A line per series over an ordered axis: a trend, a burndown, one measure against its plan. Two pixels wide with round joins, a ringed marker on hover, the last value printed after the line when asked. Straight segments by default, because the points are what was counted; a smooth curve never overshoots them. It lives in a [Chart](?path=/docs/patterns-chart-overview--docs) Frame, which names it, keys it and lays it out as a table.

## Anatomy

| Part      | What it is                                                                                                                                                                                                                                                                                                                                           |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Line      | 2px in the series' tone, round caps and joins. `curve="smooth"` is a monotone curve through the same points.                                                                                                                                                                                                                                         |
| Marker    | 8px across, ringed 2px in the surface so it reads over the line. On hover always; on every point with `dots`.                                                                                                                                                                                                                                        |
| End label | The series' last value after its line, `font.body.xsmall` in `color.text.subtle`; labels that would collide are pushed apart by a line's height, and one pushed off its line's end leads with a stroke of the series' colour, so it still says whose it is.                                                                                          |
| Gap       | A missing value breaks the line. `connectNulls` joins across it, for a gap that is not data.                                                                                                                                                                                                                                                         |
| Band      | A 10% wash between two values (the tolerable range, labelled at its top edge) or between two categories or dates (an assessment window, labelled above its middle).                                                                                                                                                                                  |
| Reference | A dashed hairline at a value (a target, a limit) or at a category (a milestone), labelled at the end or above the plot.                                                                                                                                                                                                                              |
| Axes      | The category axis with a hairline, or a time axis whose ticks are hours, days, months or years by the span, at the starts of those units in the reader's time zone; the value axis from zero, cropped to the data with `baseline="auto"`, or pinned with `domain`, whose ticks are round steps through zero. A value below zero draws the zero line. |
| Tooltip   | The category, every series at it keyed by a stroke, and with `delta` each change from the point before. The cursor is a `color.border.bold` hairline across the plot.                                                                                                                                                                                |
| Chosen    | The chosen category ringed on every line, in each series' tone.                                                                                                                                                                                                                                                                                      |

## Variants

| Variant              | Use                                                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Plain                | Two or three series, each a tone. Findings open and closed.                                                             |
| `curve="smooth"`     | A few points that are readings of one continuous thing. Never for counts that jump.                                     |
| `dots`               | A marker on every point, when each point is an event and there are few of them.                                         |
| `labels="end"`       | The last value after each line: the number the reader takes away. The default for a trend in a Frame.                   |
| `baseline="auto"`    | The value axis cropped to the data: a cumulative in the hundreds where the slope is the story. The description says so. |
| `bands`, `reference` | A burndown: the tolerable range as a band, the limit in `danger`, a milestone on the category axis.                     |
| Emphasis             | One series in `brand`, the rest in `neutral`: the honest answer to "make this clearer".                                 |
| `scale="time"`       | `x` holds dates: the points are spaced by time, the ticks pick their unit, and a band or a reference takes a date.      |
| `domain`             | The value axis pinned, so charts side by side share a scale: small multiples, with `syncId` for one hover.              |
| `delta`              | Each series' change from the point before, in the tooltip and the card.                                                 |

## Sizes

`size` is the plot's height: `small` 120px, `medium` 200px (the default), `large` 320px, or `height` in pixels; unsaid, the Frame's, and `large` in the Frame's expanded Dialog. Every category keeps a label fitted to the room up to the next one printed: whole, on two lines broken at a space, or cut with an ellipsis and its whole text as its title; at the plot's ends a label may run into the margin, and moves in from the edge rather than past it. Only where a point's slot cannot hold three characters do the labels step over whole slots, evenly from the first, so months in a card read Jan, Mar, May rather than J, F, M. A time axis draws at most eight ticks, each at a unit's start, and keeps its first and its last as the width narrows: months step by one, two, three, six or twelve from January, so a quarter's tick is a quarter's start, and the first tick and every tick that starts a new year carry the year in full ("Feb 2025", "May", … "Jan 2026"), which a two-digit year would not ("Apr 26" reads as a day). Calendar days ("2026-09-04") read the same in every zone; instants are read in the reader's `timeZone`. The right margin holds the widest end label.

The labels above the plot share one row: where a milestone's and a window's would overlap in a narrow plot, they move apart, the milestone's staying closest to its line, and milestones on one date share one label, joined with a middle dot. Each stays over its mark (a window's middle over its window) and within the plot's width, clear of the axis ticks; where the row is too short for them so, a window's label shortens before a milestone's wherever that makes room, each only as far as the row needs, with an ellipsis and its whole text as its title, and one with no room for three characters is left out. Labels inside the plot are drawn over the lines, ringed in the surface, so a line that crosses one runs behind the words.

## States

| State    | What changes                                                                                                                                                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hover    | A hairline across the plot at the category, a marker on every line there, the tooltip.                                                                                                                                                            |
| Hidden   | A series hidden from the Frame's legend leaves the plot and the table; the value axis keeps its scale, so the others do not jump.                                                                                                                 |
| Chosen   | With `onSelect` or `details`: a click anywhere in a category's column, or Enter or Space on the focused plot, chooses it. Every series is ringed there and the card opens on the point. The selection carries no series: a point is the category. |
| Loading  | A skeleton line on a hairline, pulsing, at the plot's height.                                                                                                                                                                                     |
| Entering | The lines draw in over `motion.duration.slow`; a change of data moves them.                                                                                                                                                                       |

## Modifiers

- **`curve`**, **`dots`**, **`labels`**, **`baseline`**, **`bands`**, **`reference`**, **`connectNulls`** as in Variants and Anatomy.
- **`scale="time"`**, **`domain`**, **`delta`** as in Variants; **`syncId`** and **`texture`** as on the Frame (a line's stroke stays solid); a series' own **`format`**.
- **`xLabel`**, **`yLabel`** print axis titles.
- **`format`**, **`formatX`** for the numbers and the categories, inherited from the Frame; the Frame's table prints the plot's.
- **`data`**, **`x`**, **`series`**: Inside a Frame, `data`, `x` and `series` may be left to the Frame, and the Frame learns them from the part when they are given here instead: say them once, to either. The Frame's legend takes a Line's stroke swatch from it.
- **`onSelect`** and **`details`** as in States; the selection is `{ datum, index }`.
- **`loading`** draws the skeleton; the Frame sets it from `state="loading"`.
- **`label`** names the plot outside a Frame; native props and a ref reach the plot's box, and `aria-describedby` describes its svg.

## Content

- **The category axis is ordered**: months, weeks, versions. Unordered categories are a Bar. Real dates go on a time axis, so a gap in the sampling is a gap in the plot.
- **Label the end**, never every point. The tooltip carries the rest.
- **A cropped axis is declared** in the description: "the axis starts at the first month's count".
- **A gap is a gap.** Say why in the description; do not join across it unless the gap is a sampling artefact.
- **A limit is `danger`**, a target is `neutral`, a milestone is `neutral` on the category axis, each labelled with its name.

## Style

| Element   | Token                                                                           |
| --------- | ------------------------------------------------------------------------------- |
| Line      | `color.chart.<tone>` · 2px · round caps and joins                               |
| Marker    | 8px · 2px ring in the surface it sits on                                        |
| End label | `font.body.xsmall` · `color.text.subtle` · tabular · 8px after the line         |
| Band      | `color.chart.<tone>` at 10% · label `font.body.xsmall` in `color.text.subtlest` |
| Reference | `color.chart.<tone>` · 1px dashed 4 3                                           |
| Cursor    | `color.border.bold` · 1px across the plot                                       |
| Zero line | `color.border.bold` · 1px                                                       |
| Delta     | `font.body.small` · `color.text.subtlest` · tabular · signed                    |
| Chosen    | The series' tone: an 8px marker in a 16px halo at 20%                           |
| Dimmed    | `opacity.disabled`, over `motion.duration.fast`                                 |
| Skeleton  | `color.skeleton` · 2px path on a `color.border` hairline                        |

## Accessibility

- **A plot that chooses is one tab stop.** With `onSelect` or `details`, the svg is named by the Frame's title (or `label`), with the role description "chart" and its keys as its description; Left and Right move between the points, Home and End go to the first and the last, and each step says the category and every visible value in a polite live region. Enter or Space chooses it; the card that opens is a dialog, and focus returns to the plot after.
- **A plot that chooses nothing is an image**, named by the Frame's title, with no tab stop: the table twin carries its numbers.
- **The table is the other copy** of the same numbers, one toggle away in the Frame.
- **Two or more series have a legend**, and each end label is a number in the text colour, not the series colour.
- **A gap is visible under every vision**: it is an absence, not a colour.
- **Loading is `aria-busy`** and named "[the plot's name], loading".

## Don't

The one series that is the point takes brand and the rest neutral, never five hues. Label the end, never every point, and leave a missing month as a gap, never a line drawn across it.
