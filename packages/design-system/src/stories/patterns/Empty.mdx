# Empty

Nothing here yet: a title, one line of why, the action that fills it, and a mark for what would be here. Two sizes. The default replaces the table or the list that would have shown, in that space, in a dashed frame so an empty region is visibly a region and not content the eye skips. The compact size sits inside a card, a rail or a panel, the mark beside the text, with no frame of its own because the card's border is the frame. An empty state is a title as a positive statement, a body that says what to do, a primary action and a secondary link, left-aligned as a block; in a small container the image goes when space is tight, and several empties in view take tertiary buttons. A line of grey text where rows would be is none of these: it reads as a row that failed to load, and it gives no way out.

## Anatomy

| Part        | What it is                                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Frame       | Default only: a dashed `color.border` hairline, `radius.large`, `space.200` inline and `space.300` block. Nothing is filled.            |
| Icon        | A mark for what would be here, in a neutral circle: 40px above the title, 32px beside the text when compact. Off when the space is tight. |
| Title       | `font.body` medium in `color.text`: what would be here, or what to start with.                                                          |
| Description | One line, `font.body.small` subtle: why it is empty and what fills it.                                                                  |
| Action      | One Button, secondary unless it is the page's one thing to do; a link button when several empties are in view, so its label sits on the text's edge. |
| Secondary   | A TextLink beside the action: a second way, or where to read more.                                                                      |

## Variants

Three kinds, one component:

| Empty       | Use                                                                                                          |
| ----------- | ------------------------------------------------------------------------------------------------------------ |
| No data     | First use: "Start by linking evidence", with the action that starts.                                         |
| No results  | A search or a filter with nothing: "No controls match", with a search icon and "Clear filters" as a link button. |
| Cannot show | A permission or a system fault: "Evidence is not available to the assessor", with the way to get it, if any. |

Not built, and why: an illustration, because the product has none drawn yet, and the icon slot is where one goes when it does; a third action, because two ways are enough and the third is a menu; a centred large layout, because a page here is never empty as a whole: its header and its filters remain and the frame sits where the rows would; a loading state beside the actions, because the space before it is known to be empty is a Skeleton.

## Sizes

| Size      | Layout                                                                          | Where                                                                                     |
| --------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| `default` | The framed block; the icon above the title, 40px; the text left-aligned under it. | Where a table or a list would be: a tab, a section, a page's body.                        |
| `compact` | No frame; the icon beside the text, 32px, centred on the block; the text and the action to its right. | Inside a card, a rail, a panel, a Related: the container's border is the frame.           |

Both are as wide as the space they fill. Under 320px the action wraps under the line, and the compact icon comes off first.

## States

An empty state has one state. When rows arrive it is gone; it never sits beside content.

## Modifiers

- **`title`**, **`description`**, **`action`**, **`secondary`**, **`icon`**, **`size`** as in Anatomy and Sizes.

## Content

- **The title as a positive statement** where it can be: "Start by adding a system" over "You don't have any systems".
- **The line says why and what fills it**: "Nothing on this control has been observed yet."
- **The action is the verb that fills it**: "Link evidence", "Record a finding". For no results, the way back: "Clear filters".
- **The icon is what would be here**, not a warning: a link for linked records, a search for no results, a file for evidence. Never an exclamation mark.
- **One primary per page.** Several empties in view take link buttons: a subtle button's label sits `space.150` in from the text above it and floats.
- **No exclamation, no apology.** An empty register is a fact.

## Style

| Element     | Token                                                                                                |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| Frame       | `color.border` dashed · `radius.large` · `space.200` inline · `space.300` block                      |
| Icon        | `color.background.neutral` circle · `color.icon.subtle` · 40px with a 20px icon; compact 32px with 16px |
| Title       | `font.body` medium · `color.text`                                                                    |
| Description | `font.body.small` · `color.text.subtle`                                                              |
| Actions     | `space.075` above · `space.150` between the button and the link                                      |
| Layout      | `space.075` between the lines, left-aligned as a block; compact `space.150` between the icon and the text, `space.025` between the lines |

## Accessibility

- **The empty state replaces the element**: no table headers over nothing, so a screen reader does not read a table to reach the line that says there is none.
- **Text, then the controls**: the title and the line are read first, the action and the link are stops after them.
- **The icon is hidden.** It says to the eye what the title says to everyone.
- **Not a live region.** An empty result of a search is announced by the search's own status, not by the frame.
- **The frame is decoration**: the dashed border says "region" to the eye; the words say it to everyone.
