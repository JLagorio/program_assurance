# Editable

A value edited where it sits. The reader clicks it, changes it, and it saves: no form, no Save button, no dialog. It commits at once and shows the save beside the value; a refused save puts the old value back with the reason under it. **Editable.Text** edits text, with `multiline` for full paragraphs; **Editable.Select** is one of a fixed set, drawn as the record draws it.

It is for one value on a record that already exists: the owner in the rail, the next action in a table's cell, the status as a Badge. A record that does not exist yet is a [form](?path=/docs/patterns-forms--docs); several values that change together are a form in a Dialog; a paragraph uses `Editable.Text multiline` to edit in a Textarea in the same cell.

## Anatomy

| Part    | What it is                                                                                                                                                                      |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Row     | A button the full width of its cell, 24px tall. The value sits flush on the text column; under the pointer the row tints, the tint reaching `space.050` past the value.         |
| Value   | The committed value in `font.body`, one line that truncates. Empty, the `placeholder` in `color.text.subtlest`, or the muted dash.                                              |
| Mark    | At the end of the row: a Spinner while saving, a check in `color.icon.success` for a moment after, a warning in `color.icon.danger` after a refusal. A chevron on a Select.     |
| Field   | Text, editing: an input of `dimension.control.xsmall` in the value's place, its box reaching `space.050` past the column so the text stays on it.                               |
| Menu    | Select, editing: the options under the row, the current one marked, and nothing else; a short set uses Select; a long set uses Combobox with its search input inside the popup. |
| Message | Under the row in `font.body.xsmall` and `color.text.danger`: what `validate` refused, or why the save failed.                                                                   |

## Variants

Two, by what the value is. **Text** for a value the reader writes: a name, an acronym, a next action, a date typed as text. **Select** for one of a fixed set: a status, a method, an owner from a roster, drawn by `render` as the record draws it, a Badge or a Person, so the rail and the table agree.

Where it lives: in a [KeyValue](?path=/docs/components-keyvalue--docs) row of the rail, in a [Fact](?path=/docs/components-fact--docs), in a [Table](?path=/docs/components-table--docs) cell under the column's heading. A [DataTable](?path=/docs/patterns-datatable--docs) column with `editable` draws these itself.

<Canvas of={Stories.InTable} />

Use `multiline` for criteria and other paragraphs: the entire value wraps at rest, and the textarea grows with its content. Enter adds a newline, Ctrl/Cmd+Enter or leaving the cell saves, and Escape cancels and returns focus. Validation and save recovery are the same as single-line text.

## Sizes

One: 24px, `dimension.control.xsmall`, so the row is a line of body text with `space.025` above and below, the height of the KeyValue row and the table cell it sits in. The width is the cell's.

Each instance accepts one save at a time. While saving, the resting control cannot reopen for another edit. A rejected save restores its previous value only while this request still owns the current value; an external update is preserved. Completion after unmount is ignored. The caller remains responsible for reconciling server updates to the record.

## States

| State   | Look                                                                                                                                         |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Rest    | The value, flush. Nothing says it edits until the pointer arrives; the rail's rows all edit, so nothing needs to.                            |
| Hover   | The row tints `color.background.neutral.subtle.hovered`; pressed, `.pressed`.                                                                |
| Focus   | The kit's focus outline on the row.                                                                                                          |
| Editing | Text: the field in the value's place, focused, the existing value ready to edit. Select: the listbox or searchable popup open under the row. |
| Invalid | Editing, the field's border `color.border.danger` and the message under it, as the reader types. The commit is refused while it shows.       |
| Saving  | The new value shows at once and a Spinner sits at the end of the row.                                                                        |
| Saved   | A check for `motion.duration.slower` twice, then nothing.                                                                                    |
| Failed  | The old value is back, the warning mark at the end, the reason under the row. It stays until the next edit.                                  |
| Empty   | The placeholder in `color.text.subtlest`, or the muted dash. Never a grey instruction.                                                       |

There is no disabled state. A value the reader cannot change is plain text in the same row, which lines up with the editable ones.

## Modifiers

- **`validate`**: a function of the draft that returns a message or null. It runs as the reader types and again at the commit, so a rule is seen before Enter is refused.
- **`save`**: a promise. Resolved, the check; rejected, the rollback and the error's message. `onChange` is called at once with the new value, and again with the old one when the save fails, so the caller's state is always what the reader sees.
- **`placeholder`** on Text: what goes here, as a noun.
- **`options`** and **`render`** on Select: the set, and how a value is drawn.
- **`label`**: the field's name for a screen reader. The KeyValue or the column shows the visible one.

## Content

- **The label is the field's name as the rail shows it:** "Owner", "Next action". The same word as the KeyValue's label or the column's heading.
- **A placeholder says what goes here, as a noun:** "Unassigned", "Add next action". Not "Click to edit", not "Enter a value".
- **A validation message says the rule, in one sentence:** "Two to twelve letters, digits or hyphens." Not "Invalid".
- **A save failure says why, from the server's message when it has one,** and "Could not save" when it does not.
- **A Select's options are the record's words,** drawn as the record draws them.

## Accessibility

- **The row is named by the label and the value:** "Owner: Dana Whitfield". The label is read before the value, so a screen reader hears what the field is where a sighted reader reads the KeyValue's label beside it.
- **The field is named by the label** (`aria-label`) and, invalid, is `aria-invalid` and described by the message.
- **Keyboard:** Tab reaches the row; Enter or Space opens the field with the existing value; Enter commits and Escape puts the old value back, and either returns focus to the row. Leaving the field by Tab or a click commits and focus goes where the reader sent it. Select and searchable Combobox triggers expose the native combobox role. Enter, Space or Down opens the options; arrows move between them and Enter chooses. Escape closes without changing the value. While saving, the trigger stays focusable and read-only, with `aria-disabled` announcing that another edit must wait.
- **A landed save is announced:** "Saved", or "Not saved", from a status region under the row; the Spinner says "Saving".
- **The stories** exercise validation, keyboard selection, search, save rejection, rollback, pending guards and focus restoration in both themes.

## Props

Editable keeps its value, validation and save contract while composing the shared Input, Select and Combobox. No application API migration is required. The searchable popup follows [shadcn](https://ui.shadcn.com/docs/components/base/combobox#popup) and [Base UI](https://base-ui.com/react/components/combobox#input-inside-popup).

### Editable.Text

| Prop          | Type                                  | What it is                                                                       |
| ------------- | ------------------------------------- | -------------------------------------------------------------------------------- |
| `label`       | `string`, required                    | The field's name for a screen reader: "Owner".                                   |
| `value`       | `string`, required                    | The committed value, shown at rest.                                              |
| `onChange`    | `(next: string) => void`, required    | Called at once with the new value, and with the old one again if the save fails. |
| `save`        | `(next: string) => Promise`, required | Saves it. Rejected, the value rolls back and the error's message shows.          |
| `validate`    | `(next: string) => string \| null`    | A message blocks the commit; null lets it through.                               |
| `placeholder` | `string`                              | What goes here, as a noun, shown while empty.                                    |

### Editable.Select

| Prop         | Type                               | What it is                                                                                                |
| ------------ | ---------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `label`      | `string`, required                 | The field's name, for the screen reader; the options have no heading.                                     |
| `value`      | `T`, required                      | The current option.                                                                                       |
| `options`    | `readonly T[]`, required           | The set, in the order it shows.                                                                           |
| `onChange`   | `(next: T) => void`, required      | As Text.                                                                                                  |
| `save`       | `(next: T) => Promise`, required   | As Text.                                                                                                  |
| `validate`   | `(next: string) => string \| null` | As Text: a status the record is not ready for, with the reason.                                           |
| `render`     | `(value: T) => ReactNode`          | Draws a value: a Badge, a Person. Unsaid, the value as text. The searched list shows the values as words. |
| `searchable` | `boolean`                          | A search field over the options, shown as words. On by itself past eight options.                         |
