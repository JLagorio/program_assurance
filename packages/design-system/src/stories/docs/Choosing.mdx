# Choosing a part

The catalog is organised by family. This page is organised by need: find the row that names what the reader has to do, then open the part's own page for its props and states. When two parts look alike, the row says which one and why. A need with no row is a gap to flag, not a reason to build a raw element.

## Show a value

| The reader needs to see                                                                    | Use                                                                                                                                                                                                                                   | Not                                                                                           |
| ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| A record's status, one word in a pill                                                      | **Badge** with a tone. One pill per row, in the status column.                                                                                                                                                                        | Indicator, which is never a pill.                                                             |
| Severity or health beside a label                                                          | **Indicator** (a Dot and a word), or the bare **Dot** in a tight cell.                                                                                                                                                                | A second Badge in the row.                                                                    |
| How many: unread, rows behind a filter, findings                                           | **Count**, after the name of what it counts.                                                                                                                                                                                          | A Badge holding a number.                                                                     |
| An identifier: AC-2(3), FND-2231, a hash                                                   | **Id**. Tabular numerals, inherits everything else.                                                                                                                                                                                   | CodeBlock, or a Badge.                                                                        |
| An identifier the reader will paste into a ticket                                          | **Id** with an icon-only **CopyButton** (`label="Copy ID"`) beside it.                                                                                                                                                                | A CodeBlock around one id.                                                                    |
| A label and value on one baseline, above the fold                                          | **Fact**, and **Fact.Group** for the four to six facts under a title.                                                                                                                                                                 | KeyValue, which is a rail row.                                                                |
| A label and value in a rail, one per line                                                  | **KeyValue** in a **KeyValue.Group**, which shares the label width and puts the label over the value when narrow; **Inspector** for a folding group of them.                                                                          | A hand-written definition list.                                                               |
| A headline number                                                                          | **Stat**; **Stat.Tile** in a **Stat.Grid** when framed.                                                                                                                                                                               | A Heading holding a number.                                                                   |
| A value that is missing                                                                    | **Absent**, the muted dash; with `label` ("Not recorded") when a screen reader should hear it.                                                                                                                                        | An empty string, a hyphen typed by hand, or "N/A".                                            |
| A name or value that stays on one line in a row, a rail or a list, readable in full        | **Truncate**, or Text `maxLines`; KeyValue does it itself. **useIsTruncated** when you cut the text yourself.                                                                                                                         | Truncating a sentence, a heading, an error or a notification, which wrap.                     |
| A mark that stands for something with no word beside it: a boundary, a met check           | **Icon** with a `label`; without one when it sits beside its word.                                                                                                                                                                    | A bare glyph, or an Icon that acts, which is an IconButton.                                   |
| Words only a screen reader needs: a mark's meaning, a heading the outline needs            | **VisuallyHidden**.                                                                                                                                                                                                                   | An `sr-only` span written by hand.                                                            |
| A section's name in a rail, a record's kind over a title                                   | **Eyebrow**.                                                                                                                                                                                                                          | A small Heading.                                                                              |
| A labelled paragraph, or authored text in several paragraphs or Markdown                   | **Prose**: a string child keeps its paragraphs and line breaks; `markdown` with `renderLink` for Markdown. **Text** `preserveLineBreaks` for one short note.                                                                          | Text with a bold first line, or HTML set by hand.                                             |
| Two or more short points: messages, conflicts, steps                                       | **List**, `ordered` for steps.                                                                                                                                                                                                        | Records, which are an Item.Group or a DataTable; labelled values, which are a KeyValue.Group. |
| A person                                                                                   | **Person**; **Avatar** and **AvatarGroup** for the mark alone.                                                                                                                                                                        |                                                                                               |
| A file                                                                                     | **Attachment**; **Attachment.Link** when the card opens or downloads a URL; **formatFileSize** in its description. The application owns upload, retry and removal.                                                                    | An anchor with the overlay classes copied onto it, or a raw byte count.                       |
| A date or a moment: updated, collected, a milestone                                        | **DateTime**, in the provider's locale and zone.                                                                                                                                                                                      | `toLocaleString`, or a formatter of your own.                                                 |
| How long ago, for activity and recency                                                     | **RelativeTime**; the exact value is its tooltip.                                                                                                                                                                                     | "2h ago" written by hand.                                                                     |
| A due date, an expiry or a milestone the reader acts on                                    | **DateLabel**: overdue, due today and due soon in words and an icon.                                                                                                                                                                  | A date in red text.                                                                           |
| What changed between two versions of a text                                                | **Diff**, inline, or side by side on a wide page; **diffText** for the counts alone.                                                                                                                                                  | Two full copies side by side, or both values in table cells.                                  |
| Source, a log, a command to paste                                                          | **CodeBlock** with `copy` when the reader will take it.                                                                                                                                                                               | A `<pre>`.                                                                                    |
| A keyboard shortcut                                                                        | **KbdShortcut** with `keys="Mod+K"`: the platform's glyphs and one spoken name. **useFormatShortcut** or **formatShortcut** for the same shortcut as text or `aria-keyshortcuts`. **Kbd** and **KbdGroup** for caps composed by hand. | A ⌘ or Ctrl cap chosen per screen, or a branch on the platform.                               |
| Events in order                                                                            | **Timeline**.                                                                                                                                                                                                                         | A Table of dates.                                                                             |
| Steps through an ordered path                                                              | **Stepper**.                                                                                                                                                                                                                          | Tabs.                                                                                         |
| What an action or a step waits on: the checks before a create, the conflicts before a save | **Gates**: each condition met or not, with what is missing and the one action that meets it; a list, never a score.                                                                                                                   | Progress, or reasons in a bordered Box or a grey line beside a disabled button.               |
| A completion fraction                                                                      | **Progress**; **ProgressStacked** for parts of a whole.                                                                                                                                                                               | A Stat with a percentage, unless it is the headline.                                          |
| Numbers drawn                                                                              | **Chart** and one of its kinds: Bar, Line, Area, Donut, Scatter, Heatmap, Treemap, Sparkline. **Chart.Frame** holds the data, size and format once, for a bare part inside.                                                           | A hand-drawn SVG, or the same props on the Frame and the part.                                |
| A chart's numbers as a table                                                               | **Chart.Frame** around the part: its Table toggle and its CSV lay out what the part draws. Name the columns with `xLabel`, `columns`, Scatter `zLabel` and Treemap `levels`. A colour-scale Heatmap in a Frame also offers Values.    | A separate Table beside the chart, or a `title` on hover.                                     |

## Lay it out

| The layout is                                                                                                           | Use                                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Things stacked top to bottom with one gap                                                                               | **Stack** with a `space` token.                                                                                                                                                                   |
| Things left to right with one gap, wrapping                                                                             | **Inline**.                                                                                                                                                                                       |
| Something Stack and Inline cannot say                                                                                   | **Flex**.                                                                                                                                                                                         |
| Columns                                                                                                                 | **Grid** with token gaps.                                                                                                                                                                         |
| A padded or coloured block                                                                                              | **Box**. Padding and background are token-typed; there are no margins.                                                                                                                            |
| A child escaping its parent's padding                                                                                   | **Bleed**, the only negative space.                                                                                                                                                               |
| A titled region of a page                                                                                               | **Section**, with `count`, `description` and `action` when needed.                                                                                                                                |
| A collapsed Details block on a page body: provenance, counts, derivation                                                | **Section** with `title` and `isCollapsible` (`defaultOpen` to start open). Not a subtle Button with a chevron, or a native `<details>`.                                                          |
| A folding group of facts in a Details rail                                                                              | **Inspector.Group**, `defaultOpen={false}` when it starts closed.                                                                                                                                 |
| The page's name and its actions                                                                                         | **PageHeader**: Lead, Heading, Title, Description, Actions.                                                                                                                                       |
| A record's name in a preview or a sheet body                                                                            | **PageHeader.Title**, which takes its level from the context or `render`. Not a raw h2 with the Title's classes.                                                                                  |
| The application frame                                                                                                   | **Shell** and its areas: Banner, TopNav, SideNav, Main, Aside, Panel.                                                                                                                             |
| Focus and an announcement when a client-side route changes the page                                                     | **Shell** `locationKey` (the router's resolved pathname or route id), with `getPageTitle` for other words.                                                                                        |
| A phone side-nav overlay that stays open while its links change the page in place                                       | **Shell.SideNav** `closeOnNavigate={false}`.                                                                                                                                                      |
| The product's search in the top nav                                                                                     | **Shell.TopNav.Search** in TopNav.Middle: a field-shaped button in a top nav at least 48rem wide, an icon button narrower, ⌘K from anywhere. It opens a **SearchDialog**.                         |
| Actions and destinations at the end of the top nav                                                                      | **Shell.TopNav.Item** in **Shell.TopNav.End**: they fold into one More menu when the top nav is narrow; the ModeSwitch and `persistent` items stay. Not a hand-built `md:hidden` menu.            |
| A part that switches layout on its own width, in a panel, a rail, a card or a dialog                                    | A container query on a **dimension.container** size: name the container and query it by name (`@md/<name>:`). A new switch point is a new token; viewport breakpoints belong to page-level parts. |
| Two panes the reader resizes                                                                                            | **ResizablePanelGroup**.                                                                                                                                                                          |
| A region that scrolls with the platform's own scrollbar: a dialog's body, a panel, a list                               | Native overflow on the region the kit already gives it (DialogBody, SheetBody, Shell.Panel, DataTable's frame). Not a ScrollArea or Scroller added around it.                                     |
| A scrolling region with a visible bar the reader can drag                                                               | **ScrollArea** and **ScrollBar**.                                                                                                                                                                 |
| A list or a strip of your own that scrolls, with an arrow at each edge that can still scroll, as menus and line Tabs do | **Scroller**, with **ScrollerViewport** and a **ScrollerArrow** per edge; it reveals a focused item on its own axis. Not an `overflow-auto` div with arrows written by hand.                      |
| A hairline between things                                                                                               | **Separator**. The parent owns the spacing around it.                                                                                                                                             |
| A raised container for a table, chart or facts                                                                          | **Card**.                                                                                                                                                                                         |

Body copy is **Text**; titles are **Heading** with the size from the design and the level from where it sits. A part's own title (PageHeader.Title, a Section's title, a Heading without `as`) reads the heading-level context; put a **HeadingLevelProvider** where an outline starts, with `level` in a portal, a rail or a dialog body, rather than `as` on every heading inside.

## Collect input

| The reader enters                                                      | Use                                                                                                                                                                                                                                               | Not                                                                                                                                        |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Any control's label, hint and error                                    | **Field** and its parts: FieldLabel, FieldDescription, FieldError. Pass `invalid`, `required` and `disabled` to the Field, which wires the ids. Field owns layout; the form owns values and validation.                                           | Hand-wired ids and `aria-describedby`, or red text beside the control.                                                                     |
| What fixes one field                                                   | **FieldError** inside the Field, with children or `errors`.                                                                                                                                                                                       | An Alert, or `role="alert"` text.                                                                                                          |
| Every error after a failed submit, each leading to its field           | **ErrorSummary** above the form, `focusKey` the submit count; `onSelect` opens another step or tab.                                                                                                                                               | A list in an Alert, or FieldError alone in a long or multi-step form.                                                                      |
| A required field                                                       | Field `required`, announced with the asterisk; native `required` on the control only when the browser should check it.                                                                                                                            | A hand-written asterisk, or "(optional)" in a placeholder.                                                                                 |
| Fields locked while a save runs                                        | **FieldSet** `disabled`, which reaches every control inside.                                                                                                                                                                                      | A raw `<fieldset disabled>`.                                                                                                               |
| One line of text                                                       | **Input**; **InputGroup** when it carries an icon, a unit or a button.                                                                                                                                                                            |                                                                                                                                            |
| Several lines                                                          | **Textarea**.                                                                                                                                                                                                                                     |                                                                                                                                            |
| A query that finds or narrows records, as the reader types or on Enter | **SearchField**.                                                                                                                                                                                                                                  | Input `type="search"` in a hand-built InputGroup; a search box for a value the record keeps.                                               |
| A quantity the reader types or steps: days, a budget, a count          | **NumberField**.                                                                                                                                                                                                                                  | Input `type="number"`.                                                                                                                     |
| Digits that name something: an identifier, a build number, a postcode  | **Input** with `inputMode="numeric"`.                                                                                                                                                                                                             | NumberField, which drops leading zeros and adds steps and separators.                                                                      |
| One of a few known values                                              | **Select**; **RadioGroup** when all the choices should be visible.                                                                                                                                                                                |                                                                                                                                            |
| One of many values, by typing                                          | **Combobox**. It filters; Select does not.                                                                                                                                                                                                        | A SearchField with a hand-built list.                                                                                                      |
| Several values as chips                                                | **Combobox** with `ComboboxChips`.                                                                                                                                                                                                                |                                                                                                                                            |
| Yes or no                                                              | **Checkbox** in a form; **Switch** when it takes effect at once.                                                                                                                                                                                  |                                                                                                                                            |
| Several choices that can each be true                                  | **CheckboxGroup** with a FieldLegend, and **CheckboxGroupSelectAll** with `allValues` for select-all. Put the group in a Field to describe and validate it; a required Field's legend says "(required)". Each choice is its own horizontal Field. | A FieldSet of loose checkboxes, `aria-invalid` on every item, or records from a long list, which are DataTable selection or a PickerSheet. |
| A pressed state on a button                                            | **Toggle**; **ToggleGroup** for one-of or many-of.                                                                                                                                                                                                |                                                                                                                                            |
| A day                                                                  | **DatePicker**; `entry="type"` for a day the reader already knows; **Calendar** on its own when the month should stay open.                                                                                                                       |                                                                                                                                            |
| A time of day, with no date                                            | **TimeField**.                                                                                                                                                                                                                                    | Input `type="time"`.                                                                                                                       |
| A moment: a day and a time                                             | **DateTimeField**, which names the zone.                                                                                                                                                                                                          | `datetime-local`.                                                                                                                          |
| A range of days                                                        | **DateRangePicker**, with presets for periods; two DatePickers with `min` and `max` when the ends stand apart.                                                                                                                                    |                                                                                                                                            |
| Files, from a compact spot: a form row, a composer, a toolbar          | **FileTrigger** in a Field, with the constraints in a FieldDescription.                                                                                                                                                                           | Input `type="file"`, which reads as a line of text.                                                                                        |
| Files, dropped or chosen, checked against types and a size             | **DropZone** in a Field, with the constraints as its FieldDescription child; the accepted files become Attachment rows.                                                                                                                           | A primary that stays disabled until a file is chosen.                                                                                      |
| A filter on a register                                                 | **FilterChip** in a **Toolbar**.                                                                                                                                                                                                                  |                                                                                                                                            |
| A short draft with mentions                                            | **Composer**.                                                                                                                                                                                                                                     |                                                                                                                                            |
| A whole form                                                           | The **Forms** pattern: Field, controls, primitives and Buttons. There is no Form component. A create or edit form in a Dialog follows the form recipe on Guidance/Recipes.                                                                        | A Sheet or a page, outside a product's named exceptions.                                                                                   |

## Pick records

| Choosing                                                      | Use                                                                                                                                                                         |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| One value from a short, fixed list                            | **Select**.                                                                                                                                                                 |
| One value from a long list, by typing                         | **Combobox**.                                                                                                                                                               |
| One record with an id, a name and a status, by typing         | **RecordPicker**: a Command dialog with record rows. The caller supplies the rows.                                                                                          |
| A record of any type, found by name or identifier, to open it | **SearchDialog**, opened by **Shell.TopNav.Search** or ⌘K. The caller hands over the records, or runs the search itself (`filter={null}`). Not a CommandPalette of records. |
| Many records from hundreds, with filters and a running count  | **PickerSheet**: a Sheet whose body is a DataTable with selection.                                                                                                          |
| Related records the reader must compare before choosing       | **RecordBrowser**: search, compare, preview and select without leaving the record.                                                                                          |
| A command, not a record                                       | **CommandPalette** (⌘K) over the page; **Command** parts to build a list of your own.                                                                                       |

The task decides it, not the number of rows.                                                                                   |

| A summary of linked records in a rail or a card: how many, a way to add one, the few that matter                                                             | **Related**: a card with a Count, a way to add one, a row or card per record. Linked records the reader works through are an embedded **DataTable**.          |
| One compact record row with aligned parts                                                                                                                    | **Item**.                                                                                                                                                     |
| A checklist or work queue row                                                                                                                                | **TaskRow**.                                                                                                                                                  |
| A long list decided one record at a time, the chosen record's detail beside it: tailoring controls, setting parameters                                       | **WorkPane**: side by side when wide, a drill-in with Back to the row when narrow. A list the reader scans, sorts and filters is a DataTable.                 |
| The next record without leaving the list                                                                                                                     | **PreviewNavigation** in a **Shell.Panel**; **PreviewSheet** only when the task must hold focus.                                                              |
| A record's summary on hover                                                                                                                                  | **HoverCard** holding a **Glance**.                                                                                                                           |
| Search, views, filters and actions above a table                                                                                                             | **Toolbar**: search, `views`, `filters`, children, `actions`.                                                                                                 |
| The sort, seen and set when the headers fold: a register on a phone or beside a panel                                                                        | **DataTable.Sort** among the Toolbar's display controls. A table that never folds keeps its headers' sort.                                                    |
| A column's width, set without dragging                                                                                                                       | `resizable` on useDataTable: the column menu's Wider, Narrower and Reset width.                                                                               |
| Columns or rows the reader puts in their own order                                                                                                           | `reorderable` on useDataTable for columns (a grip and Move left or right in the column menu); `reorderRows` for rows, which turns sorting off while it is on. |

| A thousand rows or more in one scrolling frame                                                                                                               | `virtualize` on useDataTable with a `maxHeight` on the table, and no `pageSize`.                                                                              |
| A register's search, sort, filters and page, kept after the reader opens a record and comes back                                                             | **useTableQuery** with `storage: "session"`, or `search` and `onSearchChange` for a shareable URL. | A link to a filtered register, without a table                                                                                                               | **tableQueryToString**, **tableQueryToSearch** and **tableQueryFromSearch**.                                                                                  |
| One status vocabulary (label, tone, order) shared by several columns                                                                                         | `c.status` with a **StatusMap**; `tone` for a one-off column.                                                                                                 |
| Page controls                                                                                                                                                | **Pagination**; DataTable draws its own.                                                                                                                      |

## Overlays

Eight surfaces float over the page. The Overlays page holds the full table with what opens and closes each; the short form:

| Need                                       | Use                                                         |
| ------------------------------------------ | ----------------------------------------------------------- |
| A short label                              | **Tooltip**. IconButton already draws one from its `label`. |
| A peek at a record, no actions             | **HoverCard**                                               |
| A small task at its button                 | **Popover**                                                 |
| A list of actions                          | **DropdownMenu**                                            |
| A focused task over the page: create, edit | **Dialog**                                                  |
| A modal selection or review                | **Sheet**                                                   |
| A quick task on a narrow screen            | **Drawer**                                                  |
| A decision that needs a word first         | **AlertDialog**                                             |

A value edited where it sits, with no form and no Save, is **Editable**. A larger change is a Dialog.

Inside an overlay:

| Need                                                                       | Use                                                                                                                                         |
| -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| The scrolling content between the header and the footer                    | **DialogBody**, **SheetBody**, **DrawerBody** or **AlertDialogBody**. Not a hand-written overflow div, a Card or a ScrollArea.              |
| The overlay held open while its save runs                                  | `pending` on Dialog, Sheet or AlertDialog, with `<FieldSet disabled={pending}>` and the submit Button's `isLoading`.                        |
| A dialog's or a sheet's width                                              | `width` on DialogContent or SheetContent: small, medium, large, xlarge, fullscreen. AlertDialog takes `size`. Not a pixel `style.maxWidth`. |
| What a destructive decision affects: the records a delete removes          | **AlertDialogBody** under the header, not a long AlertDialogDescription.                                                                    |
| A sticky header, a pinned cell or a fade that matches the surface under it | `bg-surface-current`: every overlay records its surface.                                                                                    |

## Navigate and act

| The reader                                                  | Use                                                                                                                                                                                                                          |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Goes somewhere, reading as text                             | **TextLink** with a router link through `render`.                                                                                                                                                                            |
| Goes somewhere, looking like a button                       | **LinkButton** with a router link through `render`; **LinkIconButton**, with a required `label`, for an icon alone. Not a Button that navigates from `onClick`.                                                              |
| Does something                                              | **Button**; **IconButton** with a required `label` when the icon is unambiguous.                                                                                                                                             |
| Cannot do something yet, and needs to know why              | `disabledReason` on **Button**, **IconButton**, **LinkButton**, **DropdownMenuItem** or **Shell.TopNav.Item**: still reachable, with the reason as its description. Not `disabled` alone, or a `title` on a disabled button. |
| Tells two similar menu actions apart                        | DropdownMenuItem `description`. Not a Tooltip inside a menu.                                                                                                                                                                 |
| Copies a value to paste elsewhere: an id, a command, a link | **CopyButton**; `label` for the icon-only form.                                                                                                                                                                              |
| Downloads a file the page built: an export, a CSV           | A Button or an Attachment Trigger that calls **downloadBlob** or **downloadText** (`bom: true` for a CSV).                                                                                                                   |
| Chooses among joined actions                                | **ButtonGroup**.                                                                                                                                                                                                             |
| Sees where they are                                         | **Breadcrumb** in `PageHeader.Lead`, its trail links made with the router's `createLink(BreadcrumbLink)` or matched exactly, so only BreadcrumbPage is current.                                                              |
| Switches between views of one page                          | **Tabs** with `TabsList variant="line"`.                                                                                                                                                                                     |
| Opens a region                                              | **Collapsible** with **CollapsibleHeader** for a titled disclosure; **Accordion** when only one opens at a time; **Item** `isCollapsible` for a row.                                                                         |
| Switches colour mode                                        | **ModeSwitch**, inside **ModeProvider**.                                                                                                                                                                                     |

## Feedback and states

| The situation                                                    | Use                                                                                                                                                                    |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A region with nothing in it                                      | **Empty** with an illustration, a title, one line and the next step; `render={<h1 />}` on EmptyTitle when it is the page's only content. DataTable draws its own.      |
| Something about this record, inline                              | **Alert** with a title, a description and an action.                                                                                                                   |
| Something about the whole site                                   | **Banner**, one at a time, in the shell's Banner area.                                                                                                                 |
| Short feedback after an action                                   | **Toaster**, mounted once.                                                                                                                                             |
| A change that moves no focus: a result count, a save, a new page | **announce**, through the **Announcer** that Shell mounts; mount one near the root without a Shell. A field's error stays in FieldError, and a toast announces itself. |
| Content with a known shape still loading                         | **Skeleton**; **PageSkeleton** for a page's first paint.                                                                                                               |
| An action in flight                                              | **Spinner**, or Button's loading state.                                                                                                                                |
| A failure                                                        | An Alert with a retry. Never a blank region.                                                                                                                           |
| Density of a table                                               | **Table** `density`; DataTable's Columns menu offers Compact rows.                                                                                                     |

## Across the product

| The product needs                                                                     | Use                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The reader's locale, time zone and direction, and the kit's words in another language | **LedgerProvider** once near the root, the same on the server and the client, and **useLedgerLocale** for its formatters in your own code; see [Locale](?path=/docs/components-locale--docs). Not `toLocaleString`, the host's zone, or a copy of a kit label. |
| More contrast for a reader who asks for it                                            | Nothing per part: `prefers-contrast: more`, or `data-contrast-mode="more"` on `html` (`"no-preference"` pins standard). The tokens follow. Not a contrast prop, a darker class or a bolder border picked for one control.                                      |
| Its typeface                                                                          | `@import "@ledger/design-system/fonts.css"` beside ledger.css: Geist Variable, self-hosted. Not a Google Fonts link or a copied `@font-face`.                                                                                                                  |

## Not in the kit

These have no part yet. A screen that needs one says so in writing, with a recommendation, before building anything:

- A slider or a range slider, and a one-time-code input.
- A navigation menu, a menubar, a context menu, a carousel.
- A rich-text editor beyond Composer's short drafts with mentions.
- A board of cards in columns (a kanban), and a calendar of events.
- A file upload service: DropZone and FileTrigger choose and check files, and the application uploads them.
