# Coming from shadcn, Radix and Base UI

Ledger's families are built from shadcn's Base UI compositions, so most names are the ones you know. The APIs are not identical, and the differences are exactly where an agent invents a prop. Read this page once, then look every prop up on the family's page before using it.

## The three differences that matter most

**`render`, not `asChild`.** Ledger is on Base UI, not Radix. A part composes another element through `render={<a href="…" />}` (or a function). `asChild` does not exist anywhere in the package.

**Tokens, not the shadcn theme.** There is no `bg-background`, `text-muted-foreground` or `bg-primary` from shadcn's CSS variables, and no `dark:` variant. Every colour, space, radius and type value is a Ledger token utility (`bg-surface`, `text-subtle`, `border-default`, `p-200`, `font-body-small`) or a primitive prop. The lint rejects the rest; the theme names below say what each shadcn colour is in Ledger, and the Which token page lists what to reach for. Two names are the same in both: `border-input` and `bg-input` are Ledger's own tokens for a field's border and background.

**`cn` from the package.** Import it from `@ledger/design-system/cn`. There is no `lib/utils`.

## Theme names

shadcn's colour names and the Ledger class for the same job. The lint reports each of these with the class to write, which it also offers as an editor suggestion when the class does the same job; with an opacity modifier (`bg-muted/50`), it names the colour and leaves the shade to a state token, since Ledger never dims a token with alpha.

## Name by name

| You know                                                                          | In Ledger                                                                                                                                         | What differs                                                                                                                                                                                                    |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Button                                                                            | **Button**, **IconButton**, **LinkButton**, **LinkIconButton**                                                                                    | A focus-preserving `isLoading` state and `disabledReason`. IconButton needs a `label` and draws its own Tooltip. Navigation is a LinkButton or LinkIconButton: a real link, the router's Link through `render`. |
| Badge                                                                             | **Badge**                                                                                                                                         | Six variants plus semantic `tone`s and two sizes. A status is one Badge per row; severity is **Indicator**, a number is **Count**.                                                                              |
| Label, Field                                                                      | **Field** and its parts: **FieldLabel**, **FieldDescription**, **FieldError**; **FieldSet** and **FieldLegend** for a group                       | No standalone Label. Field is Base UI's Field.Root: it binds the control inside it and takes `invalid`, `required` and `disabled`. **ErrorSummary** lists a failed submission's errors.                         |
| Form (react-hook-form)                                                            | The **Forms** pattern                                                                                                                             | No Form component. TanStack Form owns state and validation; Field, the controls and the primitives are the presentation.                                                                                        |
| Input                                                                             | **Input**; **SearchField** for a query; **NumberField** for a quantity                                                                            | Input wraps Base UI's Input. Labels and errors belong to Field. A search box is SearchField and a stepped number NumberField, not `type="search"` or `type="number"`.                                           |
| Input Group                                                                       | **InputGroup** and its parts                                                                                                                      | Flat shadcn Base UI composition; addons, text, buttons and a textarea variant.                                                                                                                                  |
| Textarea                                                                          | **Textarea**                                                                                                                                      | A native textarea on Base UI's Field.Control, so a Field binds it as it does Input.                                                                                                                             |
| Select, Native Select                                                             | **Select**                                                                                                                                        | Native Select is removed. Select does not filter; a list that needs typing is **Combobox**.                                                                                                                     |
| Combobox, Command as a picker                                                     | **Combobox**; **RecordPicker** for records                                                                                                        | Combobox is flat Base UI composition with chips. A picker of records with ids and statuses is the RecordPicker pattern.                                                                                         |
| Command (cmdk)                                                                    | **Command** parts, **CommandPalette**                                                                                                             | The palette takes plain command objects and stays presentational.                                                                                                                                               |
| Checkbox, Radio Group, Switch                                                     | Same names; **CheckboxGroup** for several                                                                                                         | Base UI underneath; `render` for composition. CheckboxGroup names the group with a FieldLegend and takes **CheckboxGroupSelectAll**.                                                                            |
| Toggle, Toggle Group                                                              | Same names                                                                                                                                        | Icon-only toggles need `aria-label`.                                                                                                                                                                            |
| Calendar, Date Picker, date and time inputs                                       | **Calendar**, **DatePicker**, **DateRangePicker**, **TimeField**, **DateTimeField**; **DateTime**, **RelativeTime** and **DateLabel** to show one | react-day-picker underneath. DatePicker holds and reports an ISO day, DateRangePicker `{ start, end }` and TimeField an ISO time; DateTimeField a moment in the LedgerProvider's zone.                          |
| Dialog, Alert Dialog, Sheet, Drawer, Popover, Tooltip, Hover Card, Dropdown Menu  | Same names                                                                                                                                        | All Base UI. The Overlays page says which surface fits which task; Drawer is the gesture bottom sheet, Sheet the side panel.                                                                                    |
| Sonner, Toast                                                                     | **Toaster** and the Toast parts                                                                                                                   | Base UI Toast with a native manager API. Mount once near the root.                                                                                                                                              |
| Alert                                                                             | **Alert** with **AlertAction**                                                                                                                    | Explicit title, description and action parts.                                                                                                                                                                   |
| Tabs                                                                              | **Tabs**, `TabsList variant="line"`                                                                                                               | The line variant fills its container with one border and scrolls in one row; do not add wrapping or width classes.                                                                                              |
| Accordion, Collapsible                                                            | Same names                                                                                                                                        | Base UI.                                                                                                                                                                                                        |
| Table                                                                             | **Table** for markup; **DataTable** for state                                                                                                     | DataTable is a TanStack Table 9 instance with columns declared by kind (`defineColumns`), a Toolbar and `fill`; it fits its frame unless `responsive={false}`.                                                  |

## Parts Ledger has that shadcn does not

These carry the product's vocabulary and have no shadcn analogue, so nothing you know applies: **Id**, **Count**, **Indicator** and **Dot**, **Fact**, **KeyValue** and **Inspector**, **Stat**, **Absent**, **Eyebrow**, **Prose**, **List**, **Truncate**, **VisuallyHidden**, **Icon**, **Person**, **Attachment**, **FileTrigger**, **DropZone**, **CopyButton**, **Diff**, **KbdShortcut**, **CodeBlock**, **Timeline**, **Stepper**, **Gates**, **Glance**, **Related**, **TaskRow**, **Composer**, **Editable**, **FilterChip**, **Toolbar**, **Scroller**, **PickerSheet**, **RecordBrowser**, **SearchDialog**, **PreviewSheet**, **PreviewNavigation**, **PageHeader**, **Section**, **CollapsibleHeader**, **HeadingLevelProvider**, **Tree**, **Banner**, **Announcer** and **LedgerProvider**. Read their pages; the Choosing a part page says when each one is the answer.
