# Coming from shadcn, Radix and Base UI

Ledger's families are built from shadcn's Base UI compositions, so most names are the ones you know. The APIs are not identical, and the differences are exactly where an agent invents a prop. Read this page once, then look every prop up on the family's page before using it.

## The three differences that matter most

**`render`, not `asChild`.** Ledger is on Base UI, not Radix. A part composes another element through `render={<a href="…" />}` (or a function). `asChild` does not exist anywhere in the package.

**Tokens, not the shadcn theme.** There is no `bg-background`, `text-muted-foreground`, `border-input` from shadcn's CSS variables, and no `dark:` variant. Every colour, space, radius and type value is a Ledger token utility (`bg-surface`, `text-subtle`, `border-default`, `p-200`, `font-body-small`) or a primitive prop. The lint rejects the rest; the Which token page lists what to reach for.

**`cn` from the package.** Import it from `@ledger/design-system/cn`. There is no `lib/utils`.

## Name by name

| You know                                                                         | In Ledger                                                 | What differs                                                                                                                               |
| -------------------------------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Button                                                                           | **Button**, **IconButton**, `buttonVariants`              | A focus-preserving `loading` state. IconButton needs a `label` and draws its own Tooltip. Navigation is a real link with `buttonVariants`. |
| Badge                                                                            | **Badge**                                                 | Six variants plus semantic `tone`s and two sizes. A status is one Badge per row; severity is **Indicator**, a number is **Count**.         |
| Label                                                                            | **FieldLabel**, inside **Field**                          | No standalone Label. Field owns the label, description and error layout.                                                                   |
| Form (react-hook-form)                                                           | The **Forms** pattern                                     | No Form component. TanStack Form owns state and validation; Field, the controls and the primitives are the presentation.                   |
| Input                                                                            | **Input**                                                 | Wraps Base UI's Input. Labels and errors belong to Field.                                                                                  |
| Input Group                                                                      | **InputGroup** and its parts                              | Flat shadcn Base UI composition; addons, text, buttons and a textarea variant.                                                             |
| Textarea                                                                         | **Textarea**                                              | Native.                                                                                                                                    |
| Select, Native Select                                                            | **Select**                                                | Native Select is removed. Select does not filter; a list that needs typing is **Combobox**.                                                |
| Combobox, Command as a picker                                                    | **Combobox**; **RecordPicker** for records                | Combobox is flat Base UI composition with chips. A picker of records with ids and statuses is the RecordPicker pattern.                    |
| Command (cmdk)                                                                   | **Command** parts, **CommandPalette**                     | The palette takes plain command objects and stays presentational.                                                                          |
| Checkbox, Radio Group, Switch                                                    | Same names                                                | Base UI underneath; `render` for composition.                                                                                              |
| Toggle, Toggle Group                                                             | Same names                                                | Icon-only toggles need `aria-label`.                                                                                                       |
| Calendar, Date Picker                                                            | **Calendar**, **DatePicker**                              | react-day-picker underneath. DatePicker holds and reports an ISO day string.                                                               |
| Dialog, Alert Dialog, Sheet, Drawer, Popover, Tooltip, Hover Card, Dropdown Menu | Same names                                                | All Base UI. The Overlays page says which surface fits which task; Drawer is the gesture bottom sheet, Sheet the side panel.               |
| Sonner, Toast                                                                    | **Toaster** and the Toast parts                           | Base UI Toast with a native manager API. Mount once near the root.                                                                         |
| Alert                                                                            | **Alert** with **AlertAction**                            | Explicit title, description and action parts.                                                                                              |
| Tabs                                                                             | **Tabs**, `TabsList variant="line"`                       | The line variant fills its container with one border and scrolls in one row; do not add wrapping or width classes.                         |
| Accordion, Collapsible                                                           | Same names                                                | Base UI.                                                                                                                                   |
| Table                                                                            | **Table** for markup; **DataTable** for state             | DataTable is a TanStack Table 9 instance with columns declared by kind (`defineColumns`), a Toolbar, `fill` and `responsive`.              |
| Data Table (shadcn recipe)                                                       | **DataTable**                                             | It is a pattern with a hook, not a page recipe you copy.                                                                                   |
| Sidebar                                                                          | **Shell** and its areas                                   | The whole application frame: Banner, TopNav, SideNav with an icon rail, Main, Aside, Panel. Not a standalone sidebar.                      |
| Breadcrumb                                                                       | **Breadcrumb**                                            | `BreadcrumbLink` takes a router link through `render`.                                                                                     |
| Card                                                                             | **Card**                                                  | Same parts, token surfaces.                                                                                                                |
| Avatar                                                                           | **Avatar**, **AvatarGroup**, **AvatarBadge**              | Flat shadcn Base UI composition with Ledger sizes and accents.                                                                             |
| Skeleton, Spinner, Progress                                                      | Same names, plus **PageSkeleton** and **ProgressStacked** |                                                                                                                                            |
| Empty, Item, Kbd, Button Group                                                   | Same names                                                | Same part structure. DataTable draws its own Empty.                                                                                        |
| Chart                                                                            | **Chart** and its kinds                                   | Recharts underneath as in shadcn; Ledger adds the Frame, the table twin, drill-down, export and the chart tokens.                          |
| Resizable, Scroll Area, Separator, Pagination                                    | Same names                                                |                                                                                                                                            |
| Typography (`<h1 className=…>`)                                                  | **Heading**, **Text**, **Eyebrow**, **Prose**             | Type is a composite token on a primitive, never a class list.                                                                              |
| Navigation Menu, Menubar, Context Menu, Carousel, Aspect Ratio                   | Not in Ledger                                             | A need for one is flagged in writing before it is built.                                                                                   |

## Parts Ledger has that shadcn does not

These carry the product's vocabulary and have no shadcn analogue, so nothing you know applies: **Id**, **Count**, **Indicator** and **Dot**, **Fact**, **KeyValue** and **Inspector**, **Stat**, **Absent**, **Eyebrow**, **Prose**, **Person**, **Attachment**, **CodeBlock**, **Timeline**, **Stepper**, **Gates**, **Glance**, **Related**, **TaskRow**, **Composer**, **Editable**, **FilterChip**, **Toolbar**, **PickerSheet**, **RecordBrowser**, **PreviewSheet**, **PreviewNavigation**, **PageHeader**, **Section**, **Tree**, **Banner**. Read their pages; the Choosing a part page says when each one is the answer.
