# Lint rules

The package exports an ESLint plugin whose allowlist is generated by the token build, so the rules and the tokens cannot drift. Two presets: `package` (what this package lints itself with) and `recommended` (for a consumer).

| Rule | Reports | Instead |
| --- | --- | --- |
| `no-arbitrary-value` | `text-[13px]`, `w-[240px]`, `bg-[#eee]` | A token utility or a primitive prop. |
| `no-alpha-token` | `bg-brand-bold/80`, `text-default/60` | The hovered, pressed, subtle or disabled token. |
| `no-dark-variant` | `dark:bg-neutral` | Nothing. Every colour token flips by itself; a `dark:` class means a token is missing. |
| `no-margin` | `mt-200`, `-mx-100` | Stack or Inline space, or Bleed. `m-auto` is allowed. |
| `no-static-design-value` | `rounded`, `opacity-50`, `duration-200`, `border-2`, `ring-2`, `bg-white`, `text-transparent` | `rounded-small…full`, `opacity-disabled`, `duration-fast`, `border-w-selected`, `outline-focused`, a colour token. |
| `no-non-token-class` | Any class that is not a token utility or a documented structural utility (`flex`, `truncate`, `sticky`, `sr-only` …) | A token utility. |
| `no-deprecated-token` | A deprecated token's utility | Its replacement, applied by `--fix`. |
| `use-primitives` | A `div` or `span` carrying `flex`, `grid`, padding or gap classes | Box, Stack, Inline, Flex or Grid. Error in the package, warning in `recommended`. |
| `prefer-text-link` | A `Link` or `a` carrying `text-brand` or `hover:underline`; a `Button variant="link" asChild` | TextLink around the link element. |
| `no-colgroup` | `<colgroup>` | `width` on each Table.Header. |

Inside the package a portability rule also blocks any import from a consumer (`@/…`), from the prototype, or from a router.

## What counts as structural

Display, position, alignment, overflow, text flow and interaction utilities are allowed as written, because they carry no design value: `flex`, `grid`, `relative`, `absolute`, `sticky`, `truncate`, `whitespace-nowrap`, `select-none`, `pointer-events-none`, `overflow-auto`, `sr-only`, `cursor-pointer`, `transition-colors`, `animate-spin` and their kin. Sizes with a token key are allowed on every sizing property: `w-200`, `min-h-800`, `size-150`.

## Running it

```sh
# inside the package
npm run lint

# in a consumer, after adopting the preset
npx eslint src
```
