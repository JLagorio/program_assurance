# Lint rules

The package exports an ESLint plugin, `@ledger/design-system/eslint`, whose allowlist is generated by the token build, so the rules and the tokens cannot drift. It has two presets: `package`, what this package lints itself with, and `recommended`, for a product. This is the one table of the rules; the repository's component library guide links here.

| Rule                       | Reports                                                                                                              | Instead                                                                                                            | `package` | `recommended` |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | --------- | ------------- |
| `no-arbitrary-value`       | `text-[13px]`, `w-[240px]`, `bg-[#eee]`                                                                              | A token utility or a primitive prop.                                                                               | error¹    | error         |
| `no-alpha-token`           | `bg-brand-bold/80`, `text-default/60`                                                                                | The hovered, pressed, subtle or disabled token.                                                                    | error     | error         |
| `no-dark-variant`          | `dark:bg-neutral`                                                                                                    | Nothing. Every colour token flips by itself; a `dark:` class means a token is missing.                             | error     | error         |
| `no-margin`                | `mt-200`, `-mx-100`                                                                                                  | Stack or Inline space, or Bleed. `m-auto` is allowed.                                                              | error²    | error         |
| `no-static-design-value`   | `rounded`, `opacity-50`, `duration-200`, `border-2`, `ring-2`, `bg-white`, `text-transparent`                        | `rounded-small…full`, `opacity-disabled`, `duration-fast`, `border-w-selected`, `outline-focused`, a colour token. | error     | error         |
| `no-non-token-class`       | Any class that is not a token utility or a documented structural utility (`flex`, `truncate`, `sticky`, `sr-only` …) | A token utility.                                                                                                   | error¹    | error         |
| `no-deprecated-token`      | A deprecated token's utility                                                                                         | Its replacement, applied by `--fix`.                                                                               | error     | error         |
| `no-deprecated-name`       | A part's old name (`Shell.Sidebar`, `Shell.NavItem`)                                                                 | Its replacement; `--fix` does the one-to-one renames.                                                              | error     | error         |
| `prefer-text-link`         | A `Link`, `NavLink` or `a` carrying `text-brand` or `hover:underline`                                                | TextLink with the link element through `render`.                                                                   | error     | error         |
| `no-colgroup`              | `<colgroup>`                                                                                                         | `width` or `minWidth` on each Table.Header.                                                                        | error     | error         |
| `button-icon-slot`         | An element with `size-icon-*` inside a Button or an IconButton                                                       | `iconBefore`, `iconAfter` or `icon`, passed bare; the button sizes it.                                             | error     | error         |
| `cell-plain`               | A Table.Cell carrying a neutral colour, weight or type token                                                         | Nothing; only a status colour may differ.                                                                          | off       | error         |
| `id-not-blue`              | An Id with `text-brand` outside a link or a button                                                                   | Wrap it in a link, or drop the class.                                                                              | off       | error         |
| `no-kit-shadow`            | A local component named like a kit part (`Badge`, `Table`, `Stack`)                                                  | Import the kit part.                                                                                               | off       | error         |
| `no-native-confirm`        | `confirm()` or `window.confirm()`                                                                                    | An AlertDialog, which keeps cancellation, the draft and the pending lock.                                          | off       | error         |
| `text-link-navigation`     | A TextLink whose `render` is a Button, an IconButton or a native element other than `a`                              | An anchor or a router link in TextLink; a Button for an action.                                                    | off       | error         |
| `dialog-footer-order`      | Cancel after the primary in a DialogFooter                                                                           | Cancel first, then the primary.                                                                                    | off       | error         |
| `use-primitives`           | A `div` or `span` carrying `flex`, `grid`, padding or gap classes                                                    | Box, Stack, Inline, Flex or Grid.                                                                                  | off       | warn          |
| `product-responsive-table` | A DataTable without `responsive`, or with it before a prop spread                                                    | `responsive` after any spread.                                                                                     | off       | off³          |
| `product-line-tabs`        | A TabsList without `variant="line"`, or with a wrapping, width or overflow class                                     | `variant="line"` after any spread, and no layout override: the kit owns the strip.                                 | off       | off³          |

1. In the package's stories, `no-arbitrary-value` is off and `no-non-token-class` is a warning: a story's own frame may take a fixed width, while the parts it demonstrates stay on the tokens.
2. Off in `primitives/bleed.tsx`, the one place a negative margin is written.
3. Opt-in product layout rules, off in both presets: filled tabs and horizontally scrolling comparison tables remain supported by the kit. A product that adopts the contract turns them on for its product files; this repository's application does. Each required prop must follow any spread so the spread cannot override it.

Inside the package a portability rule also blocks any import from a consumer (`@/…`), from the prototype, or from a router.

## What counts as structural

Display, position, alignment, overflow, text flow and interaction utilities are allowed as written, because they carry no design value: `flex`, `grid`, `relative`, `absolute`, `sticky`, `truncate`, `whitespace-nowrap`, `select-none`, `pointer-events-none`, `overflow-auto`, `overscroll-none`, `sr-only`, `cursor-pointer`, `transition-colors`, `animate-spin` and their kin. Sizes with a token key are allowed on every sizing property: `w-200`, `min-h-800`, `size-150`. The kit's own structural utilities are allowed as well: the layout rules in `layout.css` and `shell.css` (`page-header`, `section-header`, `fill-window`, `sticky-rail` and the shell regions), `stat-grid` with `stat-grid-2` to `stat-grid-6` in `stat.css`, and the hit areas `touch-target`, `touch-target-block` and `touch-target-block-after` in `touch.css`.

## Running it

```js
// eslint.config.js in a product
import ledger from "@ledger/design-system/eslint";

export default [
  ...ledger.configs.recommended,
  // The two opt-in layout rules, for the files that follow the product contract.
  {
    files: ["src/routes/**/*.tsx"],
    rules: {
      "ledger/product-responsive-table": "error",
      "ledger/product-line-tabs": "error",
    },
  },
];
```

```sh
# inside the package
npm run lint

# in a product, after adopting the preset
npx eslint src
```
