# Getting started

The package is `@ledger/design-system`. It ships TypeScript source, a generated CSS layer and an ESLint preset. Its only peers are React and Tailwind 4.

## Install

```sh
npm install @ledger/design-system
```

The package ships `dist/` (ESM with declarations, from `npm run build`) and `src/`. A bundler that sets the `development` condition (Vite in dev) resolves to source; everything else resolves to dist. The stylesheets always come from `src`, because `ledger.css` scans the source for the classes your build needs.

## CSS

One stylesheet, in this order. The reset must come before the system: it clears Tailwind's default namespaces (colours, spacing, radii, shadows, fonts) so that only token utilities exist, and it would clear the system's own mappings if it came after them.

```css
@import "tailwindcss";
@import "@ledger/design-system/reset.css";
@import "@ledger/design-system/ledger.css";
@import "@ledger/design-system/base.css";
```

`ledger.css` carries an `@source` directive pointing at the package, so Tailwind generates the classes the components use even though they live in `node_modules`. `base.css` is optional: it sets the colour scheme, the default border colour and the body's type and colour.

## Components

```tsx
import { Button, Stack, Text } from "@ledger/design-system";

export function Empty() {
  return (
    <Stack space="space.200" alignInline="center">
      <Text color="color.text.subtle">No controls match these filters.</Text>
      <Button variant="primary">Clear filters</Button>
    </Stack>
  );
}
```

Standard reusable components follow the local shadcn Base UI reference with flat named parts,
native props and refs, and Ledger token styling. Breadcrumb is the first family migrated;
other existing families keep their documented APIs until explicitly migrated. Assemble
convenience layouts in patterns while keeping the component parts available.

Components never import a router. Breadcrumb uses `render` to compose your router's link;
the link must accept the merged attributes, handlers and ref:

```tsx
import { Link } from "@tanstack/react-router";
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@ledger/design-system";

export function RecordTrail() {
  return (
    <Breadcrumb aria-label="Breadcrumb">
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink render={<Link to="/controls" />}>Controls</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>New control</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  );
}
```

The list, links, current page and separators are explicit parts. `BreadcrumbEllipsis` is a
decorative overflow mark; compose it inside a named menu trigger when an overflow menu is needed.
The default list wraps. See [Breadcrumb](?path=/docs/components-breadcrumb--docs) for the full
anatomy and migration examples.

For navigation with button styling, put `buttonVariants` on the router link. It keeps its native
link behavior. Action composition uses Button's `render`; Tabs.Tab keeps its existing `asChild` API.

```tsx
import { buttonVariants } from "@ledger/design-system";

<Link to="/controls/new" className={buttonVariants({ variant: "primary" })}>
  New control
</Link>;
```

## Colour mode

Tokens flip on `data-color-mode="dark"` on the root element, or on the system preference when no attribute is set. Nothing in a component knows which mode it is in.

```html
<html data-color-mode="dark">
```

## Lint

The package exports an ESLint flat config. `recommended` makes every token rule an error and layout-through-primitives a warning.

```js
import ledger from "@ledger/design-system/eslint";

export default [...ledger.configs.recommended];
```

## Utilities in product code

Token utilities (`bg-surface-raised`, `text-subtle`, `p-200`, `rounded-medium`) are legal in product code; primitives are preferred for layout. Tailwind's own design utilities (`bg-blue-500`, `text-sm`, `p-4`, `rounded-md`) do not exist after the reset and the lint reports them.
