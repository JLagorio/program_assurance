# DropdownMenu

Actions and view options anchored to a button, using shadcn's Base UI Menu composition. Ledger supplies the menu surface, row geometry, colors and motion.

```tsx
<DropdownMenu>
  <DropdownMenuTrigger render={<Button variant="secondary" />}>Actions</DropdownMenuTrigger>
  <DropdownMenuContent style={{ width: 200 }}>
    <DropdownMenuItem onClick={edit}>Edit</DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="destructive" onClick={archive}>Archive</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```

## Composition and states

Root owns controlled or uncontrolled open state, modality, generic trigger payloads and cancellable `onOpenChange(open, details)`. Trigger defaults to a native button and composes existing buttons through `render`. Custom rendered components must accept merged props and refs; use `nativeButton={false}` only when replacing a button with a non-button action target.

Content includes its portal and positioner. It defaults to bottom/start, with a 4px side offset and zero alignment offset. Its width follows the trigger with a 128px minimum; existing consumers explicitly retain their previous widths. It scrolls within available height. Native `style`, `className`, `render` and refs target the popup; classes and styles accept state callbacks. Content's `dir` overrides Ledger's inherited positioning direction.

Use Group around related items and Label inside that Group. Items compose icons, text and Shortcut as children. Destructive actions use `variant="destructive"`; `inset` aligns labels and items without icons. The row uses Ledger's 28px menu height. Wrap long labels in a truncating span or supply deliberate wrapping styles for longer content.

## Choices and closing

Use CheckboxItem with `checked` and `onCheckedChange` for independent options. Use RadioGroup with `value` and `onValueChange`, and RadioItem with `value`, for exclusive options. A change callback's `details.cancel()` rejects the change. The installed Base UI radio value contract is not generic; callers can validate values against their own options.

Ordinary Item actions use `onClick` and close by default. CheckboxItem and RadioItem stay open by default; set `closeOnClick` when selecting should close the menu. Columns keep the menu open while toggling visibility; saved views and sorting close after a choice. Essential form values still belong in labeled form controls.

## Submenus and links

Sub, SubTrigger and SubContent create a nested menu. SubContent defaults to start alignment, -3px alignment offset, zero side offset and a 96px minimum. Its logical `inline-end` side and chevron follow the locale. Escape closes the submenu first; Root's `closeParentOnEsc` can change that behavior.

LinkItem is Base UI's native anchor part. Give it `href`, or `render` a router Link, to retain navigation and modified clicks. It stays open by default; `closeOnClick` closes after navigation. Item with a rendered action button instead uses `nativeButton`. The public Portal part is available for custom Base UI compositions; Content already includes one.

## Accessibility and dialogs

The trigger exposes `aria-haspopup="menu"` and expanded state. Items use `menuitem`, `menuitemcheckbox` or `menuitemradio`, with checked state where appropriate. Enter, Space or ArrowDown opens from the trigger; arrows, Home, End and typeahead navigate; Enter or Space activates an action. Disabled items remain focusable and announce their disabled state, but cannot activate. Root defaults to modal with looping keyboard navigation.

A row-action button must remain keyboard-reachable. Use `opacity-0 focus-visible:opacity-100 group-hover/row:opacity-100 data-popup-open:opacity-100` for visual concealment, rather than `visibility: hidden`, which removes it from keyboard navigation.

Content owns `finalFocus`. Ledger's modal wrappers resolve an activating menu item to its stable menu trigger, so closing the dialog returns there. For custom modal compositions, give the dialog an explicit return ref and use `finalFocus={false}` if menu focus return must be suppressed. A menu inside a current Radix dialog shares its portal boundary; Escape dismisses the menu before its parent dialog.

## Migration and API

Replace the configured `trigger` prop with Trigger's `render`; move placement and width into Content. Replace `DropdownMenu.Item`, `.Label` and `.Separator` with the flat exports. `onSelect` becomes `onClick` for actions; `isSelected` becomes CheckboxItem or RadioGroup state; `closeOnSelect` becomes `closeOnClick`; `tone="danger"` becomes `variant="destructive"`; `trailing` becomes Shortcut children. Remove children-as-`close` callbacks: items close through Base UI, and Root exposes controlled state or `actionsRef` for imperative dismissal.

See [shadcn Dropdown Menu](https://ui.shadcn.com/docs/components/base/dropdown-menu) and [Base UI Menu](https://base-ui.com/react/components/menu) for the native APIs. Content adds the four positioning props to Popup. Ledger adds token styling and locale/dialog integration; reference catalogs remain independently refreshable.
