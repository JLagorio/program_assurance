# Table

The register, by hand. For a table with state (sort, filters, pages, selection) see Data table in Patterns. Header cells are sticky and sit on the current surface; rows are `dimension.row` tall with a hairline between; the header is `dimension.row.header`. Text is the body size with tabular numerals where a column is numbers.

## Parts

| Part              | Does                                                                                                                                                                                                                                                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Table`           | `maxHeight` makes the wrapper the scroll frame, so the sticky header sticks to it and not to the page.                                                                                                                                                                                                                                                              |
| `Table.Header`    | A column heading. `sort` makes it a button that reports its direction through `aria-sort` and shows the arrow; `sticky` pins it to the leading edge of a table that scrolls sideways; `width` (pixels) fixes the column, because column widths are content decisions and not classes.                                                                               |
| `Table.Row`       | `isSelected` paints the selected role and sets `data-selected`. The row is a `group/row` so cells can react to its hover. `isStatic` is for rows that are not records (a form laid out as a table, a totals row): they do not light up.                                                                                                                             |
| `Table.Cell`      | Truncates by default. `sticky` pins the column and keeps it opaque over the rows behind; `width` matches the header's. A table with no header row puts `width` on the cells of its rows instead (Table.Id takes one too).                                                                                                                                           |
| `Table.Id`        | The id column. The row opens the record; the eye that appears on hover opens the same row in the preview rail.                                                                                                                                                                                                                                                      |
| `Table.Selection` | The checkbox column. In the header it selects every row and reads mixed when only some are.                                                                                                                                                                                                                                                                         |
| `Table.Group`     | A band of rows under one heading that opens and closes. It renders a `tbody`, so several stack in one Table.                                                                                                                                                                                                                                                        |
| `Table.Tree`      | The name cell of a row in a hierarchy that also has columns (the ARIA treegrid): one indent per `depth`, the chevron on rows with children, the name truncated, a `hint` after it. The Table takes `role="treegrid"`, each Row `aria-level` and, with children, `aria-expanded`. The caller flattens and folds. Tree (in Lists) is the same recipe without columns. |

Toolbar sits above (search, filters, actions on the right); Pagination sits below (range on the left, pages on the right).
