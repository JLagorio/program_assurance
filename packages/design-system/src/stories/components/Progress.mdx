# Progress

Based on [shadcn’s Base UI source](https://ui.shadcn.com/docs/components/base/progress) and [Base UI](https://base-ui.com/react/components/progress). Ledger retains its tokens and application layouts.

## Anatomy

Task completion using Base UI Progress. Progress supplies its default Track and Indicator; ProgressLabel and ProgressValue are optional children. ProgressTrack and ProgressIndicator expose the corresponding native parts for custom composition under Base UI’s root. ProgressStacked remains the separate proportional coverage bar.

## Accessibility

Name meaningful bars through ProgressLabel or aria-label. Mark redundant decorative bars aria-hidden. Base UI keeps the indicator width, bounded value and accessible value in sync for min/max; null or a nonfinite value is indeterminate. Interactive stacked segments keep individual button names.

## Props

Progress exposes Base UI native root props and ref, including value, min/max, formatting, locale, render and state callbacks. Ledger tone and small/medium/large track sizes remain. Label, Value, Track and Indicator expose their corresponding native contracts.

### Migration and API

- Replace label with aria-label or ProgressLabel; valueText with aria-valuetext; showValue with ProgressValue children.
- Replace Progress.Stacked with ProgressStacked. Existing tone, size and coverage segment APIs remain.
- ProgressValue defaults to the formatted percentage; its children callback can display counts. Base UI performs clamping; the wrapper no longer calculates a second percentage.
