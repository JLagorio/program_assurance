# Combobox

Search and select predefined values using shadcn's Base UI Combobox composition. Root owns selection, filtering, popup state and form serialization. ComboboxInput composes the shared InputGroup and its trigger/clear controls.

## Anatomy

```tsx
const frameworks = ["React", "Vue", "Svelte"];

<Field>
  <FieldLabel htmlFor="combobox">Framework</FieldLabel>
  <Combobox items={frameworks}>
    <ComboboxInput id="combobox" placeholder="Choose a framework" showClear />
    <ComboboxContent>
      <ComboboxEmpty>No frameworks found.</ComboboxEmpty>
      <ComboboxList>
        {(item: string) => (
          <ComboboxItem key={item} value={item}>
            {item}
          </ComboboxItem>
        )}
      </ComboboxList>
    </ComboboxContent>
  </Combobox>
</Field>;
```

Root renders no DOM wrapper. Content includes Portal, Positioner and Popup. List renders filtered items. Group, Label, Collection and Separator compose categorized results.

For multiple selection, use an array value with ComboboxChips, ComboboxValue, ComboboxChip and ComboboxChipsInput. Chips include removal controls unless `showRemove={false}`. Use `useComboboxAnchor()` to anchor the popup to the whole chips container.

For remote results, own loading/query state and pass `filter={null}` when the server filters. ComboboxStatus presents loading feedback outside the list of options. Disabled options cannot be selected; read-only selection stays submitted without allowing changes.

## Accessibility

Connect FieldLabel to ComboboxInput with `htmlFor`/`id`; put description IDs, invalid state and required announcements on the editable input. Root’s `required` enables native constraint validation separately. Typing filters, arrows highlight, Enter selects, and Escape closes the popup before the surrounding dialog. Base UI controls focus and nested popup behavior.

## Props

`ComboboxProps<Value, Multiple>` is the generic Base UI root contract, with Ledger locale/direction defaults. Root's `value` is one value/null or an array; `onValueChange(value, details)` supports cancellation. Use `name`, `form`, `inputRef`, serialization and equality callbacks on Root. The installed Base UI version is 1.7; reset controlled selections in the owning form's `onReset`.

ComboboxInput forwards native input refs, events, render composition, classes and styles; Ledger retains small/medium sizing. `showTrigger` defaults true and `showClear` defaults false. Its children follow the control addons. Content forwards popup props plus positioning, `portalContainer` and `keepMounted`; the latter two preserve existing advanced integrations. Clear, ChipRemove and Status are additional flat native parts.

Replace `Combobox options/onChange` and `Combobox.Root` with the single root API. Move placeholder, ref, blur and input ARIA to ComboboxInput. Replace the old separate InputGroup/Trigger composition with ComboboxInput, and use ComboboxChipsInput inside chips. Layout owns widths. NativeSelect has been removed; use Select for choices that do not need search.
