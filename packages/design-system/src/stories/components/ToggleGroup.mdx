# ToggleGroup

A group of toggle buttons with shared selection and keyboard navigation. Compose each choice with `ToggleGroupItem`, using a unique `value` and explicit children for its label, icon or count.

```tsx
<ToggleGroup aria-label="View" defaultValue={["table"]} variant="outline">
  <ToggleGroupItem value="table">Table</ToggleGroupItem>
  <ToggleGroupItem value="board">Board</ToggleGroupItem>
</ToggleGroup>
```

## Selection and layout

Selection is an array in both modes. By default, at most one item can be pressed; pressing it again clears the selection. Add `multiple` to allow several pressed items. `defaultValue` initializes local state; `value` and `onValueChange(values, details)` control it. Call `details.cancel()` to reject a change, such as clearing a required view.

Group `variant` and `size` pass to its items. Variants are `default` and `outline`; sizes are `sm` (28px), `default` (32px) and `lg` (36px). Default `spacing={2}` leaves an 8px gap; `spacing={0}` joins the items. `orientation="vertical"` stacks them and changes arrow navigation.

The group and items support native attributes, refs, `render`, and state callbacks for `className` and `style`. Use `disabled` on an item or the whole group to block selection.

## Accessibility

- The root has `role="group"`; each item is a button with `aria-pressed`. Name the group with `aria-label` or `aria-labelledby`, and give icon-only items an accessible name.
- Tab enters and leaves the group as one stop. Arrow keys move focus; Enter or Space changes selection. Disabled items are skipped.
- Horizontal arrows follow the Ledger locale direction; `dir` on the group overrides it. Vertical groups use Up and Down. Home and End reach the first and last enabled items.
- Focus wraps by default. Set `loopFocus={false}` to stop at the ends.
- Add [Tooltip](?path=/docs/components-tooltip--docs) explicitly when an icon needs a visible explanation.

## Migration

Replace `items` with `ToggleGroupItem` children, scalar `value` with an array, and `onChange` with `onValueChange`. The old required single-selection rule now belongs to the consumer: ignore or cancel an empty selection when one choice must remain active. `small` becomes `sm`; `medium` becomes `default`. Counts are explicit Count children, and icons are ordinary children. `isIconOnly` and automatic item tooltips are removed.

This uses the installed Base UI array API with `multiple`; it does not use Radix's `type="single"` or `type="multiple"` API.
