# ToggleGroup

**Status: Stable.**

A group of toggle buttons with shared selection and keyboard navigation. Compose each choice with `ToggleGroupItem`, using a unique `value` and explicit children for its label, icon or count.

```tsx
<ToggleGroup aria-label="View" defaultValue={["table"]} variant="outline">
  <ToggleGroupItem value="table">Table</ToggleGroupItem>
  <ToggleGroupItem value="board">Board</ToggleGroupItem>
</ToggleGroup>
```

## When to use it

| Need                                                                                                              | Part                                                                                                   |
| ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| One choice among two to five, all shown, that changes the view at once: Table or Board, a period, the colour mode | ToggleGroup                                                                                            |
| Several independent on/off options side by side: Bold, Italic, Underline                                          | ToggleGroup with `multiple`, or a row of [Toggle](?path=/docs/components-toggle--docs)                 |
| One choice submitted with a form, or more than a handful of options                                               | [RadioGroup](?path=/docs/components-radiogroup--docs) or [Select](?path=/docs/components-select--docs) |
| Switching between panels of content                                                                               | [Tabs](?path=/docs/components-tabs--docs)                                                              |
| Related actions joined into one control                                                                           | [ButtonGroup](?path=/docs/components-buttongroup--docs)                                                |

## Content

- Each item is one or two words that name the choice ("Table", "Board", "Last 30 days"); the group's `aria-label` names what they choose between ("View", "Period").
- Items share a grammar and a length, so the group reads as one set, and the order is the order of the thing they choose (shortest period first, the default view first).
- A count after a label is a [Count](?path=/docs/components-count--docs), with the same `max` as the product's other counts.

A group without its `aria-label` is heard as buttons with no word for the choice they make.

## Selection and layout

Selection is an array in both modes. By default, at most one item can be pressed; pressing it again clears the selection. Add `multiple` to allow several pressed items. A pressed item takes Toggle's pressed look, the selected fill with a 1px `color.border.selected` edge that follows a joined group's corners, so the current view never looks like a hovered one; in forced colours it is Highlight. `defaultValue` initializes local state; `value` and `onValueChange(values, details)` control it. Call `details.cancel()` to reject a change, such as clearing a required view: one choice that must stay active ignores or cancels an empty selection. The API is Base UI's array with `multiple`, not Radix's `type="single"`.

Group `variant` and `size` pass to its items. Variants are `default` and `outline`; sizes are Toggle's: `small` (28px), `medium` (32px, the default) and `large` (36px), with `sm`, `default` and `lg` as deprecated spellings for one version. `spacing` counts 4px steps on the space scale: the default `spacing={2}` is `space.100` (8px), `1` to `6`, `8`, `10`, `12` and `16` are the other steps, a number between two steps takes the smaller, and `spacing={0}` joins the items. `orientation="vertical"` stacks them and changes arrow navigation.

<Canvas of={Stories.Spacing} />

The group and items support native attributes, refs, `render`, and state callbacks for `className` and `style`. Use `disabled` on an item or the whole group to block selection.

<Canvas of={Stories.ViewsStory} />

A spaced group wraps its items onto the next line when its row is too narrow for them, so every choice stays in view and in reach. A joined group, a group in a table cell and a group in a horizontal Scroller keep one line, and the table's frame or the Scroller scrolls. Put a joined group in a horizontal [Scroller](?path=/docs/components-scroller--docs) when its row can be narrower than its items.

## Accessibility

- The root has `role="group"`; each item is a button with `aria-pressed`. Name the group with `aria-label` or `aria-labelledby`, and give icon-only items an accessible name.
- Tab enters and leaves the group as one stop. In a single-select group with a pressed item, that stop is the pressed item, as in a radio group, so the reader lands on the current choice; otherwise, and in a `multiple` group, it is the first enabled item. Arrow keys move focus; Enter or Space changes selection; Tab from any item leaves the group, and coming back lands on the pressed item again. A value changed from outside moves the stop with it. Disabled items are skipped.
- Horizontal arrows follow the Ledger locale direction; `dir` on the group overrides it. Vertical groups use Up and Down. Home and End reach the first and last enabled items.
- Focus wraps by default. Set `loopFocus={false}` to stop at the ends.
- An icon-only item has no visible name, so give it a [Tooltip](?path=/docs/components-tooltip--docs) with its name, as ModeSwitch does: `<Tooltip><TooltipTrigger render={<ToggleGroupItem value="dark">…</ToggleGroupItem>} /><TooltipContent>Dark</TooltipContent></Tooltip>`.
