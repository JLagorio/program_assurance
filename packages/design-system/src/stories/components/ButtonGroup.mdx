# ButtonGroup

Join related actions, split buttons or controls. Each child keeps its own behavior and accessible name.

## Anatomy

```tsx
<ButtonGroup aria-label="Export">
  <Button>Export</Button>
  <ButtonGroupSeparator isDecorative />
  <Button>Print</Button>
</ButtonGroup>
```

ButtonGroup joins the outer corners of children with `data-slot` attributes. ButtonGroupText adds a label, value or prefix. ButtonGroupSeparator adds a visible rule. Nested groups may separate related sets of actions.

## Variants and states

`orientation` accepts `horizontal` (default) or `vertical`. Horizontal joins use logical edges in RTL. Child controls choose their size, disabled state and loading behavior. The separator's orientation describes its own line; use a horizontal separator between vertically stacked controls.

<Canvas of={Stories.Orientations} />

## Accessibility

Name the group with `aria-label` or `aria-labelledby`. Each enabled control remains in the normal tab order. A group does not add arrow-key navigation or selection behavior. Use ToggleGroup for a selection among options. Decorative separators may use `isDecorative`.

ButtonGroupText supports Base UI `render`, including a native label with `htmlFor`. Rendered elements must accept merged attributes, events and refs.

The root forwards native div attributes and refs. Text uses Base UI useRender/mergeProps; Separator uses the existing Base UI Separator. `buttonGroupVariants` exports the same orientation classes for composition.

### Migration

Rename `label` to `aria-label`. Compose text and separators with the flat exports. The root is now a div and accepts native props, refs and orientation.
