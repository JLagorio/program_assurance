# Lists and facts

Rows that are not a table, and the small text parts a record page is made of.

## Breadcrumb and Item

Every breadcrumb but the last is a link back up the record tree; pass `asChild` and the child (a router's Link) takes the item's classes. An Item is one row of a list: leading mark, id column, title with meta, right-aligned value, actions. `link` takes a link element that becomes the row; `onSelect` makes it a button.

<Canvas of={Stories.Items} />

## Facts

`Fact` is an inline label and value for the strip under a record header (wrap a row in a `dl`). `KeyValue` is one rail row with a label column. `Prose` is a labelled paragraph. `Eyebrow` is the uppercase micro-label on `font.heading.xxsmall`. `Absent` is the muted dash.

<Canvas of={Stories.Facts} />

## Timeline

Events along one rail. Groups carry sticky labels on the current surface. A marker is a ring-and-dot in the tone, or anything 20px you pass.

<Canvas of={Stories.TimelineStory} />

## Stepper

Progress through an ordered path. One step is `current`; `blocked` is the step that failed. Horizontal puts labels under markers; vertical stacks them down the left.

<Canvas of={Stories.Steppers} />

## Tree

A hierarchy the caller flattens. Rows carry indent guides, a chevron where there are children, and the tree aria.
