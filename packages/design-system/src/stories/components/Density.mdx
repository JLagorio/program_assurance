# Density

Row density belongs to each table. `default` gives rows 40px of height; `compact` gives them 36px. Headers, controls and typography keep their sizes.

## Usage

Set `density` on a plain Table. The frame sets `data-density="compact"`, which changes the row-height token for its contents. Keep that attribute on the table frame so nearby lists and cards retain their spacing.

<Canvas of={Stories.Tables} />

## Reader preference

A DataTable's Columns menu offers Compact rows. With a `view` name, the choice persists with its column settings; Reset view restores the author's default.

<Canvas of={Stories.RegisterStory} />

For a compact default, pass `density: "compact"` to `useDataTable`. The reader can still change it.

<Canvas of={Stories.ByDesign} />

## Accessibility

Changing row height preserves labels, focus order and control targets. The Columns menu exposes the current choice as a checkbox item. Offer density per table, so a choice in one view does not change unrelated content.

## Migration

The former global density provider, switch, hook, storage helpers and scripts are removed. Remove their imports and unwrap the provider's children. Use `Table density` or the DataTable view setting; no document-wide storage key or before-paint script is needed. The `Density` type remains exported.
