# Surfaces

## CodeBlock

Source shown as source: a line-number gutter that stays put when the block scrolls sideways, one row per line, the code face. The caller owns highlighting and passes rendered lines.

<Canvas of={Stories.Code} />

## Resizable and ScrollArea

Panes a person sizes for themselves. The handle is a hairline that lights up on hover and takes the arrow keys. ScrollArea scrolls with the kit's thin bar instead of the platform's, so a rail looks the same on every OS.

<Canvas of={Stories.Panes} />

## Toaster

Confirmation of an action: bottom right, gone in a few seconds. Render one Toaster near the root, then call `toast.success`, `toast.error`, `toast.warning` or `toast.info` from anywhere.

<Canvas of={Stories.Toasts} />
