# Drawer

A gesture-driven panel using [shadcn’s Base UI composition](https://ui.shadcn.com/docs/components/base/drawer) and [Base UI Drawer](https://base-ui.com/react/components/drawer). Use Sheet for a side panel that needs no swipe gestures.

## Anatomy

```tsx
<Drawer showSwipeHandle>
  <DrawerTrigger render={<Button />}>Quick actions</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Control actions</DrawerTitle>
      <DrawerDescription>For the selected control.</DrawerDescription>
    </DrawerHeader>
    <div className="min-h-0 flex-1 overflow-y-auto p-250">Actions</div>
    <DrawerFooter>
      <DrawerClose render={<Button />}>Done</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

Content composes Portal, the modal Overlay, Base UI Viewport/Popup and the text-selectable Content region. Header, Title, Description, Footer and Close are explicit parts. Portal, Overlay and SwipeHandle are also exported for custom native compositions.

## Variants and states

`swipeDirection` is `down` by default; `up`, `left` and `right` use physical edges. `showSwipeHandle` defaults to false. Root supports controlled or uncontrolled open state, native snap points and modal modes. Give long content its own scrolling body. Side drawers default to 75% of the viewport, capped at 24rem; vertical drawers leave space above the panel.

For pending work, cancel the native `onOpenChange` event details when dismissal is unavailable. The same callback receives Escape, outside press, close button and swipe requests.

## Accessibility

Supply a Title or an accessible name. Description is optional and creates its relationship only when rendered. Include an accessible Close action; the swipe handle is decorative. Base UI handles focus trapping, restoration, Escape, scroll locking and nested popups. Content accepts native `initialFocus`, `finalFocus`, refs, render and state callbacks. Specify a surviving finalFocus target if the opener disappears.

Nested drawers must be nested in the React tree. Ledger’s CSS follows Base UI’s measured swipe, snap and stack variables and honors reduced motion.

## Props

Replace the old configured `title`, `description`, `footer` and `onClose` props with children and Root `onOpenChange`. Move `returnFocusRef` to Content `finalFocus`, and surface dimensions/className to Content. The Vaul dependency and its portal/Escape/focus bridge are removed from the package.
