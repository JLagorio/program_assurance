# Drawer

A gesture-driven panel using [shadcn’s Base UI composition](https://ui.shadcn.com/docs/components/base/drawer) and [Base UI Drawer](https://base-ui.com/react/components/drawer). Use Sheet for a side panel that needs no swipe gestures.

## Anatomy

```tsx
<Drawer showSwipeHandle>
  <DrawerTrigger render={<Button />}>Quick actions</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Control actions</DrawerTitle>
      <DrawerDescription>For the selected control.</DrawerDescription>
    </DrawerHeader>
    <DrawerBody>Actions</DrawerBody>
    <DrawerFooter>
      <DrawerClose render={<Button />}>Done</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

Content composes Portal, the modal Overlay, Base UI Viewport/Popup and the text-selectable Content region, and records the overlay surface as the current one, so a sticky header or pinned cell inside matches the drawer. Header, Body, Title, Description, Footer and Close are explicit parts; the title is the drawer's h2 and headings inside start at h3. Portal, Overlay and SwipeHandle are also exported for custom native compositions.

DrawerBody is the one scrolling region between the header and the footer, with the drawer's inset, at least 80px tall. Base UI lets a swipe that starts in it scroll it, and dismiss once it is at its edge. Read-only content that overflows makes it a tab stop, "Content, scrolls". In a window under 30rem tall the drawer scrolls as one, with the footer held at the bottom.

## Variants and states

`swipeDirection` is `down` by default; `up`, `left` and `right` use physical edges. `showSwipeHandle` defaults to false. Root supports controlled or uncontrolled open state, native snap points and modal modes. Put long content in DrawerBody. Side drawers default to 75% of the viewport, capped at 24rem; vertical drawers leave space above the panel.

Drawer has no `pending` prop. For pending work, cancel the native `onOpenChange` event details while the command runs, and disable the close controls; the same callback receives Escape, outside press, close button and swipe requests. Dialog, Sheet and AlertDialog have `pending`.

## Accessibility

Supply a Title or an accessible name. Description is optional and creates its relationship only when rendered. Include an accessible Close action; the swipe handle is decorative. Base UI handles focus trapping, restoration, Escape, scroll locking and nested popups. Content accepts native `initialFocus`, `finalFocus`, refs, render and state callbacks. Specify a surviving finalFocus target if the opener disappears.

Nested drawers must be nested in the React tree. Ledger’s CSS follows Base UI’s measured swipe, snap and stack variables and honors reduced motion.

## Props

Drawer takes Base UI Drawer's root props, `open`, `defaultOpen`, `onOpenChange` (with the change's `reason` and `cancel()` in its details), `onOpenChangeComplete`, `modal`, `disablePointerDismissal`, `actionsRef`, `handle`, `swipeDirection`, `snapPoints`, `snapPoint`, `defaultSnapPoint`, `onSnapPointChange` and `snapToSequentialPoints`, and Ledger's `showSwipeHandle`. DrawerContent takes the popup's `initialFocus`, `finalFocus`, refs, `render` and `className`. The types are in [Base UI's API reference](https://base-ui.com/react/components/drawer#api-reference).
