# Avatar

Represent a person or entity with Base UI image loading and shadcn's flat Avatar parts. Ledger retains its sizes, shapes and accent treatments.

## Anatomy

```tsx
<Avatar role="img" aria-label="Dana Whitfield" size="medium">
  <AvatarImage src="/dana.png" alt="" />
  <AvatarFallback>DW</AvatarFallback>
  <AvatarBadge tone="success" />
</Avatar>
```

Compose overlapping avatars with `AvatarGroup` and `AvatarGroupCount`. The caller chooses members and writes the overflow count. `Person` remains the small avatar plus visible name used in record rows.

## Variants and states

Sizes are `xsmall`, `small` (default), `medium`, `large` and `xlarge`. Shapes are `circle` and `square`; treatments are `neutral`, `tinted`, `bold` and `gradient`. Use `avatarHue(name)` when a person's accent should stay stable and `avatarInitials(name, count)` to produce fallback text.

Base UI shows the fallback while the image loads or fails. `AvatarFallback.delay` can delay its appearance. Changing Image's `src` retries loading.

## Accessibility

Name an informative avatar with `role="img"` and `aria-label`, including meaningful presence information. When a visible name already identifies the person, set `aria-hidden="true"` on the avatar. A named group can hide its avatars and count when its accessible name already describes the entire group. Give Image an empty alt when the root supplies the name.

## Props

Root, Image and Fallback preserve their native Base UI props, refs, `render`, and state-based classes/styles. Badge accepts native span props and Ledger's `tone`. Group and GroupCount accept native div props. Ref targets follow each part.

Replace `Avatar name/src` with explicit Image and Fallback children; replace `isDecorative` with native `aria-hidden`. Replace `Avatar.Stack names/max` with caller-owned `AvatarGroup` children and `AvatarGroupCount`. There is one composition API.
