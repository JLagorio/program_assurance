# Collapsible

One independent disclosure. Experimental; owner: Ledger maintainers. The caller supplies the trigger and content. Compose a title, count or chevron into the trigger when needed.

## Anatomy

`Collapsible` owns boolean state. `Collapsible.Trigger` toggles it. `Collapsible.Content` contains what it reveals. No title row, heading, count, border or chevron is imposed.

```tsx
<Collapsible>
  <Collapsible.Trigger asChild>
    <Button>Advanced options</Button>
  </Collapsible.Trigger>
  <Collapsible.Content>Additional settings.</Collapsible.Content>
</Collapsible>
```

## Variants

The same interaction accepts either a plain native trigger or `asChild` around a single ref-capable Button. Use Accordion for coordinated sections. An independent Collapsible keeps its own state even inside an Accordion's content.

## Sizes

No fixed dimensions. Button determines the size of a composed trigger; the content takes its container width. Supply wrapping labels and responsive body content.

## States

Closed by default; `defaultOpen` opens initially. `open` and `onOpenChange` make state controlled. `disabled` disables toggling. Focus remains on a trigger when it closes its panel. Avoid changing between controlled and uncontrolled use during a mount.

## Modifiers

Native attributes, events and refs go to the named root, button or content. `asChild` merges them onto a single child that must forward them. `Content forceMount` retains local child state while closed content is hidden and out of the tab order. Closed retained panels hide immediately; ordinary panels animate before unmounting. Caller-controlled closures must relocate focus first if it is inside the panel.

## Content

Name what the trigger reveals. Forms, reference material and additional settings are supported. Avoid hiding required steps without a discoverable path to reveal them. Closed content cannot be found with browser search; retaining it does not implement hidden-until-found behavior.

## Style

Minimal small-radius focus treatment on the trigger, disabled text and pointer behavior. Content uses Ledger collapse motion and honors reduced motion. Spacing and visual surfaces belong to the composition.

## Accessibility

A native button handles Enter and Space, `aria-expanded` and `aria-controls`; Radix associates it with the content ID. There is no group arrow-navigation model and no implicit region landmark or heading. Add semantic structure when the content requires it. Hidden retained controls are excluded from tab navigation and the accessibility tree. Use a button as the slotted trigger, not a navigation link.

## Props

<ArgTypes of={Collapsible} />

`Trigger` accepts native button attributes/events and an HTMLButtonElement ref. Root and Content accept native div attributes/events and HTMLDivElement refs. Content adds `forceMount`; the root adds `open`, `defaultOpen`, `onOpenChange`, and `disabled`.

## Don't

Do not put a Button inside a native Trigger without `asChild`. Do not use `title`, `count`, `inset`, or `.Group` to request the former section API. Compose the trigger and content directly; use Accordion for coordinated state.
