# Collapsible

Based on [shadcn’s Base UI source](https://ui.shadcn.com/docs/components/base/collapsible) and [Base UI](https://base-ui.com/react/components/collapsible). Ledger retains its tokens and application layouts.

## Anatomy

An independent boolean disclosure using Collapsible, CollapsibleTrigger and CollapsibleContent. Use Accordion for a coordinated set. Labels, counts and icons are ordinary trigger children.

## Accessibility

Base UI owns expanded state, trigger/panel association, disabled behavior and keyboard activation. Retained closed panels stay hidden and unfocusable. hiddenUntilFound lets supported browser find-in-page reveal closed content. Nested disclosures keep independent state.

## Props

The three parts expose native Base UI props, refs, render, state classes/styles and cancellable onOpenChange. Content uses the measured --collapsible-panel-height for Ledger motion and respects reduced motion.

### Migration and API

- Replace Collapsible.Trigger/Content with the flat exports. Replace asChild with render and forceMount with keepMounted.
- Use data-open/data-closed instead of Radix data-state selectors. Item, Section, Stepper, Inspector and DataTable metrics use the same Base UI disclosure behavior.
- The unused LegacyAccordion/LegacyCollapsible adapters are removed; use the current flat Accordion and Collapsible parts.
