# Disclosure

Reference material: present, addressable, closed. The catalog statement, the assessment objectives and the discussion are things a reader occasionally needs and never needs first; rendering them expanded is most of why a control page reads as a novel.

A **Collapsible** is one section. An **Accordion** is several that know about each other: `single` opens one at a time, `multiple` is independent sections with one keyboard model. They share the trigger row, so a page can mix them.
