# Calendar

A day or range picker following [shadcn’s Calendar](https://ui.shadcn.com/docs/components/base/calendar), built on React DayPicker. Ledger provides token styling and provider-localized date labels.

## Anatomy

```tsx
const [date, setDate] = useState<Date>();
<Calendar mode="single" selected={date} onSelect={setDate} />;
```

Calendar exposes DayPicker’s native props. Navigation uses the shared Button recipe; `CalendarDayButton` uses Button while preserving DayPicker’s focus, selection and event contracts. Days remain 32px cells.

## Variants and states

Use native single, multiple or range selection, disabled matchers and month bounds. `numberOfMonths` supports a range across months, stacking on narrow screens. `captionLayout="dropdown"` and `showWeekNumber` use the same token styling.

Custom `components`, `formatters`, `labels` and `classNames` merge with Calendar’s defaults. Use the exported CalendarDayButton when customizing a day. `buttonVariant` controls the navigation buttons; selected days keep their selection treatment.

## Accessibility

DayPicker owns keyboard movement and disabled-day behavior. The day button forwards native attributes and moves focus when DayPicker marks it focused. Give standalone pickers a visible context or accessible name. Ledger supplies localized month/day labels; explicit locale, labels and formatters remain caller overrides. Timestamp timezone settings do not shift date-only labels. Native `timeZone` remains available for callers that supply timezone-aware Date values.

## Props

Existing DayPicker callers keep their selection contract. CalendarDayButton is a new flat export. Custom component overrides now preserve unrelated defaults, and dropdown chevrons point down rather than inheriting the next-month icon.
