# Pickers

Three ways to choose from a list, and one for a date. All four triggers are the hairline control from Controls, so a picker and a field are the same shape in a form.

<Canvas of={Stories.FieldsStory} />

| List | Use |
| --- | --- |
| A plain list of words | **NativeSelect** (in Controls): the browser's own, lightest |
| A short, fixed list whose options carry a Dot or a Badge | **Select** |
| A list worth searching | **Combobox**: a Command in a Popover |
| A day | **DatePicker**: a Calendar in a Popover, holding an ISO day like `input type="date"` |

## Calendar

The Calendar is react-day-picker with the tokens: 32px cells, the selection is the blue budget, today is weight 600 with no dot. Ranges paint `color.background.selected` between the ends.
