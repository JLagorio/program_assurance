# Command

Based on [shadcn’s Base UI source](https://ui.shadcn.com/docs/components/base/command) and [cmdk](https://cmdk.paco.me). Ledger retains its tokens and application layouts.

## Anatomy

Keyboard-filtered actions using cmdk, as in shadcn’s Base UI implementation. CommandDialog uses the shared Base UI Dialog. Compose Command, CommandInput, CommandList, CommandGroup, CommandItem, CommandEmpty, CommandSeparator and CommandShortcut.

## Accessibility

Give Command a descriptive `label` (cmdk uses it to name the search input), and give CommandDialog a title. cmdk handles filtering, disabled choices, option navigation and selection. Base UI Dialog handles focus, modality and dismissal. CommandSeparator is presentational within the listbox. Put CommandLoading alongside CommandList, with aria-busy on the list while fetching. Item onSelect owns the action and any palette closing. When showCloseButton is false, compose a DialogClose so touch and screen-reader users have a dismissal control; the palette and record picker make their Escape footer hint a close button.

## Props

Command parts forward their native cmdk props and refs. CommandDialog accepts the native generic Dialog root contract plus title, description, className, style, showCloseButton and finalFocus. CommandLoading, CommandFooter and CommandCount retain their existing loading and result-count roles.

### Migration and API

- Replace Command.Input/List/Group/Item/etc. with flat exports. Put trailing content in children, using CommandShortcut for key hints.
- Replace Command.Dialog with CommandDialog. Compose an explicit Command inside it; command filtering/value props belong on Command.
- Replace onClose with onOpenChange and label with title on the dialog. Use style or className for palette width; finalFocus replaces returnFocusRef.
- Command continues to use cmdk; its modal shell no longer imports Radix Dialog directly.
