# Button

A button starts an action. The recipe is Atlassian's: one fill per variant, hovered and pressed as their own tokens, disabled as tokens rather than an opacity, one focus outline. The look is Ledger's: a flat brand fill for primary and a raised surface with the raised shadow for secondary.

<Canvas of={Stories.Matrix} />

## Variants

| Variant | Use |
| --- | --- |
| `primary` | The one action the screen is for. At most one per view. |
| `secondary` | The default. Any action that is not the main one. |
| `subtle` | Toolbars and dense rows, where a raised button would be noise. |
| `danger` | An action that destroys or cannot be undone. Pair with a confirmation. |
| `warning` | An action that needs attention but is recoverable. |
| `link` | Reads as text. Navigation inside prose or a table cell. |

## Sizes

`medium` (32px) is the default for forms and pages. `small` (28px) is for toolbars, table rows and rails. `xsmall` (24px) is for the densest chrome and drops to the small body size.

## Icon buttons

An IconButton holds one icon and nothing else. `label` is required: it is the accessible name and the tooltip.

## As a link

Pass `asChild` and the child element takes the button's classes. This is how a router's Link becomes a button without the package depending on the router.

<Canvas of={Stories.AsLink} />

## TextLink

Navigation that reads as text: brand colour, an underline on hover, the focus outline. `asChild` is on by default, so the router's Link goes inside and takes the classes; `asChild={false}` renders an anchor from `href`. Left unset, `size` inherits the surrounding text; `weight="medium"` is for a link that stands alone (a footer's "Open the full record"). The lint reports a Link carrying `text-brand` or `hover:underline` by hand.

`Button variant="link"` is the other thing: an action that only looks like a link (drill into a child, show more). Navigation is TextLink.

## Selected

`isSelected` marks a toggle that is on: a filter that is applied, a view that is chosen. It sets `aria-pressed` and paints the selected role.
