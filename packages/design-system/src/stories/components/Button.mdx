# Button

Button starts an action. Use a short label that names what happens, such as “Save changes” or “Export report.” For navigation, style a real anchor or router Link with `buttonVariants`; for a text link, use [TextLink](?path=/docs/components-textlink--docs).

## Variants and sizes

| Variant | Use |
| --- | --- |
| `secondary` | Default raised action: Export, Edit, Open. |
| `primary` | The main action in a header, form or dialog. |
| `subtle` | Low emphasis actions in toolbars, rows and footers. |
| `danger` | Destructive actions, with confirmation when appropriate. |
| `link` | A text styled action, such as Show more. |

| Size | Height | Typical placement |
| --- | --- | --- |
| `medium` | 32px | Default for forms, headers and footers. |
| `small` | 28px | Toolbars and rows. |
| `xsmall` | 24px | Dense inline actions. |

The `link` variant has no fixed height. `iconBefore` and `iconAfter` take an icon element; Button sizes it to 14px and keeps a 6px gap. `isSelected` applies the selected palette and `aria-pressed`.

## Loading and forms

Button defaults to `type="button"`. Set `type="submit"` for a form's submit action. Native form attributes, event handlers and refs reach the button element. `isFullWidth` fills its container.

`isLoading` replaces the leading icon with a decorative spinner and retains the label. It sets `aria-busy`, blocks activation and preserves focus while work is pending. An explicitly `disabled` button remains disabled and leaves the normal tab order. Base UI's `focusableWhenDisabled` is available when a disabled action needs to remain focusable.

## Composition

`render` accepts an element or a render function for an action control. Render elements merge native props, handlers, refs, classes and styles. Render functions receive the props and state and must apply those props to their result. Custom components must forward them to their DOM element. Button's root ref describes a native button; put a ref for another target on the render element itself.

Use `nativeButton={false}` when the rendered action is not a native button; it receives button semantics and Enter/Space activation. `className` and `style` also accept callbacks with Base UI's `{ disabled }` state, including while loading.

Navigation uses a real anchor or the application's router Link, with the same styling recipe. [Base UI Button enforces button semantics](https://base-ui.com/react/components/button#rendering-links-as-buttons), so styling the link directly preserves its navigation behavior:

```tsx
<a href="/requirements" className={buttonVariants({ variant: "primary" })}>
  View requirements
</a>
```

`buttonVariants` accepts `variant`, `size`, `isSelected`, `isFullWidth` and `className`. It supplies classes without adding ARIA or disabled behavior. Existing `Button asChild` and `IconButton asChild` usages must move to a styled link for navigation, or to `render` for an action control.

## Accessibility

- Tab reaches an enabled button. Enter and Space activate it; the focus outline appears on keyboard focus.
- Disabled buttons are skipped by Tab by default. Explain unavailable actions nearby; for form validation, keep the submit action available so the form can report errors.
- Loading blocks click, Enter and Space activation, including handlers on the rendered action. It keeps the accessible name stable.
- Use [IconButton](?path=/docs/components-iconbutton--docs) for an icon only action with a required accessible label, and [Toggle](?path=/docs/components-toggle--docs) for an on/off control.
