# Spinner

An indeterminate wait such as saving, exporting or refreshing. Use Skeleton when the loading content has a known shape.

## Anatomy

Spinner renders Lucide's Loader2 SVG with `data-slot="spinner"`. Native SVG attributes, events and refs reach that element.

<Canvas of={Stories.Playground} />

## Variants and states

Sizes are small (12px, default), medium (16px) and large (24px). Appearance is subtle, inverse on a bold fill, or inherit for the surrounding text color.

<Canvas of={Stories.SizesAndAppearance} />

`delay` waits before revealing the spinner. Changing a pending delay restarts the timer; once visible, it stays visible until unmounted. A new operation can reset it with a new key. Non-positive delays reveal immediately.

<Canvas of={Stories.Delay} />

## Accessibility

The default is a status named by the provider's localized Loading text. Use `label` or native `aria-label` to describe the operation; explicit native attributes take precedence. Use `aria-labelledby` to associate visible text.

`isDecorative` hides a spinner when its parent already owns the busy announcement. Button does this for its loading indicator. Reduced motion stops the animation while retaining the accessible status.

## Props

<ArgTypes of={Spinner} />

Native SVG props include `ref`, `id`, `strokeWidth`, `style`, `className`, ARIA and events. Ledger retains `size`, `appearance`, `label`, `isDecorative` and `delay`. Class overrides can adjust dimensions.

### Migration

Existing Spinner calls keep working. Native SVG props and refs no longer need an enclosing element.
