# Tabs

Related views within one page, using [shadcn's Base UI Tabs](https://ui.shadcn.com/docs/components/base/tabs) and [Base UI Tabs](https://base-ui.com/react/components/tabs). Use short view names; use a ToggleGroup or filters to narrow the same rows.

## Anatomy

Compose `Tabs`, `TabsList`, `TabsTrigger` and `TabsContent`. Match each Trigger's `value` to its Content. Put counts, badges and icons in the Trigger's children. Name the List with `aria-label` or `aria-labelledby`.

```tsx
<Tabs defaultValue="controls">
  <TabsList variant="line" activateOnFocus aria-label="Record views">
    <TabsTrigger value="controls">
      Controls <Count value={340} max={9999} />
    </TabsTrigger>
    <TabsTrigger value="history">History</TabsTrigger>
  </TabsList>
  <TabsContent value="controls">Control register</TabsContent>
  <TabsContent value="history">Change history</TabsContent>
</Tabs>
```

Routes compose Tabs, TabsList and TabsContent directly; route state controls the selected value. Supporting context can be contributed separately with Shell.Aside.

## Variants

`TabsList` supports shadcn's `default` filled strip and `line` underline. Ledger retains its color, spacing and focus tokens; line tabs remain 32px tall on a border, with a 2px brand underline made with CSS. Horizontal line tabs fill the available width and align to the start. Their border continues across the container even when only a few tabs exist.

Horizontal line tabs use the kit's `ScrollArea` and horizontal `ScrollBar`. They stay on one row at every container width, including narrow preview panels. Touch, trackpad, scrollbar dragging and arrow-key focus can reach the overflowed tabs. Do not add `flex-wrap`, an overflow utility or another scroller to `TabsList`. Size the `Tabs` container when a bounded example is needed; the List handles its own width and scrolling.

The default filled strip fits its content. Record pages and previews explicitly use `variant="line"`; `activateOnFocus` remains an independent choice. Vertical lists retain their vertical layout and do not receive a horizontal scroller. The exported `tabsListVariants` recipe supplies list styling; the `TabsList` component also supplies the horizontal scrolling composition.

## Accessibility

Base UI owns the tablist, tab and tabpanel roles, selection, focus and panel associations. Keep a panel for the selected tab. Each strip is one Tab stop; arrows move within it and Home/End reach the ends. Focus wraps unless `loopFocus={false}` is set on the List.

Activation is **manual by default**: arrows move focus, then Enter or Space selects. `activateOnFocus` on the List selects as focus moves; use it when the panel can appear immediately. Disabled tabs remain arrow-focusable in the installed Base UI 1.7 contract and cannot activate.

A navigation tab uses `nativeButton={false}` and `render={<Link ... />}` or an anchor. It keeps its href and native modified-click navigation while receiving the tab role. The caller owns synchronization between route state and the controlled value.

<Canvas of={Stories.Links} />

Inactive panels unmount by default. `keepMounted` retains their state; hidden panels remain hidden even with a display class, and Base UI makes their controls inert. Reduced motion removes the underline's opacity transition. The stories exercise keyboard behavior and run accessibility checks in both color modes.

## Props

The four parts expose their corresponding Base UI props, native refs, `render`, events, and state-based `className`/`style`. `TabsList` props and its ref still target the element with `role="tablist"`, inside the horizontal line scroller. The scroller adds no separate Tab stop; keyboard users enter the tablist and arrows or Home/End reveal the focused tab. Public types are `TabsProps`, `TabsListProps`, `TabsTriggerProps` and `TabsContentProps`.

Root accepts `value`/`onValueChange` or `defaultValue`, including numeric values; `null` means no selection. `onValueChange(value, details)` can cancel user activation with `details.cancel()`. Uncontrolled selection falls back when a selected tab disappears or becomes disabled; those automatic notifications are not cancellable. For predictable server rendering, give an explicit enabled initial value.

### Migration and API

| Previous API                                                       | Current API                                                                                   |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `Tabs.List`, `Tabs.Tab`, `Tabs.Panel`                              | `TabsList`, `TabsTrigger`, `TabsContent`                                                      |
| Root `activation="automatic"`                                      | List `activateOnFocus` (omit for manual activation)                                           |
| List `label`                                                       | `aria-label`                                                                                  |
| Trigger `count` / `trailing`                                       | Compose `Count`, `Badge` or other children; use `max={9999}` to preserve the former count cap |
| `asChild`                                                          | `render`; add `nativeButton={false}` for a link trigger                                       |
| `TabListProps`, `TabProps`, `TabPanelProps`                        | `TabsListProps`, `TabsTriggerProps`, `TabsContentProps`                                       |
| Line styling by default                                            | List `variant="line"`; the new default is a filled strip                                      |
| Line List `w-full justify-start`, `overflow-x-auto` or `flex-wrap` | Remove these overrides; horizontal line tabs fill and scroll through ScrollArea               |
