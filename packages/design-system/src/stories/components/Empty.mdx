# Empty

**Status: Stable.**

A region with nothing in it says why, and offers the next step. The picture, the message and the actions sit at the centre of the region; the caller composes them from the parts. A [DataTable](?path=/docs/patterns-data-table--docs) draws its own, so a register never needs to.

<Canvas of={Stories.Playground} />

## When to use it

- **A region with nothing in it yet**: a list, a card or a panel before its first record, with the step that creates one.
- **A search or a filter that leaves nothing**: what matched nothing, and the way to widen it (**Clear filters**).
- **A record that is not there, or a region that failed with nothing else to show**: what is missing or what failed, and the way back or **Try again**.

Not for a load in progress: that is a [Skeleton](?path=/docs/components-skeleton--docs) or a [Spinner](?path=/docs/components-spinner--docs). Not for a failure beside content that stays on the page: that is an [Alert](?path=/docs/components-alert--docs). Not for one value that is missing: that is [Absent](?path=/docs/components-typography--docs), heard as "Not recorded". Not for a register's table: a [DataTable](?path=/docs/patterns-data-table--docs) draws its own empties.

## Anatomy

```tsx
<Empty>
  <EmptyMedia aria-hidden>
    <EmptyIllustration kind="records" />
  </EmptyMedia>
  <EmptyHeader>
    <EmptyTitle>No programs yet</EmptyTitle>
    <EmptyDescription>Create one to define its systems and their work.</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button variant="primary" iconBefore={<Plus />}>
      New program
    </Button>
    <Button variant="secondary">Import</Button>
  </EmptyContent>
</Empty>
```

| Part                | What it is                                                                                                                                                                                    |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Empty`             | The region: a column, centred, on a dashed frame. `size="compact"` for the rail's row; `frame="none"` on a surface that already bounds it.                                                    |
| `EmptyMedia`        | The picture. Holds an `EmptyIllustration`, or `variant="icon"` draws a Lucide icon in the neutral circle. Anything else fits: an avatar, a chart's ghost.                                     |
| `EmptyIllustration` | The kit's picture, on the surface tokens: a scene of ghost records the shape of what the region will hold, sometimes with a badge that says why it is empty. Twelve kinds, below. Decorative. |
| `EmptyHeader`       | The title and its description, at a readable measure.                                                                                                                                         |
| `EmptyTitle`        | A heading in the default size, at the contextual level (an h2 when nothing sets one); body text in a div in compact. `render` sets another element.                                           |
| `EmptyDescription`  | One or two lines: why there is nothing, what creates it.                                                                                                                                      |
| `EmptyContent`      | The actions, centred, wrapping. A second `EmptyContent` holds a quieter row: a link, suggested searches.                                                                                      |

## Variants

Which empty this is decides the picture and the action. The picture is the shape of what the region will hold, so a reader who has never seen a record still learns what one is:

| The region                                      | `kind`             | Action                                                                             |
| ----------------------------------------------- | ------------------ | ---------------------------------------------------------------------------------- |
| Nothing exists yet                              | `records`          | The primary: create the first, import                                              |
| A search or a filter left nothing               | `search`           | Clear filters; suggestions under it                                                |
| Empty because the work is finished              | `done`             | A link to the closed items, or none                                                |
| Nothing assigned or waiting for you             | `inbox`            | None, or a link to everything                                                      |
| Waiting on someone else (a review, an approval) | an icon (Clock)    | None; the description says who acts. Never `done`, which says the work is finished |
| The reader may not see this                     | `locked`           | Request access                                                                     |
| No controls or requirements yet                 | `shield`           | Allocate, map, import a catalog                                                    |
| No files, evidence or documents                 | `document`         | Upload, attach                                                                     |
| No tasks or work items                          | `tasks`            | Add a task                                                                         |
| No people, owners or assignees                  | `people`           | Assign, invite                                                                     |
| No systems, components or parts                 | `tree`             | Add the first node                                                                 |
| No data to chart                                | `chart`            | None; the records make the chart                                                   |
| Nothing scheduled                               | `calendar`         | Schedule                                                                           |
| The record does not exist                       | `search`           | The route back, a link                                                             |
| It could not load, and nothing else shows       | an icon (CloudOff) | Try again                                                                          |
| A tab or a card body with no items              | an icon            | One small action                                                                   |
| A rail's related list                           | compact            | One link                                                                           |

A [DataTable](?path=/docs/patterns-data-table--docs) with no records at all is only its Empty: the toolbar, the header and the hairline go, the frame stays, and the action in it creates the first record. While a search or a filter is what emptied it, the toolbar and header stay and the Empty sits under them without a frame.

## Sizes

`default` is the hero: the picture, a small heading, body copy, medium buttons, `space.300` between the three, `space.600` above and below. `compact` is the rail's row: an icon beside the message, a medium-weight body title, small body copy, a small link.

The hero's buttons are medium even when the caller hands over a small one. A collection passes its toolbar's create action as it is, so an `EmptyContent` in the default size that holds a small primary kit button (Button, IconButton, LinkButton or LinkIconButton) draws every small kit button in that row at medium: the button itself, the halves of a split `ButtonGroup`, and a menu trigger's `render` element. A row without a small primary keeps its sizes, so the suggestions' small secondary buttons and an icon Empty's one small action stay small. Compact never changes a size.

<Canvas of={Stories.HeroActions} />

The order is the same in both sizes: `EmptyMedia`, then `EmptyHeader`, then `EmptyContent`, each a direct child of `Empty`. In the default size that puts `space.300` between the picture and the title; in compact the grid puts the media in the first column and the message and the actions in the second. An `EmptyMedia` inside `EmptyHeader` sits `space.100` above the title, and an `EmptyIllustration` in a compact Empty is a 128 by 84 scene in a row drawn for an icon; each says so once in the browser console, as a warning that never stops the Empty from rendering.

## States

Empty has no states of its own. Loading is [Skeleton](?path=/docs/components-skeleton--docs) or [Spinner](?path=/docs/components-spinner--docs), never an Empty. A failure where other content stays on the page is an [Alert](?path=/docs/components-alert--docs) beside that content; a page or a region that failed and has nothing else to show is an icon Empty that says what failed, with **Try again** (Failed to load, above). A DataTable chooses between its two empties itself: the caller's message when there are no records, the kit's **Nothing matches** with **Clear filters** while a search, a column filter or the caller's own narrowing is active.

## Modifiers

- **`size`**: `default` or `compact`.
- **`frame`**: `dashed` (the default region) or `none`, for a table cell, a page body, a panel that has its own edges. Compact never draws a frame.
- **`kind`** on `EmptyIllustration`: the twelve above. Every scene is 128 by 84px, so empty states sit at one height across a page.

## Content

- **The title says what is missing, in the reader's words**: "No programs yet", "Nothing matches", "Nothing open". Not "Empty", not "No data".
- **The description says why, or what creates it**, in one or two lines. Never advice that points at another control ("Choose another tab").
- **One primary action**, the same verb as the page's own; a secondary beside it at most. In a filtered table the action is **Clear filters**.
- **Suggestions are small secondary buttons** in a second row, after a "Try" in `color.text.subtlest`.
- **One action on the page.** Where a Section's header or a toolbar already carries the create action, the Empty under it says what is missing and stops; it does not repeat the button a tab stop later.
- **A missing record names what is missing and the way back**: "Task not found", why, and a link to the list it came from.

## Long content

A title or a description with an unbroken code, hash or address breaks where it must (`overflow-wrap: anywhere`) inside the message's 400px measure (`dimension.part.emptyMeasure`), so the centred block never widens past its frame or the page.

| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |

## Accessibility

The parts are divs with no automatic landmark or announcement, except the title. In the default size EmptyTitle is a real heading at the contextual level, so a page whose content is an Empty (a first run, a missing record, a route that failed) keeps it in the heading outline: an h2 under the page's h1 when nothing sets a level, one below a titled Section. Where the Empty is the page's only content and there is no PageHeader, give it the page's level with `render={<h1 />}`; where it must not be in the outline, `render={<div />}`. In compact, a rail's row, the title is body text. Give the root `role="region"` and `aria-labelledby` the title when the region is a page's main content; inside a table the cell is enough.

<Canvas of={Stories.TitleLevel} />

The illustration and the icon circle are decorative: `EmptyIllustration` hides itself, and `EmptyMedia` takes `aria-hidden`. Text precedes the actions in reading order, so a screen reader hears why before what. In forced colours a scene keeps its drawing: its surfaces are Canvas with a CanvasText edge, its ghost lines and bars GrayText, a badge a CanvasText disc with a Canvas glyph, and the icon circle keeps its edge.

### In other parts

The default is the centred hero: a heading, the description at a measure, the actions under it. A left-aligned row with a body-weight title is `size="compact"`. `Related`, `Item.Group` and `DataTable` compose the parts themselves; a DataTable's `empty` takes `illustration`, `secondary` and `filtered`, and draws **Nothing matches** with **Clear filters** on its own while a search, a filter or the caller's `narrowed` is active.

## Don't

A filtered table's empty says what emptied it and offers Clear filters, never a grey line where the rows were. An empty state's action is the page's own verb, never advice that points at another control, and under a header that already carries the create action it says what is missing and stops.
