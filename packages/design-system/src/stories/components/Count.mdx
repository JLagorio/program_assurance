# Count

A number in a pill: unread items, rows in a group, results behind a filter, findings on a control. It sits after the name of what it counts and is named by it. Anything above `max`, 99 by default, renders as `99+`. Not the notification circle on a corner.

## Anatomy

| Part   | What it is                                                                                                                                                                   |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pill   | 20px tall, at least 20px wide, round, `space.075` at each end: the neutral fill or one of four others.                                                                       |
| Number | `font.body.small` medium, tabular, centred, in the reader's locale (1,189; 1.189 in German). Never a word. An added count carries a plus and a removed one a minus (U+2212). |

## Variants

| Appearance  | Use                                                                                           |
| ----------- | --------------------------------------------------------------------------------------------- |
| `default`   | Rows in a group, results behind a filter, items in a section. The neutral fill.               |
| `primary`   | The one count on the screen that must be seen: unread, new since you last looked. Brand fill. |
| `important` | What needs attention now: overdue, blocked. Danger fill.                                      |
| `added`     | Rows a change adds. Success fill, subtle, and a plus: +12.                                    |
| `removed`   | Rows a change removes. Danger fill, subtle, and a minus: −3.                                  |

Not built, and why: a corner placement on an avatar or an icon (a notification circle); the shell's navigation has no unread counts yet, and when it does the Count will sit after the item's label, not on its icon. No count in a tone's text colour without a fill; the number alone is a Stat.

## Sizes

One size, 20px, the height of a small Badge, so the two sit on one line. The width grows with the digits and stops at three and a plus.

## States

A Count has one state. Zero is a number: where the reader asks how many (a Section, a Related card, an Item group, a tab's rows), a 0 says "none" where no pill could mean "not counted", so Section, Related and Item.Group show a Count of 0. A Table.Group hides it, since an empty group has no rows to head. A section with nothing in it still says so in words, in its Empty.

## Modifiers

- **`value`** as a number, formatted in the reader's locale, or a string shown as given, when the text is not a number the pill should cap ("12 of 40" is not a Count).
- **`max`** for the ceiling: 99 by default; 999 or 9999 on a tab that counts rows, one ceiling across a product. 9999 is the most a pill holds; a larger total is a Stat.
- **`appearance`** as in Variants; `default` when unsaid.

## Content

- **A number.** Digits only; the word before it says what they count.
- **Named by its label.** "Findings 3", "Evidence 7": the Count follows the label at `space.100`.
- **Capped, not exact.** Past the ceiling the reader needs the order of magnitude; the exact number is a Stat.
- **Long content.** A Count never truncates and never wraps: it caps at `max`. A number too long for a pill (an amount, a total past 9999) is a Stat or text.

## Style

| Element   | Token                                                                                        |
| --------- | -------------------------------------------------------------------------------------------- |
| Pill      | `dimension.control.xsmall` 20px tall and at least as wide · `radius.full` · `space.075` ends |
| Number    | `font.body.small` medium · tabular                                                           |
| default   | `color.background.neutral` · `color.text.subtle`                                             |
| primary   | `color.background.brand.bold` · `color.text.inverse`                                         |
| important | `color.background.danger.bold` · `color.text.inverse`                                        |
| added     | `color.background.success` · `color.text.success`                                            |
| removed   | `color.background.danger` · `color.text.danger`                                              |

## Accessibility

- **It is text**, read in the flow after its label: "Findings, 3". The label names it; a Count on its own says only a number.
- **`99+` is read as "99 plus"**, which is the meaning.
- **Not colour alone.** An important count sits beside a label that says why; the red ranks it. An added or removed count carries its sign, so a screen reader hears "plus 12" and "minus 3", and forced colours, which drop the fills, keep the difference.
- **Nothing to focus.** A Count inside a Tab or a Collapsible is part of that control's name.
