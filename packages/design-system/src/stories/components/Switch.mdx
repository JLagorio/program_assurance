# Switch

An on/off setting built on Base UI with the shadcn composition API. The thumb is included; compose the setting's label and supporting text outside the switch.

```tsx
<label className="inline-flex items-center gap-100">
  <Switch defaultChecked />
  Notify the owner
</label>
```

<Canvas of={Stories.SwitchMatrix} />

## Sizes and state

| Size | Track | Thumb |
| --- | --- | --- |
| `default` | 32 × 20px | 16px |
| `sm` | 24 × 16px | 12px |

These dimensions use Ledger spacing tokens. The thumb moves toward the inline end when checked, follows RTL direction, and stops animating when reduced motion is requested.

Use `defaultChecked` for local state or `checked` and `onCheckedChange(checked, details)` for controlled state. `details.cancel()` rejects a change. `disabled` blocks activation and removes the switch from the tab order; `readOnly` retains focusability while preventing state changes.

## Labels, Field and forms

A wrapping `<label>` or a sibling `<label htmlFor={id}>` names the setting and toggles it when clicked. Keep the name stable across on/off states. [Field](?path=/docs/components-field--docs) supplies the label, hint/error description and required/invalid ARIA wiring:

```tsx
<Field label="Notify the owner" hint="Send an email when a finding changes status.">
  <Switch checked={notify} onCheckedChange={setNotify} />
</Field>
```

`name`, `value`, `uncheckedValue`, `form` and `required` configure the hidden checkbox used for native submission and validation. Without `uncheckedValue`, an unchecked switch contributes no entry. `Field isRequired` marks the control for assistive technology; use Switch's native `required` when browser validation is intended.

In installed Base UI 1.7, native form reset is caller-owned: restore controlled `checked` state in the form's `onReset` handler.

## Native props and composition

The default visible root is a `<span role="switch">`, with a hidden checkbox beside it. `ref` targets the visible root; `inputRef` and `id` target the hidden input. Native event handlers and state-based `className`/`style` callbacks apply to the root.

For a native button root, pass `nativeButton` and `render={<button />}`. In that mode `id` targets the button, and refs and event handlers merge with those on the rendered element. Every switch needs a visible label, `aria-label`, or `aria-labelledby`.

## Migration

Replace label children and the `description` prop with a wrapping label, sibling label or Field. The track is now 32px wide by default instead of 40px; `sm` adds a 24px option. A root ref now receives the visible span by default, and `inputRef` accesses the form input. Native `checked`, `defaultChecked` and `onCheckedChange` usage remains supported.
