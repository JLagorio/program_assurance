# Sheet

Based on [shadcn’s Base UI source](https://ui.shadcn.com/docs/components/base/sheet) and [Base UI](https://base-ui.com/react/components/dialog). Ledger retains its tokens and application layouts.

## Anatomy

An edge panel using Base UI Dialog. Compose Sheet, SheetTrigger, SheetContent, SheetHeader, SheetTitle, SheetDescription, SheetFooter and SheetClose.

## Accessibility

Base UI provides modal focus trapping, nested dismissal and focus return. Give the panel a title. Keep a close control available; Content includes one by default. Put scrolling on a body child so the header and footer remain reachable.

## Props

Root exposes the generic Base UI Dialog contract. Content accepts native popup props, refs, render, initialFocus and finalFocus, plus side and showCloseButton. The four physical sides follow shadcn; Ledger also accepts start/end for locale-relative edges.

### Migration and API

- Replace title/subtitle/footer shortcuts with Title, Description and Footer children. Eyebrow, facts, back actions and toolbars are ordinary header/body composition.
- Replace onClose with onOpenChange; returnFocusRef becomes Content finalFocus; width becomes Content style.maxWidth.
- Content defaults to physical right and a 420px maximum width for side panels. Migrated callers explicitly use logical end to preserve RTL behavior.
