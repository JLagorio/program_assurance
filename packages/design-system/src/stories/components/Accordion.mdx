# Accordion

A coordinated set of expandable sections, implemented with the shadcn Base UI composition. Use Collapsible for one independent disclosure.

## Anatomy

Compose the flat `Accordion`, `AccordionItem`, `AccordionTrigger`, and `AccordionContent` exports. Each item needs a stable value; values are always arrays, and `multiple` allows more than one open item.

```tsx
<Accordion defaultValue={["delivery"]}>
  <AccordionItem value="delivery">
    <AccordionTrigger>What delivery options are available?</AccordionTrigger>
    <AccordionContent>Delivery information.</AccordionContent>
  </AccordionItem>
</Accordion>
```

## Variants and states

<Canvas of={Stories.Examples} />

Use `value` with `onValueChange` for controlled state and `defaultValue` otherwise. Use `disabled` on the root or an item. `keepMounted` preserves panel state while closed; `hiddenUntilFound` additionally lets browser find-in-page reveal closed content.

<Canvas of={Stories.ControlledAndRetained} />

## Accessibility

Triggers are native buttons with Enter, Space, and normal Tab behavior. Base UI follows current APG guidance and does not add arrow-key roving focus. The trigger wrapper supplies the heading and associates every panel with its trigger.
