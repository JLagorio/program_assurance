# Accordion

A coordinated set of expandable sections, implemented with the shadcn Base UI composition. Use Collapsible for one independent disclosure.

## Anatomy

Compose the flat `Accordion`, `AccordionItem`, `AccordionTrigger`, and `AccordionContent` exports. Each item needs a stable value; values are always arrays, and `multiple` allows more than one open item.

```tsx
<Accordion defaultValue={["delivery"]}>
  <AccordionItem value="delivery">
    <AccordionTrigger>What delivery options are available?</AccordionTrigger>
    <AccordionContent>Delivery information.</AccordionContent>
  </AccordionItem>
</Accordion>
```

| Part             | What it is                                                                                                                                                                                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Accordion        | The set: a column of items, `flex` and full width.                                                                                                                                                                                                                            |
| AccordionItem    | One section, with a hairline between items.                                                                                                                                                                                                                                   |
| AccordionTrigger | The heading and, inside it, the button: the title at the start and a chevron at the end that turns with `aria-expanded`. The row tint under the pointer reaches `space.100` before a title that sits flush with the content, and the chevron sits `space.100` inside the end. |
| AccordionContent | The panel that folds, with `data-open` and the measured `--accordion-panel-height`, and a `space.200` box under the content inside it.                                                                                                                                        |

`AccordionTrigger` renders the item's heading itself. `headerProps` reach that heading (a `className`, native attributes, a ref, or `render` for another element), and `icon` replaces the chevron with another mark, or `null` for none; a custom mark shows the state itself, from the trigger's `aria-expanded`. Every part's `className` is a string or Base UI's state function, and `AccordionContent`'s reaches the panel, not the box inside it.

Use `value` with `onValueChange` for controlled state and `defaultValue` otherwise. Use `disabled` on the root or an item. `keepMounted` preserves panel state while closed; `hiddenUntilFound` additionally lets browser find-in-page reveal closed content.

## When to use it

- **A set that belongs together**, where the reader opens one section or several: the parts of a long form's help, the groups of a settings page.
- **Not** for one titled block that folds: that is a [CollapsibleHeader](?path=/docs/components-collapsible--docs), a collapsible [Section](?path=/docs/layout-section--docs) on a page, or an [Inspector.Group](?path=/docs/patterns-inspector--docs) in a rail of facts.
- **Not** for switching between views of one record: those are [Tabs](?path=/docs/components-tabs--docs).
- **Not** for a row that discloses more of itself: Item's `isCollapsible` and Table's disclosure column own their chevrons.

## Accessibility

Triggers are native buttons with Enter, Space, and normal Tab behavior. Base UI follows current APG guidance and does not add arrow-key roving focus. The trigger wrapper supplies the heading and associates every panel with its trigger. The chevron is decoration, turned by the expanded state rather than by colour; under reduced motion it turns without moving and the panel opens without the fold.

Each heading takes the contextual level from the nearest [HeadingLevelProvider](?path=/docs/primitives-heading--docs), titled Section or panel body, and is an h3 when nothing sets one. Wrap the Accordion in a HeadingLevelProvider for another level: `level={2}` where it is a page rail's first heading under the h1. `headerProps.render` sets one item's element.

<Canvas of={Stories.HeadingLevel} />

A panel clips only while it folds: settled open, its overflow is visible, so the focus ring of a link or a button at its edge shows whole. Each panel folds on its own measured height, so a Collapsible inside an open item eases rather than snapping (Components/Collapsible, Nested motion).
