# Accordion

Several sections that know about each other. An **Accordion** is a set of [Collapsible](?path=/docs/components-collapsible--docs) rows with one keyboard model: the arrows move between the titles, and in `single` mode opening one closes the rest. It is the rail's shape: the Inspector's groups are an Accordion of KeyValue rows, `multiple`, every group open.

Reference material only. The record's work is Sections, open and in the outline: content the reader will read in full is never folded, because a fold adds a click and hides the page.

## Anatomy

| Part  | What it is                                                                                                                                                 |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Set   | `Accordion`: the items in a column, a 1px rule in `color.border` above each and one below the last. It holds which items are open.                         |
| Item  | `Accordion.Item`: one Collapsible row and body, keyed by `value`. Title, count, chevron and body as on the Collapsible page.                                |
| Title | Flush left in `font.body` semibold; a heading of `headingLevel` when the set is in the page's outline.                                                      |
| Body  | Under the row, opening to its measured height in `motion.duration.medium`. A region landmark named by its title, which is why titles in one page differ.  |

## Variants

Two, by `type`. **`single`**, the default, opens one item at a time and lets the open one close: a set the reader takes one by one, where seeing two would be noise. **`multiple`** is independent items with one keyboard model: reference the reader compares, which is the Inspector. The kit keeps `single` as the default and asks for `multiple` wherever two rows are read together.

Both come flush or **`inset`** per item, as on the Collapsible page; the first item on a surface drops its rule with `border-t-0`, and the set drops its last rule with `border-b-0` when the surface has a border of its own.

## Sizes

One row, 36px, as the Collapsible's; the set is as tall as its rows and its open bodies.

## States

The set's state is which items are open: none (the titles as the overview), one, or several under `multiple`. Each row has the Collapsible's states: closed, open, hover, focus and disabled.

## Modifiers

- **`type`** as in Variants.
- **`defaultValue`**, or **`value`** and **`onValueChange`** when the caller holds it: the open item's value, or the open items' values for `multiple`. Unsaid, every item starts closed.
- **`headingLevel`**: every title as an h2 to h6, so the set is in the page's outline. Under a Section's h2 the rows are h3s.
- **`count`**, **`inset`** and **`disabled`** per item, as on the Collapsible.

## Content

- **Two or more items.** One section is a Collapsible.
- **Titles are nouns, and differ within a page:** each body is a region landmark named by its title, and two "Details" regions confuse a screen reader's landmark list.
- **Closed by default when the set is long;** open the one the reader came for; open all when the set is the rail's groups and the reader compares.
- **The bodies are reference:** KeyValue rows, Text, a short list. Never the record's work, never a table the reader works in.
- **Never nested,** and never a Tree's job: a hierarchy folds in a Tree.
- **The whole page scrolls,** never one body.

## Style

The Collapsible's tokens per row. The set adds one 1px `color.border` rule under the last item.

## Accessibility

- **Each row is a button with `aria-expanded`** and `aria-controls`; each body is a region named by its title. Radix Accordion sets them.
- **Keyboard:** Tab reaches the first row and Tab again the next; Up and Down move between the rows of one set and wrap, Home and End go to the ends; Enter or Space toggles. Controls inside an open body join the tab order after their row.
- **Headings:** with `headingLevel` the titles are headings, so the outline shows the set. The Inspector sets none, because a rail's groups are labels, not sections of the page.
- **Reduced motion** shows the bodies at once.
- **The a11y gate** checks the roles and the landmark names in the matrix, which is why two sets on one page cannot share titles.

## Props

### Accordion.Item

By hand until the generated tables reach a part:

| Prop        | Type                       | What it is                                                                      |
| ----------- | -------------------------- | ------------------------------------------------------------------------------- |
| `value`     | `string`, required         | What the Accordion opens and closes by.                                         |
| `title`     | `ReactNode`                | The row's title: what is inside, as a noun.                                     |
| `count`     | `number \| string \| null` | A Count after the title. Zero, null and undefined show nothing.                 |
| `disabled`  | `boolean`                  | A section the reader cannot open. Rare.                                         |
| `inset`     | `boolean`                  | The row and the body stepped in by `space.300`, for a surface with its own edge. |
| `className` | `string`                   | Layout only.                                                                    |
| `children`  | `ReactNode`                | The body: Text, KeyValue rows, a list.                                          |
