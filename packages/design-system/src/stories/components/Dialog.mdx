# Dialog

Based on [shadcn’s Base UI source](https://ui.shadcn.com/docs/components/base/dialog) and [Base UI](https://base-ui.com/react/components/dialog). Ledger retains its tokens and application layouts.

## Anatomy

A modal task, composed from Dialog, DialogTrigger, DialogContent, DialogHeader, DialogTitle, DialogDescription, DialogFooter and DialogClose. Content includes its portal, backdrop and optional close button; DialogPortal and DialogOverlay are available for custom composition.

## Accessibility

Use a named title and a close control. Base UI owns focus trapping, Escape, outside dismissal and nested dialog coordination. Content exposes native initialFocus and finalFocus. A supplied description is associated automatically. For triggerless tasks opened by disappearing actions, supply a stable finalFocus target.

## Props

Root exposes the native generic Base UI contract, including controlled/uncontrolled state, trigger payloads, handles, modality and cancellable onOpenChange. Native refs, render and state-based styles/classes reach their matching parts. Content adds showCloseButton; Footer can add a close button too.

### Migration and API

- Replace configured title, description and footer props with their explicit parts; body and aside layouts are ordinary children.
- Replace onClose with onOpenChange. Cancel a close request through details.cancel() while saving, and disable the caller-composed Close control.
- Move returnFocusRef to Content finalFocus, and width to Content style/className. Existing app dialogs retain their 520/860px widths and top placement.
- The default Content is centered, 520px maximum, with bounded height. Ledger Header/Footer own their padding; place scrolling body padding in children.
