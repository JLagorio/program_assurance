# Resizable

User-sized panes following [shadcn’s Resizable source](https://ui.shadcn.com/docs/components/base/resizable), built on react-resizable-panels. A plain dividing rule is a Separator.

## Anatomy

```tsx
<ResizablePanelGroup>
  <ResizablePanel defaultSize="30%" minSize="20%">
    List
  </ResizablePanel>
  <ResizableHandle aria-label="Resize the list" withHandle />
  <ResizablePanel>Detail</ResizablePanel>
</ResizablePanelGroup>
```

Give the group a sized parent. Panels clip their contents; put ScrollArea inside a scrolling pane. `withHandle` adds a visible grip.

## Variants and states

`orientation="vertical"` stacks panes. Native panel props include minimum/maximum sizes, collapse behavior and resize callbacks. The library owns layout, pointer resizing and keyboard behavior.

Persist layouts where the composition needs it. Use the upstream `useDefaultLayout` hook, stable group/panel IDs and the hook’s `defaultLayout`/`onLayoutChanged` pair. Preserve an existing ID to read its saved layouts. Supply server-safe storage when rendering the hook on the server; the story demonstrates this explicitly.

## Accessibility

The handle is a focusable separator with the orientation of the rule: a horizontal group has a vertical separator. Arrow keys resize; Home/End reach bounds; Enter toggles a collapsible panel. Name handles with `aria-label`, especially when several splits are present. Group and Panel expose native `elementRef`, `groupRef` and `panelRef` instead of translating them into a generic ref.

## Props

Replace `Resizable` with `ResizablePanelGroup`, `.Panel` with `ResizablePanel`, and `.Handle` with `ResizableHandle`. Replace handle `label` with `aria-label`; move `persist` into the native hook at the caller. **Numeric sizes now mean pixels.** Change old percentage numbers such as `minSize={20}` to `minSize="20%"`. Existing PreviewSplit proportions are preserved.
