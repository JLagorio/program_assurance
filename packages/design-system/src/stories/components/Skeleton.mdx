# Skeleton

A placeholder in the shape of what is loading, so the layout holds still and the reader knows what is coming: a line where text will be, a circle where the avatar, a block where the chart. One shape in any size rather than a skeleton per component: four kinds, sized to the thing. A page's first paint is a [PageSkeleton](?path=/docs/patterns-pageskeleton--docs) built from these; a wait on an action is a [Spinner](?path=/docs/components-spinner--docs).

## Anatomy

| Part   | What it is                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------------- |
| Shape  | A rounded box in `color.skeleton`, pulsing: a line, a heading, a circle or a block.                           |
| Lines  | Several lines `space.100` apart, the last two thirds wide, the way a paragraph ends.                          |
| Region | The container that waits, which says so with `aria-busy`; the skeleton itself is hidden from a screen reader. |

## Variants

| Shape     | Size                                            | Where                                         |
| --------- | ----------------------------------------------- | --------------------------------------------- |
| `line`    | 12px tall, `radius.small`                       | A line of body text; `lines` for a paragraph. |
| `heading` | 20px tall, `radius.small`                       | A title, a record's name.                     |
| `circle`  | `width` square, 32px by default                 | An avatar, an icon, a marker.                 |
| `block`   | `height` tall, 96px by default, `radius.medium` | A card, a chart, an image, a table's body.    |

Not built, and why: a shimmer, because a pulse says the same with less motion and stops under reduced motion; per-component skeletons, because the four shapes compose into any of them, and the compositions live where the components do (PageSkeleton, Chart's skeleton per kind); a colour prop, because the skeleton is always `color.skeleton`.

## Sizes

The size is the thing's. `width` and `height` take a number in px or a CSS length; without them a line or a heading is as wide as its container, a circle is 32px and a block 96px tall. Match the text's line height (a line is 12px in an 18px line, a heading 20px in a 28px one) and the layout does not move when the content lands.

## States

A skeleton has one state: waiting. It pulses in `motion.duration.slow` and stops under reduced motion. When the content arrives the skeleton is gone; it never sits beside what loaded.

## Modifiers

- **`shape`** as in Variants; **`lines`** for a paragraph of lines.
- **`width`** and **`height`** in px or any length.
- **`className`** and **`style`** for the rest: a flex child, a fixed width from a token.

## Content

- **The shape of what is coming**, in its size and its place: as many lines as the text has, a circle where the avatar sits.
- **No more than arrives.** Six lines for a two-line note means the page shrinks when it loads.
- **Load in place.** A skeleton for content that arrives progressively; a Spinner for an action that has no place to hold.
- **Not for a wait the reader caused** (saving, exporting): that is the button's `isLoading`.

## Style

| Element | Token                                                  |
| ------- | ------------------------------------------------------ |
| Fill    | `color.skeleton`                                       |
| Line    | 12px · `radius.small`                                  |
| Heading | 20px · `radius.small`                                  |
| Circle  | `radius.full`                                          |
| Block   | `radius.medium`                                        |
| Lines   | `space.100` apart, the last 66% wide                   |
| Motion  | opacity pulse, 2s; none under `prefers-reduced-motion` |

## Accessibility

- **Hidden from a screen reader** (`aria-hidden`): a skeleton says nothing a reader can use.
- **The region says it is busy**: put `aria-busy` on the container that waits, and remove it when the content lands, so a screen reader hears the change once.
- **Reduced motion stops the pulse**; the shape stays.
- **Contrast is not required**: a skeleton is decorative, and `color.skeleton` is deliberately faint.
