# Skeleton

A placeholder that holds the space of loading content. It follows shadcn's native div contract, with Ledger's line, heading, circle and block options. Use [PageSkeleton](?path=/docs/patterns-pageskeleton--docs) for a page's first paint and [Spinner](?path=/docs/components-spinner--docs) for an action in progress.

<Canvas of={Stories.SkeletonMatrix} />

## Anatomy

The outer element is a `div` with `data-slot="skeleton"`, hidden from assistive technology by default. A single shape paints this element in `color.skeleton`. With `shape="line"` and `lines > 1`, the outer div groups the generated lines with `space.100` between them.

Native attributes, events and refs always belong to the outer div. IDs, labels and handlers are never copied to each generated line.

## Shapes and sizing

| Shape | Default geometry | Use |
| --- | --- | --- |
| `line` | 12px tall, full width, `radius.small` | Body text. Use `lines` for a paragraph. |
| `heading` | 20px tall, full width, `radius.small` | A title or record name. |
| `circle` | 32px square, `radius.full` | An avatar or icon. `width` also sets its height unless `height` is supplied. |
| `block` | 96px tall, full width, `radius.medium` | A card, chart or image. |

`width` and `height` accept a number in pixels or a CSS length. On a single shape, explicit `style` values override those dimensions. Existing className overrides continue through the package's class merger.

For generated lines, `width` and `height` apply to **each line**; `className` and `style` apply to **the wrapper**. The last line is two thirds wide when `width` is omitted. An explicit `width` sizes every line equally, including the last.

## Native props and content

<Canvas of={Stories.NativeAttributes} />

```tsx
<Skeleton
  ref={placeholderRef}
  id="record-placeholder"
  shape="block"
  height={120}
  data-record="preview"
/>
```

Native children render once. In multiline mode, supplied children replace the automatic lines; omitting children generates them. Explicit `null`, `false` or `0` are supplied content. Native HTML content also replaces automatic lines and follows React's normal content rules.

Skeleton uses a native div, as the shadcn reference does. It has no `render` or `asChild` prop. Compose a more specific loading layout with several Skeletons inside a normal container.

## Accessibility and motion

- `aria-hidden` defaults to `true` so placeholders do not announce meaningless shapes. Explicit native ARIA props can override the default.
- Put `aria-busy` and any loading message on the region that is waiting; clear its busy state when content arrives.
- Keep placeholders noninteractive. Use a nearby status message for meaningful loading information.
- Shapes pulse while waiting. The existing reduced-motion stylesheet stops the pulse and keeps the layout in place.
- Match the size and amount of expected content, then replace the placeholders when it arrives.

## Props

`SkeletonProps` includes native div props plus `shape`, `lines`, `width` and `height`.

## Migration

Existing shapes, line counts, dimensions and style overrides retain their behavior. Skeleton now forwards native attributes, events, children and refs and exposes `data-slot="skeleton"` on the outer div. Multiline refs point to the wrapper, not an individual line. No existing consumer changes are required.
