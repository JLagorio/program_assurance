# Chart

Data drawn on the chart tokens. `Chart` is the Frame: the figure that names a plot, keys it, holds its states, keeps the way back from a drill-down, and lays the same numbers out as a table one toggle away. Each kind of plot is its own part with its own page: [Bar](?path=/docs/components-chart-bar--docs), [Line](?path=/docs/components-chart-line--docs), [Area](?path=/docs/components-chart-area--docs), [Donut](?path=/docs/components-chart-donut--docs), [Sparkline](?path=/docs/components-chart-sparkline--docs), [Scatter](?path=/docs/components-chart-scatter--docs), [Treemap](?path=/docs/components-chart-treemap--docs) and [Heatmap](?path=/docs/components-chart-heatmap--docs). Recharts draws; the kit decides the paint, the marks, the grid, the tooltip, the legend and the motion, so a chart reads like the rest of the page in both modes. Walked against Carbon's data visualization guidance and its 26 chart types, Atlassian's data visualization colour, Base's Charts, and HubSpot's chart components; the colour rules follow the data-visualization method, and the categorical order is validated, not eyeballed.

## Kinds

The data's job picks the kind, and sometimes the right kind is not a chart: one number is a [Stat](?path=/docs/components-stat--docs), one ratio against a limit is a [Progress](?path=/docs/components-progress--docs) bar, and more than seven classes that all carry meaning is a [Table](?path=/docs/components-table--docs).

| The reader must                                 | Part                                                                 | Colour job                                         |
| ----------------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------- |
| Compare sizes across categories                 | [`Chart.Bar`](?path=/docs/components-chart-bar--docs)                | One hue; `horizontal` for long names               |
| See parts of each whole                         | `Chart.Bar` stacked                                                  | Status tones, or the categorical set               |
| Read actual against planned                     | `Chart.Bar` with `target`                                            | The series' tone; the target is ink                |
| See when things happen                          | `Chart.Bar` horizontal with `[from, to]` values                      | One hue                                            |
| Follow a trend                                  | [`Chart.Line`](?path=/docs/components-chart-line--docs)              | `brand`, or a tone per series                      |
| Follow parts of a whole over time               | [`Chart.Area`](?path=/docs/components-chart-area--docs) stacked      | Status tones, or the categorical set               |
| See one number against its whole                | [`Chart.Donut`](?path=/docs/components-chart-donut--docs)            | The parts' tones on the track                      |
| Read a score against a scale                    | `Chart.Donut` `arc="half"`                                           | The tone the score earns                           |
| See a trend beside a number                     | [`Chart.Sparkline`](?path=/docs/components-chart-sparkline--docs)    | One tone                                           |
| Place things on two measures                    | [`Chart.Scatter`](?path=/docs/components-chart-scatter--docs)        | `brand`, or at most three groups                   |
| See how a total splits, and splits again        | [`Chart.Treemap`](?path=/docs/components-chart-treemap--docs)        | The categorical set, one hue per branch            |
| Read how much across two dimensions             | [`Chart.Heatmap`](?path=/docs/components-chart-heatmap--docs)        | `sequential`: one hue, light to dark               |
| Read above and below across two dimensions      | `Chart.Heatmap` `scale="diverging"`                                  | Two hues around grey                               |
| Read status by place                            | `Chart.Heatmap` with a tone function                                 | The Badge's fills, values printed                  |

Not built, and why: no pie (a ring with the number in the middle says more, and a two-slice pie is a Stat); no second value axis (two measures of different scale are two charts, or one indexed; a dual axis invents a correlation); no gauge with a needle (the half ring reads the same and its number is text); no radar, boxplot, histogram, lollipop, alluvial, word cloud, circle pack or map (Carbon has them; none of the four products has asked, and a histogram is a bar chart of bins the data layer makes); no zoom, brush or export toolbar (Carbon's; a range is a control in the Frame's `actions`, a drill-down is the Frame's `path`, and export is the register's).

## Anatomy

| Part        | What it is                                                                                                                                                              |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Title       | `font.body` medium in `color.text`, a noun phrase: what the chart shows. It names the plot to a screen reader.                                                           |
| Description | `font.body.small` in `color.text.subtle`, one line under the title: the period, the unit, the source.                                                                   |
| Path        | A [Breadcrumb](?path=/docs/components-breadcrumb--docs) under the description while a drill-down is open: every level so far, every crumb but the last a way back.      |
| Legend      | Swatch and label per series, `font.body.small` in `color.text.subtle`, at the end of the header. A square for a fill, a stroke for a line, a dot for a point. Present for two or more series; a single series needs none, the title names it. |
| Actions     | Controls at the end of the header: a range, a filter, a Retry. Then the tools: the Table toggle, the Download menu (the table twin as CSV, the plot as PNG), the Expand button. |
| Plot        | The part's marks on a hairline grid. Ticks are `font.body.xsmall` in `color.text.subtlest`; grid lines and the axis line are `color.border`, solid, 1px. Focusable when named, with the kit's focus ring on the keyboard only. |
| Tooltip     | The overlay surface. The category first, then every series at that point: the name, then the value in `font.body.small` medium, keyed by the mark's swatch. A stack adds its total. |
| Card        | The details on a chosen mark: a Popover anchored to it, the kit's head (swatch, name, category, value; or every series at a category), then whatever the caller adds.   |
| Table       | The same numbers as a [Table](?path=/docs/components-table--docs), one toggle away: the category column, then a column per series.                                      |

## Variants

| Variant                     | Use                                                                                                                    |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `Chart` (the Frame)         | Every chart on a page. Title, description, legend, actions, the states, the path, the table twin, the legend's interaction. |
| `legend="top"`, `"bottom"`, `"none"` | The legend at the end of the header (the default for two or more series), under the plot when the header is busy, or nowhere for one series. |
| `path`                      | The Frame of a drill-down: the levels so far as crumbs, the last being the current one.                                |
| `download`, `expandable`    | The tools: a Download menu with the table twin as CSV and the plot as a PNG at twice the pixel density; an Expand button that opens the same chart in a large Dialog. |
| `syncId`                    | Charts that share their hover: small multiples, one hover across them, on one `domain`.                               |
| `texture`                   | Every series wears a pattern as well as its colour, in the plot, the legend, the tooltip and the card.                 |
| `Chart.Legend`              | The key on its own, outside a Frame: beside a Donut, under a stacked bar. Inside a Frame it is the interactive one.     |
| The parts                   | One per kind, each on its own page. A part inside the Frame inherits its name, its formats, its loading state and its legend's state. |

## Sizes

| Size     | Height | Where                                                                         |
| -------- | ------ | ----------------------------------------------------------------------------- |
| `small`  | 120px  | A rail, a card in a grid of them, a cell of the matrix.                       |
| `medium` | 200px  | A Section. The default.                                                       |
| `large`  | 320px  | The one chart a page is about: the scatter of risks, the treemap of findings. |

The height is the whole plot, axis band included, so a card never scrolls inside itself. `height` takes pixels when a layout must. The Frame's states stand in at the same height, so nothing moves when the data arrives. A Donut and a Sparkline are sized in pixels, since they sit inline; a Heatmap's `size` is its cell's height.

The width is the container's. Below about 480px the header wraps: the legend and the tools drop under the title, and the plot keeps its height. An expanded chart is the same Frame at `large` in a Dialog.

## States

| State      | What changes                                                                                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hover      | The tooltip, for every series at that point; a hovered bar and a hovered slice take the tone's `hovered` step, a slice grows 2px, a line's marker appears. Synced charts show their tooltips together. A hovered legend item dims the other series to `opacity.disabled`, faded over `motion.duration.fast`. |
| Isolated   | A clicked legend item hides its series; the swatch hollows. Clicking the last visible one shows everything again.                                                       |
| Chosen     | A clicked mark, or the category Enter chose on the focused plot: the other marks dim, the card opens on it. Escape or a click outside closes the card and focus returns to the plot. |
| Loading    | The plot's own silhouette in `color.skeleton`, pulsing, at the plot's height: columns, a line, a ring, dots, tiles. The header stays.                                   |
| Refreshing | The last plot stays, dimmed to `opacity.loading`, with a Spinner beside the title. For a refetch, so the reader keeps what they had.                                    |
| Empty      | A dashed frame at the plot's height: "Nothing to show yet" and one line of why.                                                                                        |
| Error      | The same frame, the title in `color.text.danger`, and a Retry in `actions`.                                                                                            |
| Table      | The Table toggle swaps the plot for the same numbers as a Table; the legend and the actions stay.                                                                      |

## Modifiers

- **`legend`**, **`swatch`**, **`actions`**, **`status`**, **`statusTitle`**, **`statusText`** on the Frame.
- **`path`** on the Frame for a drill-down; each crumb's `onSelect` goes back.
- **`download`** (`["csv", "png"]`) and **`expandable`** for the tools; **`summary`** for the sentence a screen reader hears; **`syncId`** to share the hover; **`texture`** for the patterns.
- **`data`**, **`x`**, **`xLabel`** on the Frame, so it can lay the table out.
- **`format`** and **`formatX`** for the numbers and the categories, set once on the Frame and inherited by the part, the tooltip, the card and the table.
- **`size`** and **`height`** on the Frame, for the states that stand in for the plot; the same on the part.
- On every part: **`label`** to name a plot outside a Frame, **`loading`** to draw its skeleton, **`onSelect`** to hear a choice, **`details`** to open a card on it. Each part's page lists its own.

## Choosing a mark

A chart that answers "what is this?" and "show me more" is the point of a platform's charts, and the kit does it one way everywhere:

- **`onSelect`** hears a choice: a bar, a point, a slice, a tile, a cell. It filters what is under the chart, or drills down.
- **`details`** opens a card on the choice: the kit renders its head (the swatch, the name, the category, the value; for a whole category, every series' value) and the caller renders the rest under it, facts and a way to the record. The card is a Popover anchored to the mark: Escape and a click outside close it, and focus returns to the plot.
- **A drill-down** is a Frame whose `path` grows: the click redraws the same plot one level down, the marks moving to their new places, and the path holds the way back. Two or three levels is the ceiling; past that the reader wants a table with filters.
- **The keyboard gets the same.** A named plot is focusable; the arrow keys move across the categories with the tooltip; Enter chooses the one under the tooltip. A Heatmap's cells are buttons and do it themselves.
- **A pointer over a mark that chooses is a pointer.** A plot with neither `onSelect` nor `details` shows the default cursor and no focus ring on a click, so nothing promises what it cannot do.

## Small multiples

Two measures of different scale, or more than six series, are several small charts, not one big one. The Frame makes them honest: give every chart the same `domain`, so a bar's height means the same thing on each, and the same `syncId`, so a hover on one shows the same category on all. A cumulative that needs its own scale says so in its description and keeps `baseline="auto"`.

## Textures

Colour is never the only channel, and in print, under colour-vision loss and in a forced-colours mode it is not a channel at all. `texture` on the Frame gives every series a pattern in its own colour, in a fixed order the legend and the tooltip repeat: the first series solid, then hatch, back-hatch, dots, cross, lines, columns. The pattern is the colour at 30% under 1.5px marks in the colour, 8px across, so the series still reads as its hue. Bars, areas and rings take it; a line's stroke stays solid, since a 2px line has no room for a pattern and its marker and end label already set it apart. Turn it on for a chart that will be printed or exported, or everywhere in a product that must meet a print or high-contrast requirement.

## Motion

Marks arrive once, over `motion.duration.slow` (400ms) on the standard curve: bars grow from the baseline, lines draw in, a ring sweeps round. A change of data moves the marks the same way, which is what makes a drill-down read as the same chart one level down rather than a new one. The tooltip follows the pointer over `motion.duration.fast`; a legend hover fades the other series over the same. Under `prefers-reduced-motion: reduce` the marks draw in place and nothing fades. Nothing loops, nothing pulses but a skeleton, and no number counts up.

## Series and tones

Every series names a `color.chart.*` token through its `tone`. A status tone on a chart is data, the same rule as a Badge or a Stat, and a series that is not a status never wears one.

| Tone                                            | Use                                                                                                     |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| `success`, `warning`, `danger`, `information`   | The series carries a status: satisfied, at risk, overdue, in progress.                                  |
| `brand`                                         | The one series the reader is asked to look at.                                                          |
| `neutral`                                       | Context: totals, the remainder, last period, the plan. Also a target line and Other.                    |
| `categorical.1` to `categorical.6`              | Categories with no status, in this order: blue, orange, teal, red, purple, green. The default when a series has no tone. |
| `categorical.7`                                 | Other: the fold for everything past the sixth. Grey.                                                    |

The order is not cosmetic. It was chosen by enumerating every order of the six hues and keeping the ones whose neighbours stay apart under deutan and protan vision: the worst neighbouring pair sits at ΔE 12.7 in both modes, above the floor of 8, and the first three validate against each other in every pairing, which is why a Scatter takes three groups at most. Assign in order, never by rank: a filter that hides a series must not repaint the survivors. Past six, fold the tail into Other, split into small charts, or make a table; never a seventh hue.

Two more scales exist for a Heatmap: `color.chart.sequential.1` to `5`, blue from light to dark for how much; and `color.chart.diverging.negative.bold`, `negative`, `midpoint`, `positive`, `positive.bold`, red against blue around grey for above and below.

## Content

- **The title is a noun phrase**: "Coverage by control family", "Findings over time". Not a sentence, not a verb.
- **The description is the period, the unit or the source**, one line: "Opened in the month", "Sized by exposure in $K". While a drill-down is open it says the level: "Components of Payments".
- **A crumb is the level's name**: "All systems", then "Payments".
- **A series label is what the legend, the tooltip, the card and the table call it**: "Other than satisfied", not "other". Sentence case, no acronyms the reader would not say.
- **The numbers are formatted once**, on the Frame: grouped, two decimals at most, compact from ten thousand. A unit goes in `format`, so the axis, the tooltip, the labels, the card and the table agree.
- **A card's body is facts and one way onward**: two or three KeyValues and a button to the record. Not a form, not a second chart.
- **A reference says what it is**: "Target", "Limit", "Today", "Milestone C"; a date band says what happened in it: "Assessment window".
- **A summary is one sentence with the numbers in it**: "Open findings fell from 14 in January to 5 in September." A screen reader hears it after the description; nobody sees it.

## Style

| Element      | Token                                                                                                                              |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| Series       | `color.chart.<tone>` · the same step in both modes                                                                                 |
| Grid, axis   | `color.border` · 1px solid                                                                                                         |
| Ticks        | `font.body.xsmall` · `color.text.subtlest` · tabular                                                                               |
| Axis titles  | `font.body.xsmall` · `color.text.subtle`                                                                                           |
| Labels       | `font.body.xsmall` · `color.text.subtle` · tabular                                                                                 |
| Tooltip      | `elevation.surface.overlay` · `color.border` · `radius.medium` · `elevation.shadow.overlay` · `space.150` inline, `space.100` block |
| Card         | `elevation.surface.overlay` · `color.border` · `radius.large` · `elevation.shadow.overlay` · `space.150` · 280px · the value in `font.heading.small` |
| Hover cursor | `color.background.neutral.subtle.hovered` behind a bar · `color.border.bold` across a line chart                                   |
| Reference    | `color.chart.<tone>` · 1px dashed 4 3 · label `font.body.xsmall` in `color.text.subtlest`, above the plot for a vertical line       |
| Hovered mark | `color.chart.<tone>.hovered`: one step darker in light, one lighter in dark                                                        |
| Texture      | The series colour at 30% under 1.5px marks in the colour · 8px repeat · `radius` 2px on a swatch                                    |
| Dimmed       | `opacity.disabled`, over `motion.duration.fast`                                                                                    |
| Refreshing   | `opacity.loading`                                                                                                                  |
| Skeleton     | `color.skeleton` and `color.skeleton.subtle`, pulsing                                                                              |
| Focus        | `color.border.focused` on the plot, keyboard only                                                                                  |
| Motion       | `motion.duration.slow` on `motion.easing.standard` for the marks · `motion.duration.fast` for the tooltip and the dimming          |

Every chart colour clears 3:1 on `elevation.surface` in both modes. Text never wears a chart colour: values, labels and legends stay in the text tokens, and a coloured mark beside them carries identity. The one place text sits on a chart colour is a status Heatmap cell, which is the Badge's fill and text, already in the contrast test.

## Accessibility

- **The Frame is a figure named by its title.** A screen reader hears "Coverage by control family, figure", then the description, then the path as a Breadcrumb, then the legend as a list of toggle buttons, then the plot.
- **The table is one toggle away, for everyone.** Every chart in a Frame given `data` and `x` lays the same numbers out as a Table when the Table toggle is pressed; the toggle is a button like any other, and the plot's markup is not the only copy of the data. The tooltip enhances; it never gates.
- **The plot is a group named by the title**, or by its own `label` outside a Frame. It is focusable, the arrow keys move the tooltip across the categories, and Enter chooses the one under it, opening its card when the plot has one. The focus ring shows on the keyboard, not on a click. A plot with no name is decoration: hidden from a screen reader and not focusable, so a sparkline beside a number says nothing twice.
- **The card is a dialog** named "[the plot's name], details"; focus moves into it and back to the plot when it closes; Escape closes it.
- **Loading says so.** A loading plot is `aria-busy` and named "[the plot's name], loading"; a refreshing one is `aria-busy` over the last plot.
- **A summary is the chart in a sentence.** With `summary`, the figure is described by it, so a screen reader hears the trend without walking the table.
- **Textures are the second channel.** With `texture`, a series is its colour and its pattern, in the plot and in the legend, so a stack reads in greyscale print and in a forced-colours mode where fills are flattened. The categorical order is still validated for colour vision; textures are the belt to that brace.
- **The tools are buttons.** Download is a menu of two items, Expand opens a Dialog that returns focus when it closes, and both are disabled while the plot is loading, empty or failed.
- **Colour is never the only channel.** Two or more series have a legend; a status series has its word in the legend, the tooltip and the table; a Heatmap's status cells print their value; a target is ink, not a hue; a gap in a line is a gap.
- **The categorical order is validated** for deutan and protan vision (Machado 2009, severity 1.0) and for normal vision, both modes. A Scatter's groups stop at three for the same reason.
- **Motion respects the reader.** Under reduced motion the marks draw in place and nothing fades.
- **The axe gate runs every kind's matrix** in both modes.
