# Popover

An anchored dialog for controls, forms and supporting content. It follows shadcn's Base UI composition, with Ledger's surface, spacing and motion tokens.

```tsx
<Popover>
  <PopoverTrigger render={<Button />}>Review schedule</PopoverTrigger>
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Review schedule</PopoverTitle>
      <PopoverDescription>Reviews occur every quarter.</PopoverDescription>
    </PopoverHeader>
    <PopoverClose render={<Button />}>Done</PopoverClose>
  </PopoverContent>
</Popover>
```

## Composition

Root owns open state. Trigger and Close render native buttons by default; use `render` to compose Button, IconButton or FilterChip. Trigger's `nativeButton={false}` supports a custom element with button semantics. Custom components must forward their props and ref.

Content includes the portal and positioner. Native props, `ref`, `render`, and state callbacks for `className` or `style` apply to the popup. Title and Description connect their content to the dialog's accessible name and description; Header supplies their layout. When no visible title fits, give Content an `aria-label`.

Content defaults to 288px wide, `side="bottom"`, `sideOffset={4}`, `align="center"` and `alignOffset={0}`. Override width with `style={{ width: 300 }}` or match the trigger with `style={{ width: "var(--anchor-width)" }}`. The positioner handles collisions. Logical sides and alignment follow the Ledger locale; Content's `dir` can override it.

## Focus and dismissal

Click, Enter or Space activates the trigger. Focus moves to the first tabbable control, or the popup if it has none. Touch opening focuses the popup to avoid opening a virtual keyboard. Content's `initialFocus` and `finalFocus` support explicit focus destinations.

The default `modal={false}` leaves the page reachable. Tab moves through controls and can leave the popup, dismissing it. Escape and Close dismiss it and return focus to the trigger; an outside press dismisses it while allowing the clicked control to receive focus.

For focus trapping, use Root's `modal="trap-focus"` and include `PopoverClose` inside Content. `modal={true}` additionally restricts outside interaction; see the upstream API for its scrolling behavior. Base UI 1.7 requires the Close part inside the popup to enable its focus trap.

Inside an existing Dialog, Sheet or Drawer, the popup stays within that surface's focus scope. Escape closes the popup first and returns focus to its trigger; a subsequent Escape can dismiss the enclosing surface.

## Controlled tasks

Use `defaultOpen` for local initial state, or `open` and `onOpenChange(open, details)` for caller-owned state. `details.cancel()` rejects an open-state change. Keep form drafts in caller state when they should survive dismissal, and close after the task succeeds.

## Migration and API

Replace the old `trigger` prop with `PopoverTrigger render`, move the body into `PopoverContent`, and replace `Popover.Close` with `PopoverClose render`. Move `label` to a Title or Content's `aria-label`; move placement and sizing onto Content. `width` becomes `style.width`, and `matchTriggerWidth` becomes `width: "var(--anchor-width)"`. State attributes follow Base UI, including `data-open`.

The flat parts retain their upstream props: [Root](https://base-ui.com/react/components/popover#root), [Trigger](https://base-ui.com/react/components/popover#trigger), [Popup](https://base-ui.com/react/components/popover#popup), [Title](https://base-ui.com/react/components/popover#title), [Description](https://base-ui.com/react/components/popover#description), and [Close](https://base-ui.com/react/components/popover#close). Content additionally exposes the four positioning props above; Header accepts native div props. See [shadcn's composition examples](https://ui.shadcn.com/docs/components/base/popover).
