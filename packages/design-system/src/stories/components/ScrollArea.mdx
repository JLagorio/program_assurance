# ScrollArea

Based on [shadcn’s Base UI source](https://ui.shadcn.com/docs/components/base/scroll-area) and [Base UI](https://base-ui.com/react/components/scroll-area). Ledger retains its tokens and application layouts.

## Anatomy

A bounded scrolling region following shadcn’s ScrollArea and ScrollBar composition. ScrollArea includes the viewport, a vertical scrollbar and corner. Add ScrollBar with orientation="horizontal" for horizontal overflow.

## Accessibility

Base UI manages keyboard scrolling, scrollbar geometry and dragging. Its viewport becomes keyboard-reachable when it overflows. Use viewportProps to name the scrolling region and expose its native ref/events. Direction follows LedgerProvider or explicit dir.

## Props

Root exposes Base UI ScrollArea props, native refs, render and state callbacks; viewportProps forwards the corresponding viewport contract. ScrollBar exposes native scrollbar props, including orientation and keepMounted. Bars appear when there is overflow, following the source behavior.

### Migration and API

- Replace label with viewportProps containing role="region" and aria-label. Put sizing classes on ScrollArea.
- Replace root orientation="horizontal"/"both" with a horizontal ScrollBar child; overflow determines which bars are needed.
- The old bar visibility shortcut and fixed hide delay are removed. Native state attributes and classes can style hovering/scrolling if needed.
