# Item

A compact record row with aligned identifiers, descriptions, dates and independent actions. Item retains Ledger's record-list layout; Base UI owns link composition and disclosure behavior.

## Anatomy

Item.Group renders an ordered list inside a div. Rows share a six-column grid: disclosure, leading mark, record id, title/body, trailing value and actions. Expanded content starts under the title. A group can supply its heading, count, trailing action and empty message.

## Variants and states

Use `link` to navigate, `onSelect` for an action, or neither for a plain row. `isActive` marks the selected record. A link takes precedence over onSelect. Secondary actions and disclosure buttons remain outside the title link/button.

`children` display below the row; add `isCollapsible` to fold them. Use `defaultOpen` or controlled `open` with Base UI's `onOpenChange(open, details)`. Call `details.cancel()` to reject a change.

Group `size="compact"` reduces vertical padding. `flush` extends separators and hover backgrounds to the card edges. `idWidth` defaults to 72px; align it across related rows.

## Accessibility

The title is a real anchor or button. Enter follows links; Space activates buttons. Disclosure buttons announce expanded state and reference the linked title's id. Actions are independent tab stops. Plain rows stay out of the tab order unless the caller explicitly supplies tabIndex for programmatic focus.

A group title names the list. Use `labelledBy` when a surrounding section already provides the heading. Keep link titles descriptive; meta and trailing values are separate from the link's accessible name.

## Props

<ArgTypes of={Item} />
<ArgTypes of={Item.Group} />

Item forwards native li attributes, styles, events and refs. Its existing `id`, `title` and `onSelect` props keep their record-content/action meanings. Item.Group forwards native div attributes and refs to the outer wrapper; its `title` remains the visible group heading. Styles merge with the standalone row grid.

`link={<Link to="/record" />}` uses Base UI useRender to preserve the supplied link's attributes, ref, handlers and id. Leave the link empty to use Item's configured title. Explicit link children follow Base UI's rendered-element precedence. No router dependency is added.
