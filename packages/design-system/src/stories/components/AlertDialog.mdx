# AlertDialog

Based on [shadcn’s Base UI source](https://ui.shadcn.com/docs/components/base/alert-dialog) and [Base UI](https://base-ui.com/react/components/alert-dialog). Ledger retains its tokens and application layouts.

## Anatomy

A confirmation that requires an explicit decision. Compose AlertDialog, Trigger, Content, Header, Title, Description, Footer, Cancel and Action. Flat export names include the AlertDialog prefix. Media supplies an optional icon region; Portal and Overlay allow custom composition.

## Accessibility

Base UI prevents outside-click dismissal and supplies the alertdialog role. Put the consequences in Description. Set Content initialFocus to the least destructive action when appropriate. Escape requests a close unless the caller cancels it; Cancel is an explicit native Close part.

## Props

Root exposes generic Base UI AlertDialog props, payloads, handles and cancellable onOpenChange. Content supports native popup props plus default/sm size. Action is a Ledger Button, matching shadcn: the caller performs the action and closes only when it succeeds. Cancel composes Base UI Close with Button.

### Migration and API

- Replace configured title, description, confirmLabel and onConfirm with explicit Title, Description and Action children/onClick.
- Replace onClose with onOpenChange and pending with caller-owned cancellation, disabled buttons and loading state. Action does not automatically dismiss the confirmation.
- Move returnFocusRef to Content finalFocus. Existing app confirmations retain their 440px maximum and top placement.
