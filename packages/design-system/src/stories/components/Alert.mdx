# Alert

Inline feedback with explicit title, description and action parts. Use record-specific language that tells the reader what happened and what they can do.

## Anatomy

```tsx
<Alert variant="destructive">
  <AlertTitle>Import failed</AlertTitle>
  <AlertDescription>The file is missing record identifiers.</AlertDescription>
  <AlertAction>
    <a href="#format">Read the required format</a>
  </AlertAction>
</Alert>
```

A decorative SVG may sit directly inside Alert, or beside text inside AlertTitle. Content and icons are caller-owned. Ledger keeps actions in normal flow so long recovery links fit narrow panels.

## Variants and states

`variant="default"` uses a neutral tone; `destructive` uses danger. Ledger's optional `tone` overrides either visual tone. Tone does not choose announcement behavior.

## Accessibility

Alert defaults to `role="alert"`, following shadcn. Use `role="status"` for polite updates or `role="note"` for static contextual information. Explicitly associate titles and descriptions with `aria-labelledby` and `aria-describedby` when needed. Hide decorative icons from assistive technology. Buttons and links retain their native behavior.

## Props

<ArgTypes of={Alert} />

All parts accept native div attributes and refs. `title` is now the native HTML tooltip attribute.

### Migration

Replace `Alert.Title`, `Alert.Description`, and `Alert.Action` with flat exports. Move shorthand `title`, `action`, and `icon` content into children. Existing callers explicitly retain their previous tones and announcement roles. New callers receive shadcn's neutral default appearance and alert role.
