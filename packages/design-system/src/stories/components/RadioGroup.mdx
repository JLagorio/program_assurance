# RadioGroup

One selected value from a set of visible choices, using the shadcn Base UI composition. `RadioGroupItem` includes the circular indicator; labels and supporting content are composed outside it.

```tsx
<RadioGroup aria-label="Frequency" defaultValue="quarterly">
  <label className="inline-flex items-center gap-100">
    <RadioGroupItem value="monthly" /> Monthly
  </label>
  <label className="inline-flex items-center gap-100">
    <RadioGroupItem value="quarterly" /> Quarterly
  </label>
</RadioGroup>
```

## Selection and layout

Use `defaultValue` for local state, or `value` and `onValueChange(value, details)` for controlled state. Selecting an item clears the previous selection; selecting it again keeps it selected. `details.cancel()` rejects a change. `disabled` blocks interaction; `readOnly` allows focus while keeping the selected value unchanged. Both props can apply to the group or an individual item.

The indicator is a 16px circle with an 8px dot. The selected circle uses Ledger's brand fill and a contrasting dot. The group defaults to a grid with an 8px gap. Use classes such as `flex flex-row flex-wrap gap-200` for a horizontal layout; there is no `orientation` prop.

Tab enters and leaves the group as one stop. All four arrow keys move focus and select, skipping disabled items and wrapping at the ends. Horizontal arrows follow the Ledger locale direction, which `dir` on the group can override. Space selects the focused item; Enter does not select it. Home/End and configurable focus wrapping are not part of the installed API.

## Labels, Field and forms

The short path is a Field around a FieldSet: the FieldLegend names the group, the Field's hint and error describe it, and its `invalid` and `required` reach the group once. Each item is a horizontal Field with a FieldLabel, so it keeps its own name and needs no id. Invalid is the item's danger border, set once on the group; a focused item keeps the focus outline.

<Canvas of={Stories.BoundInField} />

Outside a Field, name the group with `aria-label` or `aria-labelledby`; inside a FieldSet the legend names it. A wrapping label or a sibling label with `htmlFor` names each item and selects it when clicked, and `aria-describedby` links supporting text. `aria-invalid` on the group marks every item. Native `required` on RadioGroup makes its hidden radio inputs take part in browser and Base UI validation; the Field's `required` only announces and marks. A FieldSet's `disabled` disables the items.

`name` and `form` associate the hidden inputs with native submission. The selected item's value is submitted. Native form reset is caller-owned in Base UI 1.7: restore controlled `value` in the form's `onReset` handler.

## Native props and composition

The group renders a div with `role="radiogroup"`. Each item renders a span with `role="radio"` and `aria-checked`, plus a hidden input. Item `ref` targets the visible control; `inputRef` and `id` target its hidden input. Group `inputRef` follows the selected input, or an enabled input when none is selected.

`render` composes a custom element and merges props, classes, styles and refs. An item rendered as a button uses `nativeButton` with `render={<button />}`; its `id` then targets the visible button. `className` and `style` accept Base UI state callbacks.

## Migration

Replace `RadioGroup.Item` with `RadioGroupItem`. Move label children and `description` into external labels and description elements. Replace `orientation="horizontal"` with layout classes. Selection values and callbacks use Base UI's generic value API, including the cancellable event details argument.

Each radio's boundary is `color.border.bold`, 3:1 against every surface, so an unchosen option can be found (WCAG 1.4.11). In forced-colors mode, the selected radio keeps a contrasting system-color dot and visible boundary.
