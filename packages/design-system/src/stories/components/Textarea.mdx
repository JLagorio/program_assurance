# Textarea

Several lines of free text: a note, description or implementation statement. This follows shadcn's native textarea implementation with Ledger styling.

## Anatomy

```tsx
<Field>
  <FieldLabel htmlFor="textarea">Review note</FieldLabel>
  <Textarea
    id="textarea"
    aria-describedby="textarea-help"
    name="note"
    value={note}
    onChange={(event) => setNote(event.target.value)}
    rows={4}
  />
  <FieldDescription id="textarea-help">
    Explain the evidence supporting this decision.
  </FieldDescription>
</Field>
```

## Variants and states

`rows` sets the expected initial answer length. Textarea has a 64px minimum height and can be resized vertically. Native read-only, disabled and invalid states use the shared control styling. Use InputGroupTextarea when the editor has header or footer addons.

## Accessibility

Use FieldLabel with `htmlFor` and the textarea’s `id`, or another accessible name. Reference hint/error IDs with `aria-describedby`; pass invalid and required announcements explicitly. Keep labels and instructions visible. Native keyboard editing, selection and form submission remain available.

## Props

`TextareaProps` is the native textarea contract, including `ref`, `rows`, `name`, `value`, `defaultValue`, `onChange`, `onBlur`, `required` and ARIA attributes. Ref and event targets are HTMLTextAreaElement. Styling and layout pass through native className and style.
