# Separator

**Status: Stable.**

A hairline between siblings: two blocks in a stack or two groups in a toolbar. Built on the shadcn Base UI Separator, with Ledger's `color.border` and parent-owned spacing. Rows, menus and tables already draw their own rules.

<Canvas of={Stories.SeparatorMatrix} />

## When to use it

- **Between two groups that are siblings** where space alone does not part them: the groups of actions in a toolbar, two blocks in a stack that hold different kinds of content.
- **Vertical, in a flex row**, between groups of controls.

Not between rows, menu items or table rows: [Item](?path=/docs/components-item--docs).Group, the [DropdownMenu](?path=/docs/components-dropdownmenu--docs)'s own separator and a [Table](?path=/docs/components-table--docs) draw their rules. Not around a container that has an edge or a surface of its own, such as a [Card](?path=/docs/components-card--docs), and not under a heading: a [Section](?path=/docs/layout-section--docs) draws that rule with `divided`. Not to divide a form's sections with a word in the rule: that is a `FieldSeparator` ([Field](?path=/docs/components-field--docs), Parts). Not as a drag handle: that is [Resizable](?path=/docs/components-resizable--docs)'s.

## Content

- A separator says nothing of its own. What the groups are is said by their headings or labels, not by the rule.
- A rule a screen reader announces, such as the one between a toolbar's groups, may take an `aria-label` that says what it divides ("Editing actions", in Native composition below). A rule that only draws a line is `isDecorative`.
- One rule between two groups, never one at the start or the end of a list or a row.

A list of rows is an Item.Group or a Table, which draw their own hairlines, never text with a Separator between each row. A rule never opens or closes a stack: with nothing on one side it is a border, which the container draws. A vertical rule goes in a flex row such as an Inline, never in a column, where it has no height to stretch to and draws nothing.

## Anatomy

One `div` by default, with `data-slot="separator"` and `data-orientation`. The rule is one pixel: a top border spanning the container horizontally, or an inline-start border stretching to the height of a flex row vertically. Stack or Inline supplies the gap around it.

Ledger retains its existing border paint instead of the reference's background-filled line. Both orientations use `color.border`; the component requires no shadcn theme or state-selector aliases.

## Variants and composition

| Option                     | Behavior                                                                   |
| -------------------------- | -------------------------------------------------------------------------- |
| `orientation="horizontal"` | Default. Spans its container between stacked blocks.                       |
| `orientation="vertical"`   | Stretches inside a flex row, such as an Inline or toolbar.                 |
| `isDecorative`             | Hides a purely visual rule from assistive technology. Defaults to `false`. |
| `render`                   | Replaces the default element or composes a custom component.               |
| `className` / `style`      | Accept a value or a callback receiving `{ orientation }`.                  |

Native props and refs reach the rendered element. Base UI merges props, event handlers, classes, styles and refs from a rendered element. A render callback or custom component must forward the supplied props and ref.

<Canvas of={Stories.NativeComposition} />

```tsx
<Separator
  orientation="vertical"
  aria-label="Editing actions"
  className={({ orientation }) => (orientation === "vertical" ? "border-bold" : undefined)}
/>
```

## Accessibility

- By default the element has `role="separator"` and an `aria-orientation` matching its orientation.
- `isDecorative` supplies `role="none"`, `aria-hidden="true"` and no `aria-orientation`. Explicit native role and ARIA props override those defaults; keep them consistent with the intended semantics.
- The default separator has no tab stop. Use Resizable for a keyboard-operable resize handle.
- Place a separator between related groups. Avoid redundant rules around containers or between rows that already draw their own borders.

## Props

`SeparatorProps` includes the Base UI primitive props and Ledger's optional `isDecorative`. Separator takes native div props, its ref, `render`, and class and style callbacks, and carries `data-slot="separator"` and `data-orientation`. See the [Base UI API](https://base-ui.com/react/components/separator#api-reference) for native composition and state callbacks.
