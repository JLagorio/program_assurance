# DatePicker

A single date stored as an ISO day (`yyyy-MM-dd`). This is Ledger’s form convenience built from [shadcn’s Popover + Calendar pattern](https://ui.shadcn.com/docs/components/base/date-picker); shadcn has no separate DatePicker root primitive.

## Anatomy

```tsx
const id = useId();
<Field>
  <FieldLabel htmlFor={id}>Scheduled completion</FieldLabel>
  <DatePicker id={id} name="due" value={due} onChange={setDue} />
</Field>;
```

The visible control is Button composed through Base UI PopoverTrigger. A hidden input carries the ISO value for native submission. The popup contains Calendar and Today/Clear actions.

## Variants and states

Use `value`/`onChange` for controlled state or `defaultValue` for uncontrolled state. Selection reports an ISO day; clearing reports an empty string. `size` is small or medium. Disabled pickers cannot open and omit their hidden input from FormData.

A range uses Calendar inside an explicit Popover. Keep application-specific range behavior at that composition.

## Accessibility

Use FieldLabel with a stable ID, or give the button an aria-label. Native refs, onFocus, onBlur, ARIA and data attributes reach the visible trigger. Hint/error IDs belong in aria-describedby. A button cannot carry aria-required; announce required state in the label or hint and validate in the owning form.

Calendar receives initial focus when opened. Selection, Clear and Escape restore focus to the visible trigger. Base UI coordinates the popup within Dialog and Drawer. Native form reset closes the popup and restores an uncontrolled default; controlled callers reset their own value. External owning forms are supported through `form`.

## Props

The existing ISO value and form contracts are retained. Button now supplies the trigger’s native behavior and shared composition, while Ledger keeps field styling and localized date-only formatting. No timezone conversion is applied to the submitted day.
