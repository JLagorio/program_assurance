# Input

One line of free text, using shadcn's Base UI Input implementation with Ledger control styling. Labels and validation messages belong to Field.

## Anatomy

```tsx
<Field>
  <FieldLabel htmlFor="input">Program name</FieldLabel>
  <Input
    id="input"
    aria-describedby="input-help"
    name="program"
    value={name}
    onValueChange={setName}
  />
  <FieldDescription id="input-help">As it appears on the authorization package.</FieldDescription>
</Field>
```

Use `InputGroupInput` inside InputGroup when the field has addons. Input itself remains a single input element.

## Variants and states

`medium` is 32px; `small` is 28px beside toolbar actions. Native `type`, `inputMode`, `readOnly`, `disabled`, `maxLength` and form attributes retain their meanings. The layout sets width. Disabled controls leave the tab order; read-only values remain focusable and copyable.

## Accessibility

Use FieldLabel with `htmlFor` and the input’s `id`, or another explicit accessible name. Reference hint/error IDs with `aria-describedby`, and pass `aria-invalid` and `aria-required` to the input. Native `required` enables browser validation. A placeholder gives an example and never replaces the label.

Native `onChange` remains supported. Search clearing and application shortcuts are caller-owned; Input does not install an Escape handler. Use an accessible InputGroupButton when a clear action is needed.

## Props

`InputProps` extends Base UI Input with Ledger's `size`. Refs and events target the native input; `render`, state callbacks for `className`/`style`, and `onValueChange(value, details)` are forwarded. A value change may be cancelled with `details.cancel()`.
