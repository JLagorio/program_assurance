# Toggle

One thing on or off, in place: bold, a pin, a filter. It is the subtle button with a recessed on state, and it acts at once on what is in front of the reader. A "toggle" that is a switch is the [Switch](?path=/docs/components-switch--docs); this is a button with a selected state. Several toggles that share one answer are a [ToggleGroup](?path=/docs/components-togglegroup--docs).

## Anatomy

| Part      | What it is                                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Container | The subtle button's box: no fill off, `color.background.neutral` on, `radius.medium`, as tall as the buttons beside it.               |
| Icon      | `icon`, passed bare, sized by the toggle: 12px at `xsmall`, 16px at `small`, 20px at `medium`. `color.icon.subtle`, default on.       |
| Label     | `children`, after the icon or alone, `font.body` medium (`font.body.small` at `xsmall`), `color.text.subtle` off and `color.text` on. |
| Name      | `aria-label` when the toggle is an icon alone: what it does, not its state.                                                           |

## Variants

Toggle has one appearance. What varies is what it holds:

| Toggle         | Use                                                                          |
| -------------- | ---------------------------------------------------------------------------- |
| Icon alone     | A toolbar: bold, italic, a pin. Named by `aria-label`.                       |
| Icon and label | A filter or a mode with a word: "Pinned", "Mine". The label says what is on. |
| Label alone    | The same, where the word carries it.                                         |

Not built, and why: an outline variant, because a bordered toggle reads as a secondary button; a bold on state, because on is a recess, not a fill, so a row of toggles never looks like a row of primary buttons; a toggle with a menu, because a control that opens is a Button.

## Sizes

| Size     | Height | Icon | Where                                                                     |
| -------- | ------ | ---- | ------------------------------------------------------------------------- |
| `xsmall` | 24px   | 12px | The densest chrome: a table's header row, a rail.                         |
| `small`  | 28px   | 16px | The default: toolbars and rows, level with small Buttons and IconButtons. |
| `medium` | 32px   | 20px | Beside medium controls on a page header.                                  |

The Button's scale, so a toggle and the button beside it are one height. An icon alone is a square: its width is its height.

## States

| State    | What changes                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------- |
| Off      | No fill, `color.text.subtle`.                                                                   |
| Hover    | `color.background.neutral.subtle.hovered`, text and icon to default.                            |
| On       | `color.background.neutral`, text and icon default; `color.background.neutral.hovered` on hover. |
| Focus    | The focus outline, on keyboard focus only.                                                      |
| Disabled | `color.text.disabled`, no hover; the on fill stays so the reader can see what was on.           |

## Modifiers

- **`pressed`** and **`onPressedChange`** control it; **`defaultPressed`** starts it on, uncontrolled.
- **`size`** as in Sizes.
- **`icon`**, passed bare; **`children`** for the label; **`aria-label`** when there is no label.
- **`disabled`** when the action is not available now.

## Content

- **The label is what it does**, not its state: "Pinned", not "On". The state is how it looks.
- **An icon alone is named** the same way: "Bold", "Pin to the top".
- **One word or two.** A toggle with a sentence is a Switch with a label.

## Style

| Element   | Token                                                                                                      |
| --------- | ---------------------------------------------------------------------------------------------------------- |
| Container | `dimension.control.{xsmall,small,medium}` · `radius.medium` · `space.075`, `space.100`, `space.150` inline |
| Off       | transparent · `color.text.subtle`                                                                          |
| Hover     | `color.background.neutral.subtle.hovered` · `color.text`                                                   |
| On        | `color.background.neutral` · `color.text` · hovered `color.background.neutral.hovered`                     |
| Label     | `font.body` medium; `font.body.small` at `xsmall`                                                          |
| Icon      | 12, 16, 20px · `space.050` or `space.075` before the label                                                 |
| Motion    | colours in `motion.duration.fast`                                                                          |

## Accessibility

- **A button with `aria-pressed`**, so a screen reader hears "Bold, toggle button, pressed". Radix Toggle underneath.
- **The name is the action.** With a label the label is the name; an icon alone takes `aria-label`. Never put the state in the name.
- **Space and Enter toggle it**; Tab moves on. Every toggle in a toolbar is its own stop.
- **On is not colour alone**: the recess, the darker text and `aria-pressed` all say it.
- **Disabled toggles stay in the tab order** as Buttons do here, so the reader can find them and hear why they are off in a tooltip.
