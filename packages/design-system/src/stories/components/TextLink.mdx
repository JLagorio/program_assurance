# TextLink

Navigation that reads as text, with Ledger's brand color, hover underline and keyboard focus outline. Use `Button variant="link"` for actions.

## Anatomy

TextLink renders an anchor by default. Compose a router link through Base UI `render`; the package has no router dependency.

```tsx
<TextLink href="/records">Records</TextLink>
<TextLink render={<Link to="/records" />}>Records</TextLink>
```

The rendered component must forward merged props and its ref. Supply its label as TextLink children.

## Variants and states

Omitted size inherits surrounding text. `small` and `medium` set the body scale; `weight="medium"` emphasizes a standalone destination. A link inside a sentence (a parent with its own text beside it, `data-in-text`) is underlined at rest, because its colour against the words beside it is about 2:1 in dark mode and colour alone would not mark it (WCAG 1.4.1); a standalone link underlines on hover. Keyboard focus adds the focus outline. Use plain text for unavailable destinations.

## Accessibility

A real anchor retains Enter activation, copy-link and open-in-new-tab behavior. Space does not activate a link. Name the destination, such as “Full timeline”, rather than “Click here”. A link in prose carries its underline by itself; no class is needed.

Where any pointer is coarse, a standalone link takes an invisible hit area at least 24px tall across its own words (the shared `touch-target-block` band), so a name in a row or a "See all" footer is easy to tap; the area is never wider than the link, even when a long name wraps. A link with its sentence's text beside it keeps its words as the target, so it takes no taps from the lines around it. A container that hides its overflow clips the area to its own box; a [KeyValue](?path=/docs/components-keyvalue--docs) value truncates across only, so a link in it keeps the whole area.

## Props

Native anchor attributes, events and refs pass through. `render` merges rendered-element refs and handlers; put element-specific props on the rendered component.

Migration: replace implicit child composition or `asChild` with `render`. Remove `asChild={false}` from native anchors. Size, weight and Ledger styles are preserved.
