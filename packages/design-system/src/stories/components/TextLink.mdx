# TextLink

Navigation that reads as text, with Ledger's brand color, hover underline and keyboard focus outline. Use `Button variant="link"` for actions.

## Anatomy

TextLink renders an anchor by default. Compose a router link through Base UI `render`; the package has no router dependency.

```tsx
<TextLink href="/records">Records</TextLink>
<TextLink render={<Link to="/records" />}>Records</TextLink>
```

The rendered component must forward merged props and its ref. Supply its label as TextLink children.

## Variants and states

Omitted size inherits surrounding text. `small` and `medium` set the body scale; `weight="medium"` emphasizes a standalone destination. Hover adds an underline; keyboard focus adds the focus outline. Use plain text for unavailable destinations.

## Accessibility

A real anchor retains Enter activation, copy-link and open-in-new-tab behavior. Space does not activate a link. Name the destination, such as “Full timeline”, rather than “Click here”. Add a persistent underline in prose where color alone would not distinguish the link.

## Props

<ArgTypes of={TextLink} />

Native anchor attributes, events and refs pass through. `render` merges rendered-element refs and handlers; put element-specific props on the rendered component.

Migration: replace implicit child composition or `asChild` with `render`. Remove `asChild={false}` from native anchors. Size, weight and Ledger styles are preserved.
