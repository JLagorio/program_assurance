# NativeSelect

**Input**, **NativeSelect** and **Textarea** share the hairline control on the input surface. All three are the browser's own element with the kit's look. Every attribute passes through. NativeSelect draws its chevron with a real icon so it follows the colour mode; `className` goes to its wrapper.

<Canvas of={Stories.NativeSelectMatrix} />

A plain list of words: **NativeSelect**, the browser's own, lightest.

A `controlBase` string is exported for the button triggers of Select, Combobox and DatePicker, so a trigger and a field are the same shape.
