# InputGroup

Compose an input or textarea with icons, units and actions using shadcn's InputGroup parts. The group supplies the shared border and focus/invalid appearance.

## Anatomy

```tsx
<Field>
  <FieldLabel htmlFor="inputgroup">Retention</FieldLabel>
  <InputGroup>
    <InputGroupInput id="inputgroup" type="number" defaultValue="90" />
    <InputGroupAddon align="inline-end">
      <InputGroupText>days</InputGroupText>
    </InputGroupAddon>
  </InputGroup>
</Field>
```

Replace `leading` and `trailing` props with InputGroupAddon children. Replace a direct Input/Textarea child with InputGroupInput/InputGroupTextarea. Set width through native style or the surrounding layout.

## Variants and states

Addon alignment is `inline-start` (default), `inline-end`, `block-start` or `block-end`. Inline positions follow text direction. Block addons create a header or footer around the control. InputGroupButton supports `xs`, `sm`, `icon-xs` and `icon-sm`, with Ledger Button variants.

## Accessibility

Label the control with Field or an explicit accessible name. Decorative icons use `aria-hidden`; explanatory text and actions remain available to assistive technology. Give icon buttons accessible names. Addon buttons are real keyboard stops and default to `type="button"`. Clicking non-interactive addon space focuses the input or textarea; custom click handlers can cancel this.

## Props

Group and Addon accept native div props and refs; Text accepts span props. Input and Textarea parts preserve their control contracts and refs. Button preserves Ledger Button's native Base UI composition, loading and disabled behavior. There are no configured content slots.
