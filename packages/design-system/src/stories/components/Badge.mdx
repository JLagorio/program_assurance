# Badge, Count, Dot and Indicator

Four ways to say a status, from one tone table. A **tone** is `neutral`, `information`, `success`, `warning` or `danger`, and every status component reads the same tokens for it, so a tone is one decision.

<Canvas of={Stories.Matrix} />

## Badge

A short status word in a soft fill: the Stripe badge, the Linear tag. Atlassian calls this a Lozenge.

- `subtle` (default) is the tinted fill with the tone's text. Use it for the status column and for tags.
- `bold` is the solid fill. One per view, for the status that must win.
- `small` (20px) is the default; `xsmall` (16px) fits a table row or a tab.
- `icon` puts a 12px icon before the word.

## Count

A number in a pill: unread items, rows in a group, results behind a filter. Anything above `max` (99 by default) renders as `99+`. Atlassian calls this a Badge.

<Canvas of={Stories.Counts} />

## Dot and Indicator

A Dot is a 6px circle in the tone's icon colour, which is tuned to read at small sizes. An Indicator is a Dot with text: severity or priority in a row, never a pill, so the status column stays the only pill in the row.

<Canvas of={Stories.InContext} />

## Which one

| Say | Use |
| --- | --- |
| The state of a record | Badge |
| How many | Count |
| Severity or priority beside a label | Indicator |
| Presence or activity in a cramped spot | Dot |
